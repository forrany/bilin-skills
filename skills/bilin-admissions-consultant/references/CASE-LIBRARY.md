# 案例库（标杆与反例）

Step 8 方向设计、Step 9 写作前各看一遍。标杆告诉你"做到什么程度算到位"，反例告诉你"哪一步会塌"。

## 怎么用这一份

- 设计方向前：扫一遍标杆案例的"方向 / 招牌项目 / 设计理念"三栏，校准标准
- 不确定某个判断时：找一个相近案例对照
- 这一份是活的——案例越多，参照越准

## handoff：怎么投喂新案例

顾问手上有新的标杆稿或踩坑稿时，按下面的格式把它加进本文件的"案例"区。投喂时给 skill 这些材料即可：

- 案例的源材料（学生资料）
- 标杆版 / 反例版的报告（说清哪一版好、哪一版差）
- 如果有版本演进记录（如某一版附录里"相对上一版改了什么"的对照表），一并给——这种记录教学价值最高

skill 收到后：读完，按下面模板压缩成一条案例，**追加**到"## 案例"区，不覆盖已有的。单版本案例控制在 40 行内，演进对照案例可略长。只留能复用的教训，不贴长报告原文。

## 案例模板

```
### <案例代号> · <一句话背景>

**学生**：年级 / 学校 / 关键特质 / 家长隐性目标
**类型**：标杆 / 反例 / 演进对照

**方向**：<这一版的方向，原样抄命名>
**招牌项目**：<有没有、是什么>
**设计理念**：<有没有显性写出、是什么>

**到位 / 塌在哪**：
- <逐条，最多 5 条>

**可复用的教训**：
- <逐条，最多 3 条——这才是这条案例存在的理由>
```

## 案例

### Jolin · HKIS G9，人文气质 + 视觉艺术 + 8 年帆船，家长隐性目标是金融

**学生**：HKIS G9 女生，全 A+（化学 A-）；硬特质 = 结构化分析 / 视觉艺术 / 海上身份；家长要"将来做金融、进藤校"。
**类型**：演进对照（v0 反例 ↔ v14 标杆）

**v0（反例）**

- 方向 = "用分析思维理解世界的人文探索者"，intended major 写 Economics / IR / SPIA——一个**类别**，换任何文科好的亚洲学生都成立
- 招牌项目：无。活动是货架清单——TASS、John Locke、Concord Review、Arts Supplement、标化
- 设计理念：有，但是反的——"多条独立路径叠加，某条没走通不致命"（投资分散思维）
- 选校：Brown anchor 之外混进了"录取率友好"的 Georgetown / Tufts
- 结构：第一章先学生画像，方向判断埋在后面

**v14（标杆）**

- 方向 = "城市研究 × 建筑"——能命名、独占、把对口大藤从 1-2 所扩到 7 所、金融出路不受影响
- 招牌项目："海岸线观察项目"——每周双视角观察，三年累积约 6-7 万字笔记 + 400-800 张摄影 + 30-40 幅画；依赖 Jolin 特有的资产交集，别人抄不走
- 设计理念：显性写出——"三条线互相喂养，她不是在做三件事，是用三种语言讲同一件事"
- 选校：逐校专业映射（Princeton 填 Architecture A.B.、Yale 填 Urban Studies……），同一份核心材料按校重组
- 结构：方向判断打头；建筑是家庭从没说过的，配了 Columbia GSAPP 试金石节点 + 明确的诚实声明

**演进的关键跃迁（v10 → v11）**

- 把视觉艺术从"海岸线项目里的配菜"升级成"作品集（承重墙）"——这一步引出建筑，是整个方案升级的钥匙（对应 STRATEGY.md 第二步"未充分利用资产审计"）
- 选校漏斗从 1-2 所扩到 7 所；周时间投入从不可持续的 35-45 小时砍到 22-33 小时

**可复用的教训**：

1. 流程做对、写作干净，仍可能只得到 v0——平庸不是流程错，是没做"战略创造"。
2. 方向升级的钥匙，常常是"被当配菜的那个资产"。先做资产审计。
3. "多路径分散"听着稳，其实是散；让活动互相喂养、并把喂养关系写出来，才是让家长眼前一亮的那个点。
