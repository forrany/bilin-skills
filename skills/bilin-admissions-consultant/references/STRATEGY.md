# 方向设计（战略创造）

Step 8 必读。这一份补的是"战略创造"层——把学生材料重组成一个让家长眼前一亮的方向。
动手前先看一遍 [`CASE-LIBRARY.md`](CASE-LIBRARY.md) 的标杆与反例。

## 这一份解决什么

流程纪律（调研先行、不编造）和写作气质（不套话、有判断）都做到，仍然只会产出一份**合格的评估报告**：学生画像 + 几个论点 + 货架活动清单 + 三档选校。它诚实、有据、不踩坑，但平庸——换个学生，结论照样成立。

家长签约前要看到的不是"评估"，是**策略**。两者的差别：

| 维度 | 合格评估（不够） | v14 级策略（标准） |
|------|-----------------|-------------------|
| 方向 | 一个类别："人文探索者" | 一个被命名的判断："城市研究 × 建筑" |
| 活动 | 货架清单：TASS / John Locke / 标化 | 一个原创招牌项目 + 互相喂养的活动系统 |
| 理念 | 没有，或"多路径分散更安全" | 显性写出："三条线是一件事的三种语言" |
| 家长感受 | "这顾问挺靠谱" | "这顾问比我还懂我的孩子" |

"眼前一亮"不是文笔堆出来的，是方向本身的洞察 + 把洞察显性讲出来。这一份就是那套方法。

## 六步法

方向不是"看出来"的，是按步骤推出来的。六步不可跳。

### 第一步：特质萃取

从全部材料里拎出学生的**硬特质**。硬特质的门槛：

- **跨年份**——不是一次表现，是多年反复出现
- **多来源**——不同评估者、不同场景独立指向同一点
- **可引用**——有原话 / 数据，不是"感觉他挺……"

一次性印象、家长的主观描述、单一来源的评语 → 不算硬特质，只能进"待验证"。

Jolin 案例：结构化分析（G5 globalization 论文 + UKAG 数学逻辑 92% + 自述）、视觉艺术（G5 美术老师评语 + UKAG creative attributes + 现场作品）、海上身份（8 年帆船 + 教练判断 + 会谈）——每一项都有 ≥3 个独立证据。这才叫硬特质。

产出：3-5 条硬特质，每条挂证据。

### 第二步：未充分利用资产审计

对每一条硬特质问一句：**"现在的（或最容易想到的）方案，是不是只把它当配菜？"**

最容易想到的方案，往往把某个真实资产浪费成"加分项"。审计就是专门找这个浪费。

Jolin 案例：最容易想到的方案把视觉艺术放进"海岸线项目"当 Common App 第二个活动——配菜。审计一问：视觉艺术能不能从配菜变成承重墙？答案就引出了建筑。

被低估的资产往往是方向升级的钥匙。

### 第三步：重组成一个被命名的方向

找一个领域 / 议题，让**尽量多的硬特质同时在场**。一个好方向同时满足：

- **能命名**——5-7 个字说清，不是一个学科分类
- **独占**——换一个学生，这个方向就不成立
- **拓宽漏斗**——能对口更多目标校，不是把鸡蛋押一个篮子
- **不牺牲家长隐性目标**——家长真正要的（如"将来做金融"）这条路也通

Jolin 案例：建筑学是少数能让"结构化思考的脑 + 视觉表达的手 + 对城市空间的真实接触"三者同时在场的领域；"城市研究 × 建筑"能命名、独占、把对口大藤从 1-2 所扩到 7 所、且金融出路不受影响。

### 第四步：发明招牌项目

方向定了，要有一个**原创的招牌项目**承载它。招牌项目 ≠ 从夏校 / 竞赛目录里选一个。它是被**设计**出来的，标准：

- **原创**——不是报名一个现成项目
- **纵向**——能持续 2-3 年，逐步累积
- **独占**——依赖这个学生特有的资产交集，别人抄不走
- **多产出**——能同时喂多条线（见第五步）

Jolin 案例："海岸线观察项目"——每周双视角观察，三年累积约 6-7 万字笔记 + 400-800 张摄影 + 30-40 幅画。它依赖 Jolin 特有的交集（8 年帆船能上水 + 绘画功底 + 住在香港），别的学生复制不了。

夏校、竞赛、研究项目（TASS、John Locke、Pioneer 等）是**底料**——必要，但不是 spike。招牌项目才是 spike。两者都要有，别混为一谈。

### 第五步：让活动咬合

把所有活动（招牌项目 + 底料 + 校内 + 标化）排成一个**互相喂养**的系统，不是几条独立路径。

- 一条线的产出要能变成另一条线的输入
- 这个喂养关系**必须在报告里显性写出来**——这就是"设计理念"

Jolin 案例：帆船拍的海岸线照片 → 喂作品集 + 喂论文素材；论文调研的劏房平面 → 转成建筑作品；AP Studio Art 课题 → 直接用论文主题。一句话点透："她不是在做三件事，是用三种语言讲同一件事。"

反面：v0 的理念是"多条独立路径叠加，某条没走通不致命"——这是投资分散，产出的是散的画像。咬合 > 分散。

### 第六步：压测 + 诚实节点

方向越大胆，越要在这一步夹住两头。

**压测**：用真实学校数据验证方向——对口专业是否存在、录取通道是否成立、时间是否可持续。压不过 → 回第三步。压测调研走 SKILL.md Step 3 + RESEARCH.md 的规则。

**诚实节点**：方向若是从特点归纳出来、家庭没说过的，必须——

- 报告里明说"这是我们的归纳判断，不是孩子原话"
- 安排一个真实的**试金石节点**让学生亲身验证（Jolin 案例：2026 暑 Columbia GSAPP 试水建筑），并写清"验证为负就收回到备选方向"

大胆而不诚实 = 给家长画饼。大胆 + 诚实节点 = 可信的洞察。

## 候选方向发散（不要只想一个）

第三步不能只产出一个方向。强制发散 **2-4 个候选**，借 SKILL.md Step 5 的 brainstorm 机制（agent team / 并行 sub-agent，不在主对话里独白）。

每个候选过四维压测：

| 维度 | 问什么 |
|------|--------|
| 选校漏斗 | 这个方向能对口几所目标校？是 1-2 所，还是一整排？ |
| 学生证据强度 | 方向的每一块都有第一步的硬特质支撑吗？有没有靠"待验证"撑着？ |
| 时间可持续性 | 排进三年周时间投入，加得起来吗？会不会逼出一个每周 50 小时的孩子？ |
| 家长隐性目标 | 家长真正要的（金融 / 名校 / 某专业）这条路兼容吗？ |

四维都过得硬的，做推荐方向；次优的留作《方向预案》里的备选。

## 八个坑（每个都有对应红旗）

| # | 坑 | 为什么会踩 | 怎么躲 |
|---|----|-----------|--------|
| 1 | 货架清单 | 模型擅长"为方向配活动"，会忠实吐出该赛道标准清单 | 每个活动问"同赛道任何学生都会被推荐吗"，是 → 只能当底料 |
| 2 | 方向含糊 | "判断方向"容易给成学科类别 | 卡死：5-7 字能命名 + 换学生不成立 |
| 3 | 分散代替整合 | "多路径更安全"听起来负责任 | 强制活动互相喂养 + 显性写出喂养关系 |
| 4 | 不会发明项目 | 模型擅长选、不擅长无中生有 | 第四步是独立必做产出，不许跳过 |
| 5 | 理念留在心里 | 做出了好设计却不解释 | "设计理念"是报告必有的显性章节 |
| 6 | 平庸 or 吹牛 | 指令不足 → 平庸；只说"要惊艳" → 编 | 大胆（六步法）+ 接地（第六步压测 + 诚实节点）同时上 |
| 7 | 越权替家庭定方向 | 大胆方向常是家庭没说过的 | 允许提，但强制诚实声明 + 试金石节点 + 人工确认闸 |
| 8 | 先定方案后调研 | 急着出方案 | 发明的方向锁定前必须用真实学校数据压测 |

## 招牌项目的可行性卡点

发明项目时过一遍可行性，避免纸上谈兵：

- **资源**——家庭 / 城市 / 学校具不具备做这件事的条件？
- **性格**——这个学生的性格做得来吗？（内向的孩子硬塞口述史采访 = 错配）
- **可独立启动**——依不依赖一个不可控的外部机构？依赖 → 必须配备选
- **真实可累积**——三年下来真能攒出东西，还是只是听着好？

任一卡点过不去 → 改设计，或在《方向预案》里标为待验证。

## 《方向预案》模板（Step 8 的交付物）

Phase A 只产出这一份，1-3 页，交人工确认。**不是完整报告。**

```
# <学生> 方向预案 · <日期>

## 推荐方向
<5-7 字命名> + 一段话推导（从哪几条硬特质推出来）

## 推导链
特质 A + 特质 B + 特质 C → 为什么指向这个方向（逐条说清）

## 支撑证据
每条硬特质挂原话 / 数据 / 来源

## 选校漏斗（压测结果）
这个方向能对口哪些目标校、各校的切入角度

## 备选方向（1-2 个）
为什么是备选不是首选——四维压测里差在哪

## 诚实标注
- 哪些是从特点归纳、家庭没说过的
- 试金石验证节点安排在哪、验证为负如何收回
- 还需要向家长确认的关键变量

## 待确认
请确认方向后，再生成完整方案。
```

确认后：pipeline.md §2 登记"方向已确认"、§5 加入已确认事实，再进 Step 9。

## 方向设计阶段自检

- [ ] 硬特质每条有 ≥2 个独立来源（单来源的进了"待验证"）
- [ ] 做过未充分利用资产审计
- [ ] 候选方向 ≥2 个，都过了四维压测
- [ ] 推荐方向能用 5-7 字命名，换个学生就不成立
- [ ] 有一个原创招牌项目，过了可行性卡点
- [ ] 活动互相喂养，喂养关系能一句话说清
- [ ] 大胆方向配了诚实声明 + 试金石节点
- [ ] 产出的是《方向预案》，没有顺势写成完整报告
- [ ] 八个坑逐一核对过
