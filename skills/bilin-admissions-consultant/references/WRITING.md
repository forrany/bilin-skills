# 写作规则

面向家长 / 学生交付物的硬规则。每次写报告 / PPT / 口播稿前必读。

## 整体气质

写作要像一个**坐在对面的老顾问在讲话**——直接、克制、有判断、不绕弯。

数据服务于叙事，不是叙事服务于数据。**冷冰冰的多维评分表 ≠ 给家长看的咨询作品。**

## 给家长看的报告 = 希望蓝图，不是评估表

报告读完，家长应该感受到：

1. 这个顾问真的研究过我孩子（不是套模板）
2. 希望是有数据底座的（不是画饼）
3. 路径是清晰的、可执行的、可追踪的
4. 不确定的地方诚实标注了（不是忽悠）

**"有退路"本身就是希望的一部分。** 家长最怕的不是"难"，是"万一不行没人告诉我"。所以 Plan B、最坏情况预案、安全网学校 = 加固希望可信度，不是削弱希望。

## 禁用模式

| 类型 | 反例 | 替代 |
|------|------|------|
| 元叙述 | "这一章是判断 X 的支撑"、"下面我们分三点讲" | 章节之间靠内容自然推进 |
| 章节衔接套话 | "讲完了 X，现在我们来看 Y" | 直接进入 Y |
| 套话 | "众所周知"、"显而易见"、"非常优秀" | 给具体证据 |
| 程式排比 | "首先…其次…最后…" 硬套 | 真的是流程才用 |
| 形容词堆砌 | "极具竞争力的优秀学生" | 用证据替代评价 |
| 章节摘要段 | 每章末尾"综上所述…" | 让结论自然落在最后一句 |
| 翻译腔 | "基于以上事实"、"在很大程度上" | "从上面看"、"差不多" |

## 要做到

- 直接给判断，再给不超过 3 条理由
- 用具体证据替代评价：✅ "HKIS G5 美术老师原话：…" ❌ "画画很好"
- 风险与限制明说，包括"如果走不通怎么办"
- 反直觉判断要有勇气说出来：例 Jolin 案例的"帆船重新定位"——8 年的投入要建议家长重新分配时间，是不舒服但必要的话
- 数据带来源（URL + 验证日期）
- 不确定就标不确定——诚实比"看起来全面"更值钱

## 长报告默认章节

任何 ≥ 3 个月的规划必须包含：

1. **学生画像**（事实陈述，每条引用证据 ID）
2. **核心论证**（为什么有希望 / 凭什么 / 论点要带数据）
3. **路径与时间线**（G10 / G11 / G12 关键动作）
4. **选校策略**（三档 + 安全网，每所匹配理由要具体）
5. **风险管理 / 最坏情况**（ED 被拒怎么办 / 竞赛没中怎么办）
6. **复评机制**（明确"每年 X 月用 Y 框架重新评估"）
7. **诚实的不确定性**（我们不知道什么 + 何时能确认）
8. **附录数据来源表**（每个数据点 URL + 日期）

## 完工自检

- [ ] 没有元叙述 / 套话 / 程式排比
- [ ] 没有"承上启下"的章节衔接
- [ ] 没有形容词堆砌
- [ ] 反直觉判断敢于明说
- [ ] 每个判断有具体证据支撑
- [ ] 数据带来源（或标"待核实"）
- [ ] 风险章节存在（≥ 3 个月规划）
- [ ] 复评机制明确（≥ 1 年规划）
- [ ] 最坏情况预案存在
