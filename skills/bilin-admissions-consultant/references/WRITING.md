# 写作规则

面向家长 / 学生交付物的硬规则。每次写报告 / PPT / 口播稿前必读。

## 整体气质

写作要像一个**坐在对面的老顾问在讲话**——直接、克制、有判断、不绕弯。

数据服务于叙事，不是叙事服务于数据。**冷冰冰的多维评分表 ≠ 给家长看的咨询作品。**

## 给家长看的报告 = 希望蓝图，不是评估表

报告读完，家长应该感受到：

1. 这个顾问真的研究过我孩子（不是套模板）
2. 希望是有数据底座的（不是画饼）
3. 路径是清晰的、可执行的、可追踪的
4. 不确定的地方诚实标注了（不是忽悠）

**"有退路"本身就是希望的一部分。** 家长最怕的不是"难"，是"万一不行没人告诉我"。所以 Plan B、最坏情况预案、安全网学校 = 加固希望可信度，不是削弱希望。

## 禁用模式

| 类型 | 反例 | 替代 |
|------|------|------|
| 元叙述 | "这一章是判断 X 的支撑"、"下面我们分三点讲" | 章节之间靠内容自然推进 |
| 章节衔接套话 | "讲完了 X，现在我们来看 Y" | 直接进入 Y |
| 套话 | "众所周知"、"显而易见"、"非常优秀" | 给具体证据 |
| 程式排比 | "首先…其次…最后…" 硬套 | 真的是流程才用 |
| 形容词堆砌 | "极具竞争力的优秀学生" | 用证据替代评价 |
| 章节摘要段 | 每章末尾"综上所述…" | 让结论自然落在最后一句 |
| 翻译腔 | "基于以上事实"、"在很大程度上" | "从上面看"、"差不多" |

## 要做到

- 直接给判断，再给不超过 3 条理由
- 用具体证据替代评价：✅ "HKIS G5 美术老师原话：…" ❌ "画画很好"
- 风险与限制明说，包括"如果走不通怎么办"
- 反直觉判断要有勇气说出来：例 Jolin 案例的"帆船重新定位"——8 年的投入要建议家长重新分配时间，是不舒服但必要的话
- 数据带来源（URL + 验证日期）
- 不确定就标不确定——诚实比"看起来全面"更值钱

## 长报告默认章节（完整方案 = v14 骨架）

前提：完整方案动笔前，方向已经过 Step 8 的人工确认。未确认不要写。

章节顺序服务于一件事：让家长在第一页就"眼前一亮"。所以**方向判断打头，孩子第二，学校第三**——招生官识别"这是哪种孩子"很快，方案也要从孩子本身出发，先讲方向，再落到学校。

任何 ≥ 3 个月的完整方案默认包含：

1. **方向判断**（开篇就给——5-7 字命名的方向 + 一段推导链。不要把它埋到第三章）
2. **学生画像**（3-5 条硬特质，每条挂证据原话；这是方向的事实基础）
3. **方向如何在目标校层面落地**（逐校专业 / 切入角度映射，同一份核心材料按校重组）
4. **三年规划路线图**，这一章必须含——
   - **设计理念**：几条线如何互相喂养，显性写出来（缺这段，方案就退回"评估"）
   - **招牌项目**：独立成节，讲清它是什么、三年产出什么
   - 学术 / 选课、底料活动（夏校竞赛）、标化节奏
   - 时间投入测算（要加得起来，不能逼出每周 50 小时的孩子）
5. **风险管理与诚实节点**（试金石验证节点、走不通的备选、ED 被拒怎么办）
6. **每年复评机制**（明确"每年 X 月用 Y 框架重新评估"）
7. **写给家长**（直接回应家长的隐性目标和反复会想的顾虑）
8. **附录数据来源表**（每个数据点 URL + 验证日期）

和 v0 式"先学生画像、再论点"的区别：方向是结论，结论先行。证据（第 2 章）用来支撑已经抛出的方向，不是慢慢铺垫才到方向。方向设计的方法见 [`STRATEGY.md`](STRATEGY.md)。

## 完工自检

- [ ] 没有元叙述 / 套话 / 程式排比
- [ ] 没有"承上启下"的章节衔接
- [ ] 没有形容词堆砌
- [ ] 反直觉判断敢于明说
- [ ] 每个判断有具体证据支撑
- [ ] 数据带来源（或标"待核实"）
- [ ] 风险章节存在（≥ 3 个月规划）
- [ ] 复评机制明确（≥ 1 年规划）
- [ ] 最坏情况预案存在
- [ ] 方向判断在开篇，不是埋在中段
- [ ] 设计理念已显性成段（活动互相喂养讲清楚了）
- [ ] 招牌项目独立成节
