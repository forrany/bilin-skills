# 风格样本目录（占位）

本目录用于存放比邻公众号过往爆款或风格代表作的文本，作为脑暴阶段的语感参考。

## 怎么用

- 把过往文章（**纯文本，不要带平台样式**）放在本目录下，以 `.md` 文件保存。
- 文件名建议用简短的英文或拼音标签，便于识别，比如：
  - `01-parent-letdown-story.md`
  - `02-cs-major-decision.md`
  - `03-activity-list-deep-dive.md`
- 每个文件的开头写 2-3 行的"标签"（适合家长 / 适合学生 / 故事型 / 方法论型 / 数据型），用 HTML 注释或 frontmatter `tags` 字段均可，帮助 skill 识别样本属于哪种风格。

## skill 怎么读取

SKILL.md 中的逻辑：

- 如果本目录下存在 `.md` 文件，Step 2 开始前 skill 会先 Read 一遍这些样本，让候选标题与切入点的语感对齐这些样本。
- 如果目录为空（如当前状态），skill 会按 SKILL.md 中"调性"小节的文字描述执行（专业、稳重、有深度）。

## 注意事项

- 文章里如果有真实学生姓名、学校名、家庭信息，**请在放入本目录前手动脱敏**——这些文件会作为上下文进入 skill，谨慎处理。
- 样本不需要多。3-5 篇有代表性的爆款比 30 篇齐全样本更有用。
- 当业务调性发生变化（比如公众号定位调整）时，记得来本目录清理一遍旧样本。
