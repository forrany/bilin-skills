# 比邻公众号选题脑暴

## 这个 skill 是干嘛的

比邻顾问在一个 case 进行到某个节点（开完家长/学生会议、规划方案出炉、阶段性资料齐整等）后，希望把这次 case 沉淀成公众号文章。但在动笔之前，顾问需要先**穷举所有可能的选题角度**，再从中挑出 1–3 个真正值得写的方向。

这个 skill 的全部职责，就是把杂乱的会议转录、报告、原始资料、手写笔记，转化为一份**可挑选、可打磨、可定稿**的选题清单。**不要在这个 skill 里写正文。** 正文写作会在另一个 skill 里完成。

## 三步工作流（请严格按顺序）

### Step 1 · 先产出"case 素材画像"，停下来等用户确认

在脑暴前，先把所有输入素材提炼成一份**简短的 case 素材画像**，输出给用户后**停下来**，等用户说"OK，继续脑暴"或者补充修正。

之所以要做这一步，是因为：

1. 输入素材常常是 4 种以上的混合体（会议转录 + 评估报告 + 原始资料 + 顾问笔记），如果不先归拢，后面脑暴会跑偏。
2. 用户对自己的 case 比你熟得多，让他/她在你正式发力之前先校正一次，能避免你在错误的素材理解上穷举 25 条都是错的。
3. 画像本身也是后续写稿的素材索引。

**素材画像的输出模板**（用 Markdown，控制在 250 字以内）：

```markdown
## case 素材画像

- **学生画像**：年级 / 申请方向（标的国家、学校梯度、专业方向）/ 性格或学术亮点的一句话
- **后源与背景**：家庭背景、过往轨迹中影响申请的关键点（脱敏前的原话即可）
- **本 case 关键节点**：本次会议或资料整理涉及的具体决策、转折、新信息
- **可挖掘的张力点**（2-4 个）：例如"想冲藤校但 GPA 不够亮眼"、"家长想读 CS 学生想读哲学"、"活动列表只有 5 条但每条都很硬"等
- **素材中的盲区**：哪些信息缺失或语焉不详，可能会限制某些选题方向
```

输出完素材画像后，**停下来**，用一句话邀请用户校对：
> "上面这份是我从素材里提炼出的画像。你看哪里需要补充或修正？确认后我就开始按 8 个维度穷举公众号选题。"

不要在 Step 1 里就开始脑暴选题。脑暴是 Step 2 的事。

### Step 2 · 按 8 个维度穷举 15–25 条候选选题

收到用户确认后，按下面的 8 个维度**逐个走一遭**，每个维度至少出 2 条候选选题（如果素材实在不足以支撑某个维度，明确写一句"该维度本 case 素材不足，候选偏弱或缺失"，但不要直接跳过——这本身也是对用户的信息）。

8 个预设维度（详细的角度提问与示例见 `references/dimensions.md`，**第一次穷举前请先 Read 一次该文件**）：

1. **学生成长故事** — 把这个 case 写成一个人的故事
2. **申请策略 / 定校定专业方法论** — 决策逻辑可被同类家庭复用
3. **活动 / 文书 / 推荐信的具体打法** — 技术层面的方法论
4. **行业趋势 / 录取变化观察** — 这个 case 反映了哪些行业信号
5. **家长视角 / 亲子决策** — 写给家长的，关于支持与放手
6. **踩坑提醒 / 反面教材** — 哪些路本可以不走
7. **顾问专业判断 / 案例复盘** — 行业内同行能学到什么
8. **数据 / 对比 / 跨 case 横向思考** — 把这个 case 放进更大的样本里看

总数控制在 15–25 条。低于 15 条说明你没穷尽，高于 25 条说明开始注水了。

**输出格式（严格遵循）**：一个 Markdown 表格，列依次为：

| # | 维度 | 工作标题 | 一句话切入点 | 目标读者 | 对家长/学生的价值 | 素材回溯 | 脱敏点 | 预估争议点 |

字段含义：

- **#**：序号 1–N，方便用户后面说"我要 #3、#11"。
- **维度**：上述 8 个维度之一，直接写数字+维度名（如"5 · 家长视角"）。
- **工作标题**：暂用标题，便于识别；不要为了博眼球而虚构（这一步不是终稿标题）。
- **一句话切入点**：用一句话讲清楚"这篇文章想从哪个角度切，给读者讲一件什么事"。这是用户挑选时最重要的判断依据。
- **目标读者**：明确写"家长 / 学生 / 双受众"，并简短补一句具体到哪类家长或哪类学生（如"GPA 一般但活动有亮点的高一家长"）。
- **对家长/学生的价值**：读者读完能带走什么——一个判断、一个方法、一个安慰、一个警觉。
- **素材回溯**：本条选题主要来自素材的哪一部分（如"5/12 会议转录第 3 段，关于家长对专业选择的反复"），便于用户核实与后续写稿时回到原文。**这一条必填**，不要写"综合多份素材"这种空话。
- **脱敏点**：哪些细节如果保留原貌会暴露隐私（学校名、姓名、家庭具体情况、活动具体名称等）。**只标识，不替换**——替换由用户在写稿阶段决定。
- **预估争议点**：这篇文章发出去后，可能引发哪类不适或反弹（同行不悦、家长群体争议、学生本人不愿被这样描述、政策敏感等）。没有写"无明显争议"。

表格输出完后，用一句话邀请用户进入 Step 3：
> "上面 15–25 条都列出来了。你看哪些感兴趣？可以直接点号（如 #3、#11），也可以让我把某条换个切入点、并到一起、或者再补充某个角度。我们一起收敛到 1–3 个最终选题。"

### Step 3 · 对话打磨，定稿 1–3 个

用户会用各种方式给出反馈：

- "我要 #3 和 #11"
- "#3 把切入点换成家长视角"
- "#7 和 #15 能不能合一篇？"
- "再补两条关于活动列表的"
- "都不太对，重新想一遍"

照做。每次用户提出修改后，**只展示被改动的部分**（被改动的条目、新增的条目、合并后的条目），不要把整个 15–25 条表格重新打一遍，否则你和用户都会被自己淹死。

当用户表达"就这几个了"、"定下来"、"OK 这几个就开始写"等收敛信号时，输出**最终选题卡片**——1–3 张，每张比清单条目更详细一些：

```markdown
## 最终选题 · #N

- **工作标题**：（同清单中的标题，或用户最终选定的版本）
- **正式标题候选**（3 条，留给写稿阶段挑选）：
  1. ……
  2. ……
  3. ……
- **核心切入点**（2-3 句）：……
- **目标读者**：……
- **读者收益**：（读完能带走什么）……
- **文章主结构提示**（3-5 个 bullet，不展开）：
  - ……
  - ……
- **素材回溯**（要展开到具体段落或文件位置）：……
- **必须脱敏的点**：……
- **写稿阶段需注意的争议点**：……
```

**正式标题候选**是终稿前最后的脑力活，请用心做——同一个选题给 3 个不同腔调的标题（一个偏理性、一个偏故事、一个偏锋利），让用户在写稿时挑或自己改。

输出最终卡片后，用一句话收尾：
> "选题已经定到这里。后续要进入写正文阶段，请用 bilin 公众号写稿 skill（待补）。"

## 核心原则

### 穷举 ≠ 注水

"穷举"指的是覆盖角度，不是堆砌数量。如果某个维度在本 case 里素材真的薄，宁可在该维度下只出 1–2 条加注"素材偏薄"，也不要硬凑 4 条同质化的"看起来不一样其实一样"的选题。**用户最反感的是被表面繁荣骗去做选择。**

### 受众分裂时分开列

家长视角的"家长应该怎么放手"和学生视角的"我是怎么熬过来的"，是**两个选题**，不要合并写。哪怕素材来源是同一段对话，也要拆出两条。这种"同源不同视角"恰好是穷举价值的体现。

### 每条都要回得到素材

这是为什么"素材回溯"字段必填。如果某条选题你写不出"来自素材的哪一段"，那就是你在凭空脑补、不是脑暴 case。这种条目要**去掉**，不要保留。

### 调性：专业、稳重、有深度

不追热点，不滥情，不渲染。比邻公众号的家长读者多数是高知或愿意投入研究的，他们更欣赏方法论的清晰和经验的真实，而不是煽情的金句。这一点会反映在"一句话切入点"和"工作标题"的措辞里——倾向用陈述句、避免"震惊体""感动体""惨痛体"。

### 脱敏只标识、不替换

你的工作是**指出哪里有隐私风险**，让用户决定怎么处理。不要主动改"L 同学"、"某常春藤"，否则会丢失信息，反而给后期写稿增加理解负担。

## 输入素材的处理建议

进入 Step 1 前，先用以下顺序通读所有素材：

1. 顾问手写笔记（要点 bullets）—— 通常最浓缩，先有个总览
2. 评估报告 / 规划方案 docx —— 校准官方判断与脱敏后表述
3. 会议转录文本 —— 抓鲜活原话、抓张力、抓未被官方化的细节
4. 学生原始资料（成绩单、活动表、文书草稿）—— 补充硬事实

如果输入是文件路径（uploads/ 下），用 Read 工具读全；如果是用户粘贴在对话里的内容，直接处理。**素材画像里的引用片段越具体越好**——具体的原话、具体的章节，比泛泛的"家长很焦虑"有用得多。

## 关于风格样本（后期接口）

`references/style_samples/` 目录目前是空的占位。后期用户会在里面放比邻过往的爆款公众号文章作为风格参考。

**当 `references/style_samples/` 下存在 `.md` 文件时**，请在 Step 2 开始前先 Read 一遍这些样本，并在脑暴时让候选标题与切入点的语感**对齐这些样本**（不是复制，而是同腔调）。

如果目录为空，按本 SKILL.md 中"调性"小节的文字描述执行即可。
