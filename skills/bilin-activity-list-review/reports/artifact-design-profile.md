# Artifact Design Profile

定义**评估报告**这份产物应该怎么读、怎么扫。内容决定视觉系统，不套固定模板。

**v1.2 更新（2026-09-04）**：从单产物改为**双产物**——中文报告（§0–§8）+ 外教英文 clean version。读者画像同步修正：真实使用反馈显示主要读者是顾问（复核 + 决策）与外教（执行改写），家长只读 §1 和 §8。

---

## 产物定位

| 项 | 决定 |
|---|---|
| **产物族** | 评审报告（review report），非教程、非仪表盘；v1.2 起为**双产物** |
| **读者** | 中文报告：顾问为主、家长为辅；英文 clean version：外教（native-speaker coach） |
| **阅读场景** | 顾问逐条复核依据并做 ED 决策；外教照单执行改写；家长看 §1/§8 知道好坏与方向 |
| **主交付格式** | Markdown；外教版独立文件（如需 PDF/DOCX，走 `bilin-admissions-consultant` 的 OUTPUT.md） |

**核心矛盾已变**：原来是「家长要快 vs 顾问要全」。现在任一产物的读者是**同一个人群**（顾问），快慢矛盾弱化；新矛盾是**中文报告要全（供顾问复核出处），外教版要极简（供外教执行）**——所以拆成两份，而不是让一份又全又简。

---

## 双产物分工

| | 中文报告（§0–§8） | 外教英文版 |
|---|---|---|
| 读者 | 顾问 / 家长 | 外教文字教练 |
| 要什么 | 全：出处、依据卡、矩阵、论证 | 极简：排序 + 按重要性分级的修改建议 |
| 篇幅 | 全文 | ≤1 页（约 500 词） |
| 语言 | 中文 | 英文 |
| 放不放分数/URL/颜色 | 放 | 全不放 |
| 规范出处 | REPORT-TEMPLATE.md | CLEAN-VERSION.md |

**关键纪律**：外教版是中文报告的**投影**，不是翻译，也不是第二轮创作。它不能出现中文报告里没有的任何主张（`CLEAN-VERSION.md` 一致性门禁）。

---

## 中文报告的阅读路径设计（§0–§8）

```
§1 一页概览（锚定组合 + 现状/预期分）  ← 家长在此形成判断
   ↓
§2 主题与定位                        ← 建立人设印象
   ↓
§3-4 三大匹配 + ED×专业矩阵           ← 顾问核对依据、做 ED 决策
   ↓
§5-6 Red mark + 排序                  ← 实际问题清单 + 执行顺序
   ↓
§7 逐条修改建议                      ← 外教版的信息来源（顾问核对后转发）
   ↓
§8 综合判断                          ← 焦虑的读者直接跳这里
```

**设计要求**：§1 和 §8 都能**独立读懂**。读者从 §1 跳到 §8 不应有理解断层。

## 密度与节奏

| 节 | 篇幅 | 密度 | 节奏作用 |
|---|---|---|---|
| §0 更正与撤回 | 仅存在时写 | 中 | 前置：撤回错误内容 |
| §1 一页概览 | 极短（约 14 行，含锚定组合+现状/预期分） | 高 | 快进：先给判断 |
| §2 主题与定位 | 100–150 字 | 中 | 慢下来：建立人设印象 |
| §3 三大匹配 | 每维 80–150 字 + 依据卡 | 中高 | 论证主体 |
| §4 ED×专业矩阵 | 多候选时写；矩阵 + 锚定 + 空转通道 | 高 | 顾问做 ED 决策的核心 |
| §5 Red mark | 每条 3–4 行（含依据） | 高（清单） | 加速：可扫读 |
| §6 排序建议 | 10 行 + 理由 + 组合差异 | 中 | 过渡 |
| §7 逐条修改 | 每条 4 字段 + 出处对账 | 高（最长一节） | 慢：执行参考 |
| §8 综合判断 | 一段 + 四落点 + 交付说明 | 低 | 收束：给落点 |

**节奏原则**：高密度的分数与清单集中在 §1、§4、§5，叙事落在 §2、§3、§8。避免连续三节都是清单。

## 各节视觉约定

### §1：不用 Markdown 表格
用**对齐的纯文本块**，顶部是锚定组合（多候选时读者理解全篇的前提）。

```
锚定组合：WashU × Music（ED 推荐）

整体综合分　4 → 5
专业匹配度　5 → 5
学校匹配度　3 → 4
文书一致性　N / A（未提供文书）

Red mark：🔴 0 条　🟠 1 条　🟡 3 条
真独立活动占比：40%（🟡）

一句话判断：……
```

### §3 学校匹配：依据卡小表
逐格一行：学校·院系 / 主张 / 时效 / 检索日 / 结论。URL 可写成脚注或随行，**但不堆砌**。

### §4 矩阵：一张 2×2 或 n×m 表 + 一段锚定理由 + 一段空转通道
矩阵表只放分数；理由与通道用叙事句，不塞进表里。

### §5：统一标记格式
每条 red mark 强制 `触发条件（引原文）/ 依据（标签）/ 建议`，色块做视觉锚点。

### §7：每条活动一个三级标题
`#3　活动名` 下按四字段列点，**含出处对账**（专有名词/数字/头衔 → 材料出处 → 结论）。英文替换文案单独成行方便复制。

### 外教版（独立文件）
见 `CLEAN-VERSION.md`。不是本报告的一节，单独成文件。

## 质量门禁（出报告前自查）

- [ ] 遮掉所有分数和表格，剩余文字仍然读得通、有判断
- [ ] §3 学校匹配的每一格都有依据卡（URL + 检索日 + 时效判定）
- [ ] §5 能看到 `X / Y = Z%` 的完整占比计算
- [ ] 每条 red mark 有依据标签 + 可执行下一步；`[缺]` 与「冲突」未混淆
- [ ] §6 排序给到了具体位次；多候选时给了组合差异
- [ ] §7 四个字段都有结论，改写文案里的实词都回材料指认过（五种编撰模式自查通过）
- [ ] §1 有现状→改后预期分，且涨幅挂得上具体建议
- [ ] §8 能独立读懂，有"如果只改三件事"
- [ ] 全文没有编造的数字/头衔/术语/录取率/政策
- [ ] 外教英文版已随附，且不含中文报告之外的新主张

## 明确拒绝的做法

- ❌ 通篇 Markdown 表格，尤其 §1
- ❌ 连续的清单节
- ❌ 把 6 分样例的活动原文贴进报告当"参考答案"——会让学生照抄
- ❌ 改写文案里出现材料没有的数字/头衔（不写占位符就写事实）
- ❌ 多候选只按一个组合出结论
- ❌ 把外教英文版翻译成整份中文报告的英文全稿（那不是 clean version，是又一份全文）
- ❌ "整体表现良好，仍有提升空间"这类无落点的话
