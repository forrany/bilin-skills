# 逐字段审核清单

对**每一个活动**的四个字段逐一过，不是笼统点评。

Common App 系统本身会限制条数与字符数，**不用在这里做字数合规检查**——但要知道描述空间很小，所以"能不能一眼讲清"是真实的质量标准。

---

## 通用检查项（四个字段都要过）

每条活动的每个字段，都问这五句：

| # | 检查项 | 不合格的样子 |
|---|---|---|
| 1 | **内容质量** | 看不出做了什么、没有影响力、全是空话 |
| 2 | **语法准确度** | 时态混乱、所有格错误、大小写不规范、冠词误用 |
| 3 | **可核查性** | 没有任何第三方可证实（导师/机构/发表/获奖/公开作品） |
| 4 | **真实性** | 与年级不自洽、与文书矛盾、时长不可能、成果不可信 |
| 5 | **出处对账** | 这个字段里的每个专有名词 / 数字 / 头衔，能指回材料的哪一句？（见 [`EVIDENCE.md`](EVIDENCE.md)） |

### 第 5 项怎么做（新增，每条活动必做）

逐条活动做一次**三列对账**，不做完不许写这条的建议：

| 活动原文里的事实 | 材料出处 | 结论 |
|---|---|---|
| `Producer` | Music_Portfolio.docx 署名为他人 | ❌ 冲突 → 🔴 |
| `40-track` | 活动信息表：九年级录音课结课作业 | ⚠️ 属于另一条活动 → 不许移植 |
| `4 museums` | 活动信息表未提及 | `[缺]` → 进待补清单，不标 red mark |

**这张表是防幻觉的主要机制。** 那次事故的 5 处编撰，全部会在这一步被拦下——因为编出来的内容在"材料出处"那一列填不出东西。

**同时它防的是另一个方向的错**：把 `[缺]` 误判成"造假"。材料不全是常态，`[缺]` 只进待补清单。

---

## 字段 1：Title（活动名称）

**好标题的标准**：一眼看出"做了什么 + 在哪 + 产生什么影响"。

**核查点**
- 是否一眼能看懂？还是需要读描述才知道这是什么？
- 有没有具体名词（项目名、机构名、成果名）？
- 是否与 `description` 的主语一致？

**常见不合格**
- 空话名词堆砌：`Leadership Club` / `Passion Project` / `Volunteer Group` / `Research Program`
- 只有机构名没有动作：`Red Cross`
- 标题与描述讲的根本不是一件事

**改写方向**：`[机构/项目名] — [角色或动作]` 或 `[动作] + [对象] + [范围]`。
参照 Jason： `Phonemicica.net` / `Bridges Among Us Educational Program` / `Southern Chinese Culture Media Podcast` —— 每一个都是"专名 + 可查"。

---

## 字段 2：Description（描述）

**好描述的标准**：强动词 + 量化结果 + 专业术语 + 影响力，在极小篇幅内讲清"做了什么、改变了什么"。

**核查点**
- 开头是不是强动词？（Founded / Led / Designed / Published / Taught …）
- 有没有量化？人数、次数、覆盖学校数、产出份数、金额——有数字才有说服力。
- 有没有用上申请专业的术语？（申 CS 写 `Python` / `regression`，申语言学写 `phonology` / `corpus`）
- 有没有"所以呢"——做完了对谁产生了什么影响？
- 语法：时态是否统一（持续性用现在时、一次性用过去时）、所有格、冠词。

**常见不合格**
- "我学到了很多""提升了我的领导力""锻炼了团队合作能力" —— 全是感受无动作。
- 只有过程没有结果："参与了 XX 项目的讨论"。
- 数字缺失或明显灌水："影响了上万人"但没有任何佐证。
- 逐字重复 Title 内容，浪费篇幅。

**改写方向**：`[强动词] + [具体对象] + [量化结果] + [影响/去向]`。
参照 Jason：`first & only open-archive 中国方言项目；采访 60+ native speakers / 39 种濒危方言；被北京声音博物馆收录` —— 首创性 + 量化 + 第三方背书，三件事一句话说完。

### 改写文案的三条硬约束

1. **每个数字、专有名词、成果，必须有材料出处。** 没有的写 `{{中文说明}}` 占位符，**不填示例值**（`EVIDENCE.md` 占位符纪律）。
2. **不许跨条移植。** 别条活动的数字、别条活动的成果，不能搬到这一条来撑场面——这是那次事故的第 2 种编撰模式。
3. **不许术语升级。** 原文写 `final dialogue` 就不能改成 `Socratic dialogue`；原文写 `helped organize` 就不能改成 `co-founded`。**强动词是把原文的动作写得更准，不是把动作换成更响的那个。**

> 判断标准很简单：改写后的每一个实词，问"这个词的依据是原文/材料，还是我的润色本能？"后者一律回退。

## 字段 3：Position（角色 / 职位）

**核查点**
- 头衔与 `description` 里的实际动作是否匹配？
- 层级是否与年级 / 时长相称？
- 是真领导还是只是"成员"？
- **材料里有没有别人占了这个头衔？**（作品集署名、活动信息表、演出节目单、项目页面）

**常见不合格**
- `Founder` / `President` 但描述里只有"参加活动"
- `Co-founder` 但只有一个人
- 头衔通货膨胀：11 年级的 `Chief Science Officer` / `National Director`
- 头衔与 `time` 投入矛盾：主席但每周 1 小时
- **头衔与材料署名冲突** —— 活动写 `Producer`，但作品集文件里写着 `Produced by: {{他人}}`。这一条是 🔴，不是 🟠（见 `REDMARK.md` 红色第 2 条）

**改写方向**：头衔要么**补上支撑证据**（招了多少人、建了什么机制），要么**降一级**到 `Coordinator` / `Member`。宁可头衔小一点也要撑得住。

> **提改写建议时最容易犯的错**：给 Position 建议一个"听起来更专业"的头衔（`Producer` / `Lead` / `Director`）。**Position 的建议只能来自材料里能查到的角色事实**——查不到就只能建议降级或写占位符，不能替学生升格。

---

## 字段 4：Time（时间投入）

**核查点**
- 每周小时数 × 每年周数，是否与年级、活动性质自洽？
- 同一时段并列的活动，总时长是否可能？
- 持续性活动的时长曲线是否合理？（不该 9 年级和 12 年级完全一样）
- 是否与文书 / 其他材料里提到的时间线一致？
- **年限与层级要逐年核**：写 `four-year` 就要材料里四个年级都有记录；写 `Varsity` 就不能把 JV 那一年合并进来。

**常见不合格**
- 多个活动同时标 `40 hr/wk`（一周只有 168 小时，还要上学）
- 短期的暑期项目标了全年周数
- 9–12 年级四年，时长完全没变化，看不出成长
- 总时长与描述里的成果规模不匹配（每周 1 小时却"组织了 500 人大会"）
- **年限拉长 / 层级抬高** —— 九年级在 JV（青年队）却写成四年校队。这是那次事故的第 5 种编撰模式，**提建议时同样不许犯**

**改写方向**：按实际投入填，**宁可少填也不要注水**。招生官对时长的敏感度远高于顾问的想象。

## 执行顺序（建议按这个过，别跳）

0. **先建材料索引**（约 3 分钟）。把手里除活动列表以外的材料列一张清单：文件名 + 这份材料能证实什么类型的事实。

   ```
   Music_Portfolio_Anna.docx —— 作品署名、曲目、时长
   活动信息表.xlsx —— 各活动年级、时长、课程归属、指导人
   会议逐字稿 0821.md —— 学生自述的动机与时间线
   ```

   **没有这张索引，后面的出处对账就无从做起**——会变成凭印象说"材料里好像提到过"。

1. **先通读一遍全部活动**（约 2 分钟，不许跳），建立整体印象。读完必须能回答三个问题：
   - **两个词概括这个学生，是哪两个词？** 答不出 → 主题清晰度不及格。
   - **如果只能让招生官看一条，该是哪条？** 这条应该排第 1。
   - **哪一条让你皱眉？** 皱眉的那条大概率要进 red mark。

   带着这三个答案再往下做逐条审核。**先见林，再见木**——直接扎进四字段，容易把一堆合格的零件审成一份没有灵魂的列表。
2. **逐条过四个字段 + 出处对账表**，用上面的核查点逐项打勾。
3. **回头做交叉检查**：
   - 时间线：有没有同一时段塞了太多活动？
   - 主题：10 条里有多少条指向申请专业？
   - 真实性：真独立活动占比是多少？（见 REDMARK.md）
   - 文书：与 PS / 补充文书有没有矛盾？
4. **最后定排序**（见 REPORT-TEMPLATE.md §6；多组合时先读 `ED-MAJOR-MATRIX.md`）。

**不要跳到第 3 步**——交叉检查再重要，也是建立在逐条过完的基础上。漏掉逐条审核，报告会变成一堆正确的废话。
