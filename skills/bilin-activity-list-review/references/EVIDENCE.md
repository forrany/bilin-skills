# 出处纪律（反幻觉铁律）

本文件是这个 skill 的第一道防线。**2026-09-04 的真实使用中，本 skill 在一份报告里编出了 5 处材料中不存在的事实**，其中 2 处如果照抄进 Common App，招生官一追问就穿。那次事故的模式全部记录在下方「五种编撰模式」，出报告前必须逐条自查。

核心原则一句话：**报告里的每一句事实性陈述，都要能指到"从哪看到的"。指不出来的，不是写得含蓄一点，是不写。**

---

## 七类出处标签

每条结论、每处改写、每个数字，都必须带标签。标签写在结论后面的括号里，或写在 `依据：` 行。

| 标签 | 含义 | 写法要求 | 能作硬判据？ |
|---|---|---|---|
| `[原文 #n·字段]` | 活动列表本身 | 必须写第几条、哪个字段 | 可 |
| `[材料 文件名·位置]` | 学生其他材料（活动信息表 / 作品集 / 会议逐字稿 / 成绩单 / 推荐信） | 必须写文件名 + 能定位的位置 | 可 |
| `[文书 篇名]` | PS / 补充文书 | 必须写哪一篇 | 可 |
| `[官方 URL·检索日]` | 学校 / 院系 / 项目官网 | 必须给**具体页面** URL + 检索日期 + 页面时效判定（见下） | 可（时效为 ✅ 时） |
| `[检索 YY-MM-DD]` | 二手来源（机构稿、论坛、榜单） | 必须注「二手待核」 | 受限，**最高 🟠** |
| `[推导]` | 从客观事实推出（时长算术、年级逻辑、字段互斥） | 必须写出推导链 | 可（物理/逻辑不可能才上 🔴） |
| `[缺]` | 材料里找不到 | 只能进「待补材料清单」，写成**向顾问提的问题** | **不可**，不进 red mark、不进改写 |

### 三条硬约束

1. **无标签的事实性陈述不许写进报告。** 说不出从哪看到的，就是幻觉，宁可漏报。
2. **标签决定等级天花板**：`[缺]` 不进红橙黄；二手 `[检索]` 最高 🟠；🔴 只能由 `[原文]`/`[材料]`/`[文书]`/`[官方]` 之间的直接冲突，或 `[推导]` 的物理不可能支撑。
3. **改写文案里的每一个新事实都必须有出处。** 没有出处的位置一律写成占位符（见「占位符纪律」），**不许替学生编**。

> 主观判断（"这条描述在讲感受不在讲结果"、"这个头衔撑不住"）不需要出处标签——那是评审意见。但**支撑该判断的原文必须引出来**，不能只给结论。

## 五种编撰模式（出报告前逐条自查）

这五种不是假想，是 2026-09-04 那次事故的实际形态。**每一种都有一个共同点：编出来的内容比原文更漂亮、更专业、更符合"一份好列表该有的样子"**——所以特别难自查，因为它读起来对。

| # | 模式 | 那次的实际形态 | 自查问法 |
|---|---|---|---|
| 1 | **头衔升级** | 把 Position 写成 `Producer`，但作品集文件里白纸黑字写着 `Produced by:` 另一个人 | 这个头衔在哪份材料里出现过？材料里有没有别人占了这个头衔？ |
| 2 | **跨条移植** | 把「40 轨 Logic Pro」挂在原创歌曲名下——那 40 轨其实出自活动信息表里九年级录音制作课的结课作业 | 这个数字/事实原本属于哪一条活动？我有没有搬家？ |
| 3 | **术语加料** | 原文只写了 `final dialogue`，报告写成 `Socratic dialogue` | 这个术语是原文的词，还是我替他升级的词？ |
| 4 | **空白填充** | 某表演考级项目的训练内容，材料里零记录，报告里编出了具体内容 | 材料里关于这条有几句话？我写了几句？多出来的是从哪来的？ |
| 5 | **年限拉长 / 层级抬高** | 写 `Four-year setter`，但材料显示九年级在 JV（青年队） | 年限、层级、规模这三个数，逐个回材料核一遍对不对得上？ |

### 自查执行方式（Step 8 强制门禁）

出报告前，把报告里**所有专有名词、所有数字、所有头衔**拉成一张单子，逐个回材料指认。指认不到的两条路：

- 该事实对判断不重要 → **删掉**
- 该事实对判断重要 → **改成占位符 + 进待补材料清单**

**不允许第三条路（保留但写得模糊一点）。** "参与了较大规模的制作项目"和编一个数字一样是幻觉，只是更难被抓到。

## 占位符纪律

改写文案里凡是需要学生提供的事实，写成 `{{中文说明}}`，不要填示例值。

```
✅ Composed and self-released original song; {{总播放量或平台数据}} across {{平台名}}.
❌ Composed and self-released original song; 40-track Logic Pro production, 2,000+ streams.
```

**为什么不许填"示例值"**：顾问和外教都会直接复制粘贴。填了 `2,000+` 就一定会有人不改就交上去。占位符是唯一能保证"这里必须有人回去问学生"的写法。

三条规则：

1. 占位符用 `{{}}` 包住，**说明写成中文**——中文夹在英文文案里视觉上跳出来，不会被误当成正文。
2. 一条改写里占位符 ≥3 个，说明这条**材料严重不足**，不要硬改，直接写「材料不足，需先补：a/b/c」。
3. 外教 clean version 里保留占位符原样，并在文首写一行说明（见 `CLEAN-VERSION.md`）——**必须防住外教自己把占位符填上**。

## 学校依据卡（学校匹配度专用）

学校匹配度那一节，每一条学校主张都要有一张卡。**顾问的原话是「他们会放过期的东西」——学校官网挂着往届的截止日、往届的政策，是常态而不是例外。**

| 字段 | 要求 |
|---|---|
| 学校 · 院系/专业 | 精确到院系（同一所学校不同学院政策常常不同） |
| 主张 | 一句话，写成可被证伪的陈述 |
| URL | **具体页面**，不是学校首页、不是搜索结果页 |
| 检索日 | 我什么时候查的 |
| 页面声明的适用季 | **页面自己写的**申请季 / last updated / 截止日年份 |
| 时效判定 | ✅ / ⚠️ / ❌（见下） |
| 对本案例的结论 | 这条主张对这份列表意味着什么动作 |

### 时效判定三档

| 档 | 判定条件 | 用法 |
|---|---|---|
| ✅ 当季明确 | 页面明确标注当季（如 "for Fall 2027 applicants"）或截止日年份为当季 | 可作硬判据 |
| ⚠️ 无日期标记 | 页面没有任何季度/更新时间标记 | **按"可能过期"处理**：可以写进报告，但结论后必须加「页面无日期标记，建议提交前二次确认」 |
| ❌ 明确往季 | 页面写的是往届申请季 / 往年截止日 | **不可作硬判据**。只能写「该校往季政策为 X，当季未见更新，需向招办确认」 |

**最容易翻车的三类信息**（这三类只要拿不到 ✅，一律降级处理）：

1. **截止日期** —— 往届日期挂一年很常见
2. **可选提交通道的规格**（作品集长度、格式、是否需要 audition）
3. **专业是否开设 / 属于哪个学院** —— 院系重组后旧页面不下线

### 检索纪律

- 逐 **（学校 × 候选专业）** 对检索，不是逐学校。同一所学校下两个专业的政策可能完全不同。
- 检索关键词至少覆盖：`[校名] [专业] what we look for`、`[校名] [专业] admission requirements`、`[校名] [专业] portfolio / supplement`。
- **查不到 ≠ 打低分。** 按 `SCORING.md` 维度 3 的「检索失败给分规则」处理，标「待核实」。
- 检索到的每一条都要进依据卡表，**包括"查了但没查到"的那些**——写「未检索到该校对该专业的公开偏好表述」，这也是信息。

## 与其他 skill 的口径关系

`bilin-commonapp-review` 有一套五类依据标签（`[顾问]`/`[官方]`/`[检索]`/`[推导]`/`[待确认]`），用于表单查错。本文件的七类标签是**同一套思路在活动质量评审场景的展开**：多出 `[原文]`/`[材料]`/`[文书]` 三类，因为本 skill 的判断绝大部分要落回学生材料，而不是落回官方规则。

两边共享的不变量：**标签决定等级天花板，说不出依据就是幻觉，宁可漏报。**
