# 评估报告模板 · §0–§8

**阅读节奏**：顾问 3 分钟看完 §1 就知道大概；往下能找到逐项依据；§8 给落点。

**贯穿全篇的两条硬约束**：

1. **每个分数后面必须跟一段人话**（比邻 PIPELINE §9：不要冷冰冰的多维评分表）。分数是锚点，不是展品。有分数没故事 = 没做完。
2. **每条事实性陈述必须带出处**（[`EVIDENCE.md`](EVIDENCE.md)）。指不出出处的，删掉或改成占位符——**不许写得含蓄一点蒙过去**。

本模板产出**中文报告**。外教英文版是**另一份独立文件**，规格见 [`CLEAN-VERSION.md`](CLEAN-VERSION.md)，两份同时交付。

---

## §0 · 更正与撤回（仅在有内容时出现）

**什么时候写**：本轮发现上一版报告（或本轮草稿）写了材料中不存在的内容，或前提变更（ED 换校、专业调整）导致上一版结论作废。

**没有内容时整节删掉**，不要留一个"本次无更正"的空节。

```
### 已撤回的编撰内容（3 处）

1. #4 Position 上一版写 `Producer`
   → 材料实际：Music_Portfolio.docx 署名 `Produced by: {{他人}}`
   → 已撤回。本版按 `Composer & Performer` 处理。

2. #4 Description 上一版写 `40-track Logic Pro`
   → 材料实际：40 轨出自活动信息表「九年级 Recording and Production 结课作业」，
     属 #7，不属 #4
   → 已撤回，未移植。

3. #6 Description 上一版写 `Socratic dialogue`
   → 材料实际：原文为 `final dialogue`
   → 已撤回。

**上一版已发出的部分请勿使用。**

### 因前提变更作废的结论

ED 由 {{旧校}} 改为 {{新校}} + {{新校}}，上一版学校匹配度 {{3}} 分的
唯一支撑点（{{旧校}} 的 {{Core}} 命中）失效，本版重跑。
```

**要求**
- 逐条写：**上一版写了什么 → 材料实际是什么 → 现已撤回**。三段缺一不可。
- 撤回项**不计入 red mark 计数、不影响分数**——它是报告自身的错，不是学生的问题。
- 如上一版已发给顾问/外教/家长，明确写「请勿使用」。

## §1 · 一页概览

**放什么**：锚定组合 + 四个分数（现状 → 预期）+ red mark 计数 + 一句话定位。**本节要能独立读完。**

不用 Markdown 表格，用对齐的纯文本块——表格会让概览看起来像系统输出，削弱"顾问在讲话"的语感。

```
锚定组合：{{WashU}} × {{Music}}（ED 推荐；矩阵见 §4）
专业候选：{{Music}} / {{Philosophy}}　　ED 候选：{{Cornell}} / {{WashU}}

　　　　　　　　现状　→　全部采纳后
整体综合分　　　3　　→　4
专业匹配度　　　4　　→　5
学校匹配度　　　2　　→　3
文书一致性　　　N/A 　→　N/A（未提供文书）

Red mark：🔴 1 条　🟠 3 条　🟡 4 条
真独立活动占比：40%（🟡）
待补材料：5 项（见 §7）

一句话判断：{{一句有立场的人话}}
```

**要求**
- **锚定组合必须写在最前面**。多候选时这是读者理解全篇的前提。
- 预期分必须写明前提（默认「全部采纳红橙两级 + 排序调整」，黄色不计）。
- 一句话判断要**说人话、有立场**，不要"整体表现良好，仍有提升空间"。
- 不在这一节展开论证，论证留给 §3、§4。

## §2 · 主题与定位

**放什么**：一段 100–150 字，讲清"招生官读完这份列表，会觉得这是一个什么样的人"。

**要求**
- 用**招生官视角**写，不是复述活动。
- 说清主线是否成立、人设是否立体。
- 如果主线不成立，**直说，不要委婉**。
- 双专业时额外回答一句：这份列表能不能撑起"双向学者"人设（判据见 [`ED-MAJOR-MATRIX.md`](ED-MAJOR-MATRIX.md)「专业选项的额外处理」）。

**校验器**：读完这一段，能不能用**两个词**概括这个学生？概括不出来 = 主题清晰度不及格，就照直写。

### 负向示范（主题不成立时该怎么写）

不要写：
> "该生的活动涉猎广泛，涵盖学术、艺术与公益等多个领域，展现了全面发展的综合素质，
> 但在专业聚焦度上仍有进一步提升的空间。"

要写：
> "读完这 10 条，我说不出这个学生是谁。商赛、支教、机器人、辩论、钢琴各两条，
> 每一条单独看都不差，拼在一起却互相打架——招生官看不到一条主线，只会记住
> '什么都试过一点'。申请 CS，但 10 条里只有 2 条与计算机相关，且都是入门级课程，
> 没有任何产出。这不是'涉猎广泛'，是没有方向。"

**差别**：前者是委婉的废话，家长读完不知道该怎么办；后者给了明确判断，家长立刻知道要动什么。
客户是资深顾问，**敢说反直觉的话比说话好听更重要**。

## §3 · 三大匹配详解

**放什么**：专业匹配 / 学校匹配 / 文书一致性，每维一个小节，每节 `分数（现状 → 预期） + 点评`。

格式固定为**分数一行、故事一段**：

```
### 专业匹配度　4 → 5

这份列表有 5 条与 Music 直接相关，但最重的一条（#4 原创作品）的描述
把功劳头衔写错了：Position 写 `Producer`，而表现在作品集里的署名是
`Produced by: {{他人}}`〔材料 Music_Portfolio.docx〕。修正头衔后，
#4 的「作曲 + 演唱」才真正立得住，这一条是能扛起专业主线的。
预期 +1 来自两处：#4 头衔修正 + #3 描述补量化产出。
```

**要求**
- 每节**必须引用具体活动编号与原文摘录**，不能只给抽象判断。摘录用 `〔原文 #n·字段："…"〕` 或 `〔材料 文件名·位置〕` 标注。
- **学校匹配度那一节必须附学校依据卡表**（URL + 检索日 + 时效判定），见下方固定块。查不到就写"待核实"，不编造学校偏好。

### 学校匹配度的小节固定块

```
依据卡（逐格）
| 学校·院系 | 主张 | 时效 | 检索日 | 结论 |
|---|---|---|---|---|
| {{WashU}}·{{Music}} | {{主张}} | ✅ | {{日}} | {{命中/落空}} |
| {{WashU}}·{{Phil dept}} | {{主张}} | ⚠️ | {{日}} | {{…}} |
```
（逐格列，一张卡一行。多候选时这一节内容会明显变长——这是对的，见 §4 收敛。）

**issuance of 依据卡规则**：每一格一定有自己的 URL（写进正文或脚注，不堆砌链接到正文里）；时效是 ⚠️/❌ 的必须在结论里体现"可能过期"。

## §4 · ED × 专业选项矩阵

**放什么**：（ED 候选 × 专业候选）的矩阵 + 推荐锚定组合 + 空转通道。

**只有多候选时写这一节**；单组合时删掉，并在 §1 已写明锚定组合即可。

**结构三块**：

1. **矩阵表**

```
学校匹配度（分组合）

　　　　　　  Music        Philosophy
{{Cornell}}   3 / 6        2 / 6
{{WashU}}     4 / 6        3 / 6
```

2. **推荐锚定组合 + 理由**（按 `ED-MAJOR-MATRIX.md` 三件事权衡：分数 / 可执行通道 / 改动代价）

3. **空转通道**（单列，别埋在段落里）：

> WashU 音乐系接受作曲者提交乐谱 PDF + 录音作为可选补充材料（依据卡 WashU·Music），
> 学生手里有完整原创作品（#4，材料）却无提交计划。这是成本最低、收益最明确的一个动作。

**要求**
- 逐格给分 + 逐格配依据卡，一张卡不许覆盖多格。
- **必须收敛到推荐锚定组合**（1 个），不要给一张 4 格表就当交差。
- 排序的差异在此节预告，详表见 §6。

## §5 · Red mark 清单

**放什么**：按 🔴 → 🟠 → 🟡 分组，每条按 [`REDMARK.md`](REDMARK.md) 标记格式写。

**要求**
- 开头先给**真独立活动占比的计算过程**：分子是哪些（列编号）、总数、百分比、对应等级。
- 每条必须写 `触发条件`（引原文）+ `依据`（标签）+ `建议`（可执行）。
- 数量控制：🔴 ≤2 条、🟠 ≤4 条。超了说明该整体重做，在报告里直接说。
- **材料里查不到 ≠ 问题**。`[缺]` 类不进这一节，统一进 §7 待补清单。
- 发现上一版报告有编撰 → 归 §0，不进这一节。

## §6 · 排序建议

**放什么**：建议的新顺序（1–10），每条附 20–40 字的位置理由。**多候选时锚定推荐组合排，并给其他组合的差异。**

```
锚定组合 {{WashU}} × {{Music}} 建议顺序：3 → 1 → 7 → 2 → 5 → 4 → 9 → 6 → 8 → 10

#3 提到第 1：这是唯一命中 {{WashU}} 偏好的活动，必须让招生官第一眼看到。
#6 降到第 9：与申请专业无关，保留但不占前排。

若改锚 {{Philosophy}}：#7 从第 3 提到第 1，#3 降至第 4，其余 8 条不变。
```

**要求**
- 给**具体位次**，不要只给方向。
- 排序逻辑统一：与申请专业 + 目标校的契合度 > 投入深度 > 时间近度。
- 多候选时必须写差异，并说明"分叉了几条"——这回答"双向定位有多分裂"。

## §7 · 逐条修改建议

**放什么**：每个活动按 `title` / `description` / `position` / `time` 四字段给具体建议，能给替换文案就给。**本模板默认保留全部 10 条的修改建议，因为这是核心交付物之一。**

每条建议的固定格式（三个字段都要填）：

```
### #3　Bridges Among Us Educational Program

- **Position**：`Founder` 目前撑不住。描述里只有"组织了几场分享会"。
  → 补一条创建实质（招募 {{人数}} / 合作 {{机构}} / 产出 {{份数}} 教案），否则降为 `Coordinator`。
- **Description**：现行版本在讲"我提升了组织能力"，没有结果。
  → 建议：`Founded program partnering with {{n}} museums; authored {{n}} lesson plans
    now used in {{n}} schools.`
- **Title**：可保留。
- **Time**：`2 hr/wk, 20 wk/yr` 与"32 所学校采用"的规模不匹配，建议复核。
```

**要求**
- 四个字段**逐个给结论**（包括"可保留"），不要跳过。
- 描述建议尽量给**可直接粘贴的英文替换文案**。
- **数字、专有名词、成果，凡材料里没有的一律 `{{中文占位符}}`**，不填示例值（`EVIDENCE.md` 占位符纪律）。
- **不许跨条移植、不许术语升级、不许替学生升格 Position**（`FIELD-CHECKLIST.md` 改写三约束）。
- 提语法问题时，指出**具体错在哪**，不要只说"语法需优化"。
- **占位符 ≥3 个的活动**：不要硬改，写「材料不足，需先补：a/b/c」并转入待补清单。
- **材料里查不到但被断言的事实**（如 `Producer`）→ 单列一行「出处对账」，标注 `[缺]` 或冲突。

### 整表描述一致性终检

逐条建议之后必须给一段全表检查结果，判据见 `FIELD-CHECKLIST.md`「整表描述一致性终检」。不要只写“风格不统一”，要给活动编号、原文和替换文本：

```markdown
整表一致性：需调整 {{n}} 处
- #{{n}} `{{原文}}` → `{{替换文本}}`（{{时态/大小写/缩写/数字/标点/术语原因}}）
- #{{n}} `{{原文}}` → `{{替换文本}}`（{{原因}}）
```

若无需调整，写「整表一致性：通过——时态逻辑、大小写、缩写、数字格式、标点与术语均已统一」。所有替换文本继续受 `EVIDENCE.md` 出处与占位符纪律约束。

## §8 · 综合判断

**放什么**：一段式收尾，含四个落点。不再分节，但四个落点齐全。

```
现在什么水平：{{#1 一句话}}

三大风险：{{风险1}} / {{风险2}} / {{风险3}}

如果只改三件事：
1. {{改哪一条的哪个字段·具体到可执行}}
2. {{…}}
3. {{…}}

本次产出两份：本中文报告 + 外教英文版（Must {{n}} / Should {{n}} / Polish {{n}}）。
```

**同时写一行改前/改后一致性提示**：

> 注意：本报告给出的预期分（§1）只反映「文案修改 + 排序调整 + 头衔修正」的收益，
> 不含任何新增活动或新成果。若学生后续补齐了待补材料（§7），需回头重估。

**要求**
- **不替家长做决定**，但必须把位次和风险说清楚。
- "如果只改三件事"要具体到可执行，不要写"加强专业相关性"。

## 写作禁令

- ❌ 通篇表格、只有分数没有人话
- ❌ "整体表现良好，仍有提升空间" 这类不落地的话
- ❌ 学校偏好判断没有来源 / 没有依据卡
- ❌ red mark 只写"建议优化"不给下一步；`[缺]` 与「与材料冲突」混淆
- ❌ 排序只给方向不给位次；多候选时不给组合差异
- ❌ 编造录取率、学校政策、项目门槛等事实（查不到就标"待核实"）
- ❌ 改写文案里出现材料没有的数字/头衔/术语（不写占位符就写事实 = 幻觉）
- ❌ 只逐条改语法，不做整表一致性终检；或只写“统一风格”不给具体替换文本
- ❌ 把报告自身的编撰（§0 撤回项）记成学生的 red mark
- ❌ 多候选时只按一个组合出结论，不给矩阵

## 交付两份

- **中文报告**：本模板 §0–§8，给顾问与家长。
- **外教英文版**：独立文件，规格见 [`CLEAN-VERSION.md`](CLEAN-VERSION.md)，**不是本报告的一节**。

在中文报告 §8 写一行「外教英文版已随附」，让顾问知道外教收到了什么，口径不散。
