# 信息收集清单

缺必填项时，把这份清单**原样转发**给对接人。一次性问清，不要零散追问。

清单设计成可直接复制粘贴的样式，转发时不用改写。

---

## 转发用（可直接复制）

```
同学你好，活动列表评估需要先确认几项信息，麻烦一次性补齐后发我：

【必填】缺任一项都无法开始评估

1. 申请专业 Major
   - 主申专业：
   - 如有第二/第三方向，也请写明：

2. 申请学校（尤其 ED 校）
   - ED / EA 学校：
   - 其余 RD 学校清单：
   （活动列表的取舍和排序要跟着 ED 校调整，所以 ED 校一定要写清楚）

3. 当前活动列表
   请把每一条的四个字段都填完整：
   - 活动名称 Title：
   - 描述 Description：
   - 担任角色 Position：
   - 时间投入 Time（每周几小时 × 每年几周 + 年级）：
   共 ____ 条

【强烈建议提供】有则可以多查一项一致性

4. 主文书（Personal Statement）
5. 补充文书（Why Major / Why School）

【可选】有则更好

6. 推荐信 1–2 封（或老师的评语）
7. 已有的顾问评估 / 校内 counselor 反馈

补齐后发我，我会出一份评估报告：整体评分、专业/学校/文书三层匹配诊断、
风险标记、排序建议，以及逐条的修改建议。
```

---

## 为什么这三项是必填（对接人问起来时可以这样解释）

| 项目 | 不填会怎样 |
|---|---|
| **申请专业** | 活动列表 = 简历，专业 = 岗位。**不知道投什么岗位，简历无从评估**——只能给语法层面的意见，给不出匹配度判断。 |
| **目标校 / ED 校** | 不同学校偏好不同人。活动列表的取舍与排序要跟着 ED 校调整，没有 ED 校就无法做学校匹配度。 |
| **活动列表四字段** | 缺 `position` 无法判断头衔是否撑得住；缺 `time` 无法判断投入是否真实。四字段缺一，那条活动的审核就是残的。 |
| 主文书 + 补充文书 | 少了这一项只是**少一个维度**（文书一致性标 N/A），其余照常评估。 |

---

## 收件后的动作

1. **逐项核对**，在心里打个勾。
2. **必填缺任何一项 → 停下来，发上面那份清单。** 不要先做一部分再说。
3. 必填齐全后即可开工；文书缺失不影响启动，在报告里标注 `N/A` 即可。
4. 活动列表若是截图 / PDF / Word，先让对方给出**可编辑文本**，否则无法给替换文案。
