# 信息收集清单

缺必填项时，把这份清单**原样转发**给对接人。一次性问清，不要零散追问。

清单设计成可直接复制粘贴的样式，转发时不用改写。

---

## 转发用（可直接复制）

```
同学你好，活动列表评估需要先确认几项信息，麻烦一次性补齐后发我：

【必填】缺任一项都无法开始评估

1. 申请专业 Major（可以有多个候选，但至少一个确定）
   - 主申专业：
   - 第二/第三方向（如有）：
   - 是否考虑双专业 / 主+辅修：是 / 否

2. ED 学校 / ED 候选（可以有多个候选，但至少一所明确）
   - ED 候选学校（如果犹豫，把犹豫的几个都写上）：
   （活动列表的取舍和排序要跟着 ED 校调整；只有 EA / RD / 一般目标校清单不能替代这一项）

3. 当前活动列表
   请把每一条的四个字段都填完整：
   - 活动名称 Title：
   - 描述 Description：
   - 担任角色 Position：
   - 时间投入 Time（每周几小时 × 每年几周 + 年级）：
   共 ____ 条

【可选】只作申请背景，不替代 ED 输入

4. 其余 EA / RD / 目标学校清单

【强烈建议提供】有则可以多查一项一致性

5. 主文书（Personal Statement）
6. 补充文书（Why Major / Why School）

【强烈建议提供】这些是核对活动真实性的材料出处

7. 活动相关材料：作品集、活动信息表、奖项证书、演出/比赛节目单、项目链接等
8. 会议逐字稿 / 顾问笔记（学生自述过活动细节的记录）

【可选】有则更好

9. 推荐信 1–2 封（或老师的评语）
10. 已有的顾问评估 / 校内 counselor 反馈

补齐后发我，我会出一份评估报告：整体评分、专业/学校/文书三层匹配诊断、
风险标记、排序建议、逐条修改建议，以及一份给外教的英文修改摘要。
```

---

## 为什么这三项是必填（对接人问起来时可以这样解释）

| 项目 | 不填会怎样 |
|---|---|
| **申请专业** | 活动列表 = 简历，专业 = 岗位。**不知道投什么岗位，简历无从评估**——只能给语法层面的意见，给不出匹配度判断。多个候选专业可以，但至少一个确定，否则硬闸拦截。 |
| **ED 校 / ED 候选** | 不同 ED 校偏好不同人，活动列表的取舍与排序必须跟着 ED 定位调整。候选多个没关系，会逐校评估；但至少要有一所明确候选。只有 EA / RD / 一般目标校仍算缺件，硬闸拦截。 |
| **活动列表四字段** | 缺 `position` 无法判断头衔是否撑得住；缺 `time` 无法判断投入是否真实。四字段缺一，那条活动的审核就是残的。 |
| **活动相关材料（作品集/信息表/逐字稿）** | 少了这一项，凡是活动列表里查不到出处的事实，我们都只能标「待补」，无法帮你核对真假。 |
| 主文书 + 补充文书 | 少了这一项只是**少一个维度**（文书一致性标 N/A），其余照常评估。 |

---

## 收件后的动作

1. **逐项核对**，在心里打个勾。
2. **必填缺任何一项 → 停下来，发上面那份清单。** 不要先做一部分再说。
3. 只有 Major、至少一个 ED 校/候选、完整活动列表三项都齐全才可开工；文书缺失不影响启动，在报告里标注 `N/A` 即可。
4. 活动列表若是截图 / PDF / Word，先让对方给出**可编辑文本**，否则无法给替换文案。
5. **专业 / ED 候选多于一个 → 直接走矩阵评估**（见 `ED-MAJOR-MATRIX.md`），并在报告写清锚定组合。
