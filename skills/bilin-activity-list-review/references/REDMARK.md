# Red Mark 分级与独立活动占比红线

三级：**黄（注意）→ 橙（必改）→ 红（重做）**。

Red mark 只标**问题**，不标"待优化的小瑕疵"——后者放进 §7 逐条建议里就行，不要污染风险清单。

---

## 依据决定等级天花板（先过这一关）

标记之前先问：**这条问题的判据来自哪里？** 标签定义见 [`EVIDENCE.md`](EVIDENCE.md)。

| 判据来源 | 等级上限 |
|---|---|
| `[原文]`/`[材料]`/`[文书]` 之间的**直接冲突**（同一事实两个版本） | 🔴 |
| `[推导]` 的**物理/逻辑不可能**（时长算术、同时段两地） | 🔴 |
| `[官方 ✅当季]` 与列表事实冲突 | 🔴 |
| `[官方 ⚠️无日期]` / `[检索]` 二手 | 最高 🟠 |
| 主观质量判断（描述空泛、头衔虚、表达低效）——**原文已引出** | 最高 🟠 |
| `[缺]` 材料里找不到 | **不进红橙黄**，进「待补材料清单」 |

### 两条区分（那次事故的直接教训）

**「材料里没有」≠「与材料矛盾」。** 这两件事严重程度差一个量级，混淆会造成误伤：

| 情况 | 定级 | 写法 |
|---|---|---|
| 学生声称 X，材料里另一处明确写着非 X（如活动写 `Producer`，作品集署名是别人） | 🔴 | 「与 {{材料}} 冲突，原文为 {{引用}}」 |
| 学生声称 X，材料里查不到任何关于 X 的记录 | **不标 red mark** | 进待补清单：「#n 的 {{X}} 在现有材料中无记录，请向学生取证」 |

第二种情况**绝对不许写成"真实性存疑"**。材料不全是常态——顾问手上的活动信息表本来就不可能覆盖学生做过的每件事。把"我没看到"写成"可能有问题"，是把自己的信息缺口记到学生头上。

**唯一例外**：该活动是列表里最重的一条（前三位），且**完全没有任何第三方可核查线索**，可标 🟠（对应下方橙色第 5 条），写法是「缺支撑证据」而非「涉嫌不实」。

## 关键定义（算红线前先对齐）

- **独立活动（independent）**：没有机构、学校、组织、赛事背书的自主活动。Common App 里通常归入 `Other`。
- **可核查性（verifiability）**：是否存在**第三方**可以证实这条活动。有效证据包括：
  - 导师 / 指导老师署名或推荐
  - 合作机构（学校、博物馆、NGO、实验室、公司）
  - 发表（期刊、校刊、会议）
  - 获奖（有主办方的比赛）
  - 媒体报道 / 公开作品链接（网站、播客、GitHub、视频）
- **真独立活动** = 独立 **且** 无可核查性。**只有这个才是红线分子。**

> 一个独立执行的研究项目，只要有教授指导 + 期刊接受，就**不算**真独立。客户原话是"太多自己做的事"——重点在"无人可证"，不在"没挂靠机构"。

## 独立活动占比红线

```
真独立活动占比 = 真独立活动条数 ÷ 活动总条数 × 100%
```

| 占比 | 等级 | 含义 | 报告里必须给的应对 |
|---|---|---|---|
| **0–30%** | 🟢 无标记 | 健康 | 无需标注 |
| **30–50%** | 🟡 黄 | 偏多 | 建议补 1–2 条带机构背书的活动 |
| **50–70%** | 🟠 橙 | 严重偏多 | 必须补充可验证活动；整份列表的**整体真实度会被怀疑** |
| **≥ 70%** | 🔴 红 | 失衡 | 整份列表需重做；招生官会直接质疑真实性 |

**计算后必须在报告 §5 写明三件事**：分子是哪些活动（列出来）、占比数字、对应等级的应对建议。

**不要机械套表**。10 条里有 4 条真独立（40%）但都是重量级公开作品（有网站、有媒体），实际可信度可能高于 3 条真独立但全都无法证实的情况。红线是**起点**，不是终点——算出占比后，再做一次人工复核并说明理由。

## 🔴 红色：必须重做

触发**任一**即标红。红色问题不解决，整份列表的可信度不成立。

**前置条件**：🔴 只能由 `[原文]`/`[材料]`/`[文书]`/`[官方 ✅]` 之间的**直接冲突**或 `[推导]` 的物理不可能支撑（见开篇天花板表）。二手检索、主观判断、材料缺失一律不上红。

1. **与 PS / 补充文书直接矛盾** —— 人物画像、时间线、角色、关键数字对不上。
2. **与学生其他材料直接矛盾** —— 活动列表写的头衔 / 数字 / 年限，与作品集、活动信息表、成绩单、推荐信里的记载冲突。**必须引出双方原文。**
3. **真独立活动占比 ≥ 70%**，且这些活动无任一条可被第三方证实。
4. **标题 / 描述出现可查伪的夸大** —— 如声称创办全国性组织、获得某奖项，但公开检索无此机构/奖项。（检索无结果只能到 🟠；需检索到**明确反证**才上 🔴）
5. **时长自相矛盾到不可能** —— 同年级多个活动合计时长超过合理上限，或同一时段声称在两地做两件事。
6. **活动与申请 Major 完全无关且无补救空间** —— 10 条里找不到一条能支撑申请方向。

> 出现红色 → **整体综合分上限 3 分**（见 SCORING.md 计分规则）。

### 红的处置要分级，别一刀切

**单条红 ≠ 整份重做。** "某一条伪造了奖项"和"整份列表 70% 无法核查"是两种病：

| 情况 | 处置 |
|---|---|
| **1 条红** | **该条必须重做**，其余照常 |
| **≥2 条红** | **整份列表重做** —— 问题已不在单条，是整体可信度崩了 |
| **真独立活动占比 ≥70%**（不论有几条红） | **整份列表重做** —— 结构性失衡，改单条没用 |
| **与文书直接矛盾** | 该条必改，**且必须回头核文书**；不知道是谁错就两边都查 |

**报告里要写明落在哪一档**，不要只写"有红色问题"。家长收到"整份重做"和"改这一条"，行动完全不同。

## 🟠 橙色：必须修改

1. **真独立活动占比 50–70%**。
2. **Position 与描述不匹配** —— 头衔写 `Founder` / `President`，但描述里看不出创建或领导的实质动作。
3. **头衔层级与年级不匹配** —— 11 年级写"首席科学官""全国总负责人"等撑不住的头衔。
4. **多数活动依赖空话动词** —— "参与""学习""提升"，缺量化结果与影响力。
5. **关键活动缺失支撑证据** —— 列表里最重的一条，反而没有任何发表/获奖/合作方信息。写法用「缺支撑证据」，**不写「涉嫌不实」**（见开篇两条区分）。
6. **排在列表前 3 位的活动，描述全是空话/感受** —— "我学到了很多""提升了领导力""感受到了团队的力量"，没有动词、没有数字、没有结果。
7. **可选提交通道空转** —— 目标校为该专业开放了可选提交通道（作品集 / 乐谱 / 研究论文 / 代码库），学生手里有对应成品却没有提交计划。依据必须是学校依据卡（`[官方 ✅]` 或 `⚠️` 档，见 `EVIDENCE.md`）+ 成品的材料出处。

> 第 6 条容易被漏掉，但危害不低于前五条：招生官的注意力集中在最前面几条，**把最宝贵的版面浪费在正确的废话上，比 Position 不匹配更致命**。平庸比造假更常见，也更难被察觉。

> 第 7 条是唯一"不改也不算错、但白扔机会"的橙色项。放在橙是因为它的修复成本极低而收益明确——手里有成品、通道开着、只是没人去投。

> 出现 ≥2 个橙色 → **整体综合分上限 4 分**。

---

## 🟡 黄色：建议优化

1. 个别活动的描述语法、标点、大小写不专业。
2. `time` 栏（每周小时 × 每年周数）填得模糊或明显拍脑袋。
3. 真独立活动占比 30–50%。
4. 描述里出现所有格错误、文化误译、术语误用。
5. 标题过长或过短，一眼看不出这条在做什么。

## 标记格式（报告 §5 统一用这个）

每一条 red mark 按这个格式写，不要写成长段落：

```
[等级] 涉及活动：#3 Bridges Among Us
触发条件：Position 写 Founder，但描述只写了"组织了几场分享会"，看不出创建实质
　　　　　〔原文 #3·Description："organized several sharing sessions"〕
依据：[原文 #3·Position] + [原文 #3·Description]（同条内自相矛盾）
建议：补一条可量化的创建动作（如"招募 {{人数}} / 与 {{机构}} 建立合作 / 产出 {{份数}} 教案"），
      否则把 Position 改为 Coordinator
```

**要求**：
- `触发条件` 必须**引用活动原文的具体字段并逐字摘录**，不能只写"描述不清"。
- `依据` 必填，标签见 `EVIDENCE.md`。**无依据的条目不许写进报告。**
- `建议` 里学生需要提供的事实用 `{{}}` 占位，**不许填示例值**（见 `EVIDENCE.md` 占位符纪律）。

---

## 三条执行纪律

1. **占比必须真的算。** 不要写"独立活动较多"然后跳过数字——客户明确要求给出具体红线。
2. **不要为凑数硬标。** 一份 4 分的列表天然问题多，但 red mark 只标**影响判断**的问题，否则家长会被清单淹没。红色 ≤2 条、橙色 ≤4 条为宜，超了说明应该整体重做而不是逐条改。
3. **红橙问题必须给出可执行的下一步。** "建议优化"不算建议，要具体到"补哪条信息 / 改成什么"。

---

## 报告自身的编撰不是学生的 red mark

如果本轮发现**上一版报告**（或本轮草稿）写了材料中不存在的内容，**不要把它记成学生的问题**。走另一条路：

- 单列在报告 §0 的「更正与撤回」，逐条写：上一版写了什么 → 材料实际是什么 → 现已撤回
- 撤回项**不计入 red mark 计数**，也不影响分数
- 若上一版已发给顾问/外教/家长，在 §0 明确写「以下内容请勿使用」

这一段存在的原因：2026-09-04 的真实事故里，5 处编撰是在下一轮被自己发现的。**能自查出来是好事，但必须让它显式可见，否则错误会静默地留在顾问手里。**
