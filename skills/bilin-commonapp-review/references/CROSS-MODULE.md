# 跨模块一致性核对

单个模块逐条查完后，做这四条「链」的交叉核对。一致性问题比单点错误更致命——它让整份申请显得不可信。

每条链的输出格式：**逐环节列出各处取值 → 结论（一致 / 不一致 / 无法核验）→ 不一致时以哪个源为准**。

---

## 链 1：姓名链

**源头（基准）：护照。**

核对点：
- Profile → Legal Name
- 成绩单上的姓名
- TOEFL / SAT / ACT / AP 成绩单上的姓名（注意 SAT/ACT 注册名）
- **多邻国 DET 账号注册名**——DET 官方要求账号姓名与护照完全一致，不一致则成绩无法与申请人匹配（易漏环节）
- 推荐信、活动证明、论文发表中的姓名拼写
- 推荐人姓名/职务（R6）
- Preferred Name 与以上材料中出现的昵称/英文名是否对得上

**结论基准**：一切以护照为准。任何一处不一致 = 🔴（材料无法归档匹配）。**没有护照时整条链标「无法核验」**，进待确认清单。

**拿不到的环节**（推荐信、DET 账号名）→ 该环节标 ❔，**不进待确认清单**，不阻塞结论。

---

## 链 2：GPA / 成绩链

**源头：学校官方成绩单。**

核对点：
- Education → GPA（计分体系原样，不许换算）
- Courses & Grades → 课程名 / 年级 / 成绩
- Testing → AP/IB/A-Level 成绩与成绩单上登记的一致
- Testing → CA 自报分数（SAT/ACT/TOEFL/DET/AP）与官方成绩单**逐位**核对——1490 手滑成 1940 这类错误靠"扫一眼"抓不住，必须逐位
- 文书中若有提到 GPA / 排名 / 成绩的数字，与表内一致

**结论基准**：成绩单为准。不一致 = 🔴（触发审核预警）。注意：CA 填报与成绩单**信息不一致**是审核预警的明确触发条件（顾问文档原话）。

---

## 链 3：活动名链

**源头：Common App Activities List（学生自己申报的版本）。**

> **去重规则**：本链与 A2、S2 查的是同一件事。**A2 / S2 的结论直接汇总到本链，不重复产出条目**——报告里同一处不一致只出现一次。本链负责的是 A2/S2 覆盖不到的环节：活动证明、推荐信中的表述，以及三处（List / PS / Supplements）之间的三方交叉。

核对点：
- Activities List 中的活动名称 / 机构名 / 职位
- 活动证明 / 推荐信中的活动表述
- 汇总 A2（PS vs List）、S2（Supplements vs List）的结论

**结论基准**：表述差异分两档——
- 同一活动两个版本的事实性出入（时间、职位、成果数字对不上）= 🔴
- 仅措辞 / 详略不同 = 不标记，属正常

**注意**：不一致时不知道是表错还是文书错，报告里写明「两边都查」，不要擅自认定哪边对。

---

## 链 4：时间线链

核对点：
- 活动参与年级（含暑假归属规则：升入年级，如 9升10 暑假 → 10 年级）
- 同一时间段的活动总时长是否物理可能（同年级多活动合计对照 A1 参照表）
- Education 的在读时间与活动年级覆盖一致（不能有活动发生在入学前/毕业后）
- Gap / 转学等时间断档在 Education 与 Additional Info 里的解释一致

**结论基准**：物理不可能（两地同时、超总量）= 🔴；数值区间外 = 🟠 待顾问确认。

## 补充：与目标校的校验

- 每所目标校的标化政策 → 逐校检索（见 SEASON-2027.md 的记录格式）
- 每所强制 C&G 的学校 → 核对 C&G 板块已填
- 每所学校的推荐人要求与提交状态 → 逐校核对（R1–R3）
- 每所学校的轮次 / 学院-专业 / 必答 Questions → 逐校核对（M1–M3）
- ED/EA/RD 截止日期与材料齐备状态（终检时）
