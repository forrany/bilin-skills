# 信息收集清单

缺必填项时，把这份清单**原样转发**给对接人。一次性问清，不要零散追问。

---

## 转发用（可直接复制）

```
同学你好，Common App 表单审核需要先确认几项信息，麻烦一次性补齐后发我：

【必填】缺任一项都无法开始审核

1. Common App 已填写的内容
   - 已填板块（勾选）：□ Profile □ Family □ Education □ Testing
                         □ Activities □ Writing □ Courses & Grades □ Supplements
                         □ Recommenders & FERPA □ My Colleges
   - 请提供截图或可复制的文本（截图要清晰，字段值看得清）

2. 申请学校清单
   - ED / EA 学校：
   - RD 学校：
   （标化政策要逐校核对，所以学校清单一定要给全）

【强烈建议提供】没有这些，一半以上的硬校验只能标"无法核验"

3. 护照信息页（姓名 / 出生日期 / 国籍的核对基准）
4. 学校官方成绩单（GPA / 课程名 / 成绩的核对基准）
5. 标化成绩单：TOEFL / IELTS / SAT / ACT / AP（含各次考试日期）
6. 主文书 + 各校补充文书
7. CA 表单状态截图（勾选了 Recommenders & FERPA / My Colleges 时必给）：
   推荐人邀请与提交状态、FERPA 签署、counselor 指派、各校轮次 / 学院 / 必答 Questions

【可选】

8. 申请专业 Major（用于课程匹配、活动相关性检查）
9. 之前与顾问确认过的特殊背景说明（转学、家庭情况等）

补齐后发我，我会出一份审核报告：逐模块问题清单、跨模块一致性核对、
需要人工确认的事项清单，以及能否提交的结论。
```

---

## 为什么这么设计（对接人问起来时可以这样解释）

| 项目 | 不填会怎样 |
|---|---|
| **CA 填写内容** | 没有表就没有审核对象。至少要有一个板块。 |
| **目标校清单** | 标化政策、C&G 强制与否、Supplements 检查全部依赖学校清单。 |
| 护照 | 姓名 / 生日 / 国籍一致性核对失去基准，只能标"无法核验"。 |
| 成绩单 | GPA 原样填报、课程名 1:1 复刻这些硬校验全部降级。 |
| 标化成绩单 | Taken 次数核查（多日期拼分是高频错误）做不了。 |
| 文书 | 活动名一致性、文书提到的活动是否有体现这两项查不了。 |
| 推荐人 / My Colleges 状态截图 | R2–R6、M1–M3 全是表单状态核验，没有截图这两个板块只能标「未覆盖」。 |

---

## 收件后的动作

1. **逐项核对**，在心里打个勾。
2. **缺任一必填项 → 停下来，发上面那份清单。** 不要先做一部分再说。
   - **单校也算清单**：只申一所（或本次只审一所）不是缺件，按单校口径正常开工，在报告注明「本次仅覆盖 {{校名}}，其余目标校需另审」。真正缺件是**一所都没给**。
3. **申请季判定**：从 entry term / 提交时间戳判断。非当季（往季复盘、已提交材料）→ 按 `SEASON-2027.md` 的「历史季案例运行模式」切换取数规则，并在报告总览注明。
4. 分次提交是正常的：填到哪审到哪，报告里标注本次覆盖的板块。
5. 截图材料字段辨认不清的，列出来让顾问补文字值，不要猜。
