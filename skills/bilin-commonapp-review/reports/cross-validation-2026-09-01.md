## 二、B 角：工程审计结论

> 可以交付，但改完三处硬伤前不建议发给顾问。最大结构风险不是内容，是**"换季只改一个文件"这个承诺是假的**——季节参数同时活在 SEASON-2027.md / MODULE-CHECKLISTS.md（W1/W2/A1）/ SEVERITY.md，且文件名硬编码在 6 处引用中。明年换季的人改完一个文件，会留下一份**半新半旧、但能顺利跑完流程**的 skill：静默错误比报错危险。

**对账**：manifest 的 files / output_contract / decisions 与磁盘完全一致（无死链、无漏登记）；REPORT-TEMPLATE 5 节与 SKILL.md 输出契约对齐。

### B 角必改（4 条）

1. SEVERITY 与 MODULE-CHECKLISTS 两处定级打架（peer review 已降 E3b/S4，SEVERITY 未同步）→ 两个 agent 读不同文件会给不同等级
2. CHANGELOG 声称已修、文件没修（**与 A 角独立发现同一处**）
3. **换季路径不成立**：数值散落三处 + 文件名硬编码 6 处 + 正文硬编码 Harvard/MIT 等政策结论（明年会沿用 2026-08 的过期结论，与铁律 2 自相矛盾）
4. **死路由**：SKILL.md 指向"对应写作 skill"，仓库只有公众号写作 skill，无申请文书 skill；S4 给两个并列目标无优先级

### B 角建议改（5 条）

- consultant 缺反向排除（A/B 双向排除已闭合，但 A4/E3b/S4 三处往它路由、它不回指）

- 链 1 把 P4 列为常规核对点，但 P4 自认"通常拿不到"

### B 角路由压力测试

| 顾问原话 | 归属 | 会抖吗 |

| 帮我看看这个学生的申请材料能不能交了 | 应归 commonapp | **会**，consultant 更宽泛且无回指 |
| 把活动列表和主文书对一遍，有没有对不上的 | commonapp 为主 | **会**，双方 description 都含"活动列表+文书+一致性" |
