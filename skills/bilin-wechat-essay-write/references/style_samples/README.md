本目录存放比邻公众号过往爆款或风格代表作,作为 `bilin-wechat-essay-write` skill 在 Step 2 调性对齐时的语感参照。

> 05 / 06 / 07 是同一个 L 同学的系列三篇(云南 → 九年级签约 → 不听老师),可整组对照阅读,学"核心意象跨篇复用(锚)"和"每篇预告下一篇"的系列写法。其中 06、07 是顾问(Hui)红线审稿后的**定稿范本**——它们的价值不只在内容,更在 `samples_index.md` 里"重点学习"逐条点出的"初稿 → 定稿被改掉的地方",是编撰克制、开头锚定、意象纪律几条原则的活教材。

## 怎么用

skill 在 Step 2 不会盲读全部样本。先 Read 上一级目录的 `samples_index.md`,根据 Step 1 的 case 类型决定:

- 读哪 1-2 篇完整样本
- 哪几段是重点学习对象(开头模式 / 节奏 / 机构定位 / hook)

全部样本都读会过度占 context,也没必要。

## 维护

- 新增样本:用 `.md` 文件,文件名前缀 `06-` `07-` 累加,frontmatter 包含 title / source / created / description / tags
- 每次新增样本后,记得更新上一级 `samples_index.md`,加上新样本的维度索引(以及"重点学习",如果是定稿范本就写清初稿→定稿被改掉了什么)
- 业务调性变化时(比如公众号定位调整),需要清理一遍旧样本

## 注意事项

- 样本里如果有真实学生姓名、学校名、家庭信息,**必须先脱敏再放入**——这些文件会作为上下文进入 skill,谨慎处理
- 样本不要堆——5-7 篇有代表性的爆款比 30 篇齐全样本更有用
- 同一作者的多篇放进来,可以帮助 skill 识别该作者的个人语感
