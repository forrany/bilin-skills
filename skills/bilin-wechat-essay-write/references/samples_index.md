# 样本索引——按文风维度查找

这份文件是 7 篇比邻样本的"维度索引"——告诉 skill 在 Step 2 调性对齐时,"想看开头模式去哪、想看 hook 设计去哪、想看机构定位语言去哪",不用每次读完整篇也能快速定位。

完整样本在 `style_samples/` 目录下:

- `01-shan-cheng-math-boy.md` —— 山城里的数学少年:从家门口的空教堂到斯坦福
- `02-vanderbilt-ed-story.md` —— 申请季才签约、没夏校、没金奖——他是怎么 ED 上范德堡的
- `03-essay-and-ai.md` —— 比邻「分享会问答」系列:文书与 AI
- `04-cant-write-in-chinese.md` —— 比邻「分享会问答」系列:我家孩子根本中文都写不出来,怎么办?
- `05-l-tongxue-yunnan.md` —— 那个去云南观鸟的男孩,最后做了一个咖啡品牌(ED Rice / 机构自营项目展示样本)
- `06-l-tongxue-9th-grade-signing.md` —— 9 年级签约,会不会太早?(L 同学系列 · 早签买的是时间不是答案 / **编撰克制 + 意象纪律定稿范本**)
- `07-l-tongxue-not-listening.md` —— 我家孩子根本不听老师的话,机构能怎么办?(L 同学系列 · 方法论问答型 / **开头锚定标题场景 + 署名归属修正定稿范本**)

> **关于 06、07**:这两篇是 L 同学系列在顾问(Hui)红线审稿后的**定稿范本**,价值不只在内容,更在"初稿 → 定稿"之间被改掉的东西——它们是 skill 编撰克制、开头锚定、意象纪律几条原则的活教材。下面"重点学习"里逐条点出。

## 样本极简速览

### 01 · 空教堂(故事型 · 深度案例)

**核心 case**:H 同学,数学天才,homeschool 长大,主文书没写数学,写了家对面一座空教堂——录斯坦福。

**调性**:慢、有诗意、第三人称叙事、意象贯穿全文。

**结构**:前言 → 一座空教堂(意象引入) → 一个"不太好写"的学生 → 寻找"只有你才能讲的故事" → 空教堂——被忽略的宝藏 → 从意象到叙事 → 反直觉策略 → 那些让人记住的细节 → 凌晨三点的少年(意象回响收束)

**字数**:约 4500 字。

### 02 · 范德堡 G 同学(故事型 + 方法论)

**核心 case**:G 同学,申请季才签约、没夏校、没金奖、托福不强、6 个月并跑——主文书写书法 + 魔方 + 养老院老人,ED 录范德堡。

**调性**:互动型、思维游戏式、第一人称(我们)、反向预设。

**结构**:那天他走进办公室时(硬件清单) → 主文书一个反直觉选择 → 小文书又一次反直觉 → 活动描述也是文书 → 一篇好文书到底是什么 → 尾声(预告系列其他问题)

**字数**:约 4500 字。

### 03 · 文书与 AI(方法论 · 数据型)

**核心 case**:不是 case,是议题——文书能不能用 AI,讲政策、讲理由、给清单。

**调性**:紧、密度高、Eva 第一人称问答、大量数据政策引用。

**结构**:分享会一位妈妈打断 → 我那天怎么答的 → 三个理由(招生官能识别 + 大学政策 + 根本帮不到孩子) → 我们怎么处理这件事 → 给家长一份清单(能用 / 不能用) → 最后我想说 → 系列预告 → 官方链接

**字数**:约 4200 字。

### 04 · 不会写文书(故事型 + 方法论问答)

**核心 case**:多个 case——G 同学 + 数学男孩——讲"不会写"怎么办,核心方法论是"聊出来"。

**调性**:中速、抒情、Eva 第一人称问答 + 故事穿插。

**结构**:焦虑的多版本列举 → 分享会上一位理科生妈妈的提问 → 我那天怎么答的 → 为什么说"不需要会写" → G 同学是一个例子 → 那个数学男孩(回呼 01) → 我又补的一句话 → 给所有理科生家长的话 → 系列预告

**字数**:约 4500 字。

### 05 · L 同学云南(故事型 + 机构方法论 + 自营项目展示)

**核心 case**:L 同学,9 年级签约,10 升 11 暑假去云南百花岭(比邻自营项目),原题目观鸟,现场转向做咖啡品牌 Chillin Coffee,做了 2 年,ED 上 Rice 双专业(Business + Environmental Science)。

**调性**:慢、有诗意、第三人称叙事 + 关键节点切入机构口吻方法论段。

**结构**:前言四段画弧线(速干衣 → Rice ED)→ 分享会调查(80% 焦虑活动)→ 进入故事(行李/民宿/速干衣有点多余)→ 比邻定位段(自营项目说明)→ 第三天山路上那句话 → 那通电话 → 机构方法论段(我们没给他模板)→ 回深圳做品牌 → 反直觉细节(L 自己不喝咖啡)→ 185% 但只多卖几千块 → 2 年坚持 → Rice ED → 三句"是…是…是…"排比收束 → 系列预告 → 意象再回响 → 现场开放型 hook(那座山还在 / 等下一个孩子)

**字数**:约 2800 字。

**重点学习**:

- **比 4 篇老样本更紧凑**——同样故事型 + 方法论但只用 2800 字,密度更高
- **机构定位段做得最清晰**——前段就明确"比邻没有给标准答案,只给了起点",后段再用"我们没有给他模板"强化
- **"是…是…是…"三句排比收束**——把"好活动"的成因拆成机构 / 学生 / 顾问三个并列条件,可被复用为收束模板
- **现场开放型 hook**——把项目从"L 的故事"开放成"等下一个孩子",是 5 种 hook 思路里最适合"机构自营项目"类文章的形态

### 06 · L 同学九年级签约(故事型 + 方法论 · 系列中段)

**核心 case**:同一个 L 同学,这一篇回答"9 年级就签约会不会太早"。论点:早签买的不是"提前定死的路线",是一段够长、能允许试错和回头的**时间**;真正的锚是孩子自己在这段时间里撞出来的。

**调性**:中速、第一人称(Eva/我们)+ 第三人称叙事交织、克制。

**结构**:承接系列(云南的锚 + 商赛)→ 一位妈妈的提问 → 多版本焦虑 → 签约那天 L 其实"看不出能上 Rice" → 王辉给的两样东西(商科+环境辅线 / 竞赛可被验证)→ 这两年他打商赛试错 → 学生第一人称顿悟引语 → 种子两年后才发芽(锚回呼)→ 早签还买来"安定" → 签的是试错和回头的机会 → 早 ≠ 定型,是给时间 → 给 8/9 年级家长一个问题(给特定家长一句话型 hook)→ 系列预告(不听老师)

**字数**:约 2600 字。

**重点学习(初稿 → 定稿被改掉的地方,即编撰克制活教材)**:

- **删虚构身份细节**:初稿写"她孩子在读 8 年级",定稿删掉——身份性具体信息素材支持不住就别进正文(核心原则 8)。
- **一篇一个核心意象,收尾不另起炉灶**:初稿在结尾才冒出"跑道"这个新比喻,定稿全删,统一回贯穿全篇的"时间"+ 系列意象"锚"(DNA 9)。
- **收束句回到本文论证,不滑回泛卖点**:"签的是四年的陪伴"→"签的是试错的机会,和回头的机会"。
- **去市侩交易动词**:"签约买来的时间"多处改成"换来"。
- **关键顿悟用学生第一人称引语**:"他真正喜欢的……"(叙述)→「我真正喜欢的……」(引语)。
- **POV 一致**:删掉"我知道,这是一个更沉的问题"里的"我知道"。

### 07 · L 同学不听老师(方法论问答型 · 系列收尾)

**核心 case**:同一个 L 同学,回答"我家孩子根本不听老师的话,机构能怎么办"。论点:"不听话"和"有自己的想法"是一件事的两面,恰恰是招生官想要的;机构要做的不是把他掰听话,而是不定性他、在他撞出方向时放手、但不放判断的手。

**调性**:Eva 第一人称问答 + 第三人称案例,中速,克制。

**结构**:分享会上妈妈的提问(标题场景,第一拍)→ 同事王辉"自己孩子也不听"佐证(第二拍)+ 早解除羞耻("不听话不是家长的失败")→ 多版本焦虑 → 我那天怎么答的(反常识结论)→ 第一次不听:九年级商赛(不定性他)→ 最重要的一次不听:云南转咖啡(放手)→ L 一开始也抵触环境线(学生为导向)→ 放手 ≠ 撒手(机构的判断)→ 反面:要求"必须听话"的机构 → 回到王辉那句话 + 一位妈妈的原话 → 给家长换一种问法(给特定家长一句话型 hook,锚回呼)→ 系列预告(九年级签约)

**字数**:约 2500 字。

**重点学习(初稿 → 定稿被改掉的地方)**:

- **开头锚定标题场景**:初稿先讲同事王辉的私人故事、再引出分享会妈妈的提问;定稿反过来——标题那句提问(分享会妈妈)放第一拍,王辉降为第二拍佐证(见 `hook_patterns.md`"开头与 hook")。
- **早解除羞耻**:"不听话不是家长的失败,是这代孩子的常态"从结尾提到开头第二拍。
- **署名归属修正(不移花接木)**:初稿把一句家长原话安到叙述者 Eva 嘴里;定稿还原成"一位妈妈在分享会上说过一句话"(核心原则 5)。
- **真实同事隐私软化**:"做美本规划十几年"→"从事教育行业十几年",淡化可识别信息。
- **降夸张 + 加对冲**:"喘不上气"→"皱眉";"这孩子是被规划出来的"→"这孩子,大概率是被人替他做出来的"。
- **平行小标题 + 完成枚举**:"第一次「不听」…/ 最重要的一次「不听」…"做成平行;并补出"第三件事"让"做的三件事"枚举完整(注意:这是**正文里的内联枚举**,不是被禁止的"一、二、三"编号标题)。

### 维度 3 · 〔现场氛围注释〕

**主要出现在 Eva 第一人称问答型**(03、04、06、07):

- 03 第 29 行:"〔现场一时安静。我看到至少有一半家长抬起头来——他们都想听这个答案。〕"
- 04 第 43 行:"〔现场一时安静。我抬头看了看其他家长——发现至少有一半人在轻轻点头。〕"
- 04 第 141 行:"〔他在分享会上讲这句的时候、家长们都笑了。〕"
- 04 第 177 行:"〔他说得很随意——就像描述自己每天会看到的一棵树。〕"
- 06:"〔现场有几位家长跟着点头。这是一个比它听起来更沉的问题。〕"——注意定稿删掉了初稿的"我知道,"(读心式插话)
- 07:"〔这个问题,每年都要被问很多遍。〕"——比初稿更短、更克制

**用法**:Eva 视角下,把读者带回分享会现场。括号内是"现场氛围观察",1-2 句。**适合在重要对话之后立刻插入,渲染家长共鸣。注意别在注释里替读者下判断(读心式插话)。**

### 维度 5 · 机构定位语言(关键句)

**01 · 强调过程**:

- 第 50 行:"通过持续的提问和对话,帮助学生看到自己习以为常的经历中那些不寻常的部分"
- 第 81-82 行:"不是简单地"把故事写出来",而是帮助学生设计一个有呼吸感、有节奏、有层次的叙事结构"

**02 · 强调判断**:

- 第 82 行:"我们今天想讲的是一个不一样的 case—— **一个机构能实实在在帮上忙的 case**"
- 第 106 行:"这种全局性的文书策略规划,是比邻与学生合作中最核心的工作之一"

**03 · 强调立场**:

- 第 47 行:"我们是不允许用 AI 工具的"
- 第 183 行:"如果一家机构对 AI 的态度是含糊的——你应该警觉"

**04 · 强调方法论**:

- 第 53 行:"他就是和文书老师聊"
- 第 109 行:"外教在旁边,帮他把英文 **表达精确化** 、帮他把句式调整到位、帮他把结构铺好, **但灵魂始终是孩子的**"
- 第 219 行:"我们清楚——聊不清、文书就出不来"

**05 · 强调"现场"和"放手"**(机构定位最强的一篇):

- 第 30 段(比邻定位段):"这趟云南,是比邻给他规划的……比邻没有给他一个标准答案,只给了他一个起点"
- 第 51 段(关键方法论段):"我们没有给他一套「咖啡项目」的模板……把他放进一个真实的现场,然后在他自己撞出方向的那一刻,陪他做下去"
- 第 80-85 段("是…是…是…"三句排比收束)

**06 · 强调"早 = 给时间"和"放方向不放判断"**:

- "签约那天,我们的中方顾问王辉老师,没有给他一套「方案」。他给了两样东西"——方向假设 + 诚实预判
- "我们用的是一种发展的眼光:让他去试……等他自己长出想法的那一刻,我们再陪着他,把那件事做下去"
- 收束:"早签换来的……是一段够长的、能允许试错、能允许回头的时间。锚不是签下来的"

**07 · 强调"不定性 / 放手 / 不放判断"(三件事枚举)**:

- "我们做的第一件事,不是说服他,是不去定性他。"
- "我们做的第二件事——在他自己撞出方向的那一刻,放手。"
- "我们放的是「方向」的手……但我们没放「判断」的手——哪条路走得通、哪件事值得 all in,这是四年陪伴里我们一直在做的事。"——三件事枚举,可复用为"放手 ≠ 撒手"型方法论的收束骨架

**规律**:一篇文章必须有 1 个核心词或意象反复出现 8 次以上,承担所有论点的回响。**写之前先确定这个核心词,且整篇只用这一个核心意象,不要在收尾处另起炉灶(见 writing_guide DNA 9)。**

**额外观察**(05 样本):一篇文章可以同时有 1 个核心意象(速干衣,贯穿叙事)+ 1-2 个核心立场词(现场 / 真实,贯穿方法论)。意象做情感线,立场词做认知线。两条线缠绕推进。

## 一些通用提醒

**读样本不是为了照抄**,是为了内化"比邻是怎么说话的"。读完之后写自己的 case,但句式节奏要像。

**样本里没有的东西,不一定不能写**——但如果你想写的东西跟样本都不像,先问一下用户"这是不是比邻调性"。

**样本基本都不超过 4500 字,系列文章更短(2500-2800 字)**——比邻公众号文章不追求字数,追求"家长读完"。如果你的稿子超过 4500 字,认真考虑能不能砍。
