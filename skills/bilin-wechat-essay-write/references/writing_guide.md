# 比邻公众号写作指南

这份文件是 `bilin-wechat-essay-write` skill 的核心知识库。SKILL.md 的 Step 0 要求在正式起草前完整 Read 一遍。

内容分五块:

1. 比邻文风 12 条 DNA(从 5 篇样本提炼)
2. 4 种 case 类型 → 4 种开头模式
3. 机构定位语言库
4. AI 文风规避清单(必看)
5. 编撰标注的具体格式

**结尾 hook 设计单独成文,见 `hook_patterns.md`。** 这是 skill 的核心迭代点之一,需要独立维护。

## 一、比邻文风 12 条 DNA

这 12 条不是规则,是 4 篇公众号样本 + Hui 第六稿改稿里反复出现的写作 DNA。每写一段问自己一次:这段有没有违反其中一条。

**1. 短句多,单句成段是常态**

> 但他这一去,做出了一个完全不在原计划里的决定。
>
> 三年后,这个决定撑起了他整套申请档案。

不是为了花哨,是为了让家长在手机屏幕上读得下去。一段超过 3 行就要警惕。

**2. 空行频繁,呼吸感强**

每段之间空一行是默认。一屏文字大概 5-8 个分段比较合适。手机端阅读体验决定了空行密度。

**3. 破折号 `——` 是核心节奏标点**

替代逗号、分号、冒号。是表达"停顿 + 强调 + 转折"的复合标点。

> 那一刻——他穿在身上的速干衣,有点多余。

中文破折号(双连字符长度)在公众号渲染时节奏感比逗号好得多。

**4. 粗体打点,但克制**

关键句加粗,一段最多 1-2 处。**关键判断、反直觉结论、机构立场、家长会复制转发的金句**用粗体——其他句子保持素净。

**5. 第二人称对话感**

"您"、"各位家长"、"如果你家也是 X"——但不滥用。用对了让家长觉得文章是写给自己的,用多了变说教。

**6. 〔现场氛围注释〕**

样本 03、04 用了一种特殊括号注释:

> 〔现场一时安静。我抬头看了看其他家长——发现至少有一半人在轻轻点头。〕

这种"舞台说明"式的注释是比邻独创句式之一,把读者带回分享会现场。**适合"方法论问答型"文章**(模拟 Eva 第一人称视角)。

**7. 直接引用对话,粗体 + 引号**

学生原话、家长原话、Eva 老师原话——粗体加引号。这是比邻样本里最常见的句式之一。

> **「Eva 老师——他写这篇文书的时候、有没有用到 AI 工具?」**

**关键顿悟优先用学生第一人称引语。** 学生"想明白了什么"的那一刻,写成他自己的一句引号原话,比叙述者转述更有力。

> (反例 · 叙述)他真正喜欢的,不是做题、不是比赛,是做出真实影响力的事。
>
> (正例 · 引语)**「我真正喜欢的,不是做题,不是比赛,是做出真实影响力的事。」**

(依据:05 九年级签约 V2 把这句顿悟从叙述改成了学生第一人称引语。)

**8. 编号列表(01 02 03)**

样本 02 用了 7 处编号列表(申请档案、活动列表、报告会写什么)。**适合需要清单感的内容**——硬件条件、活动列表、政策清单。中文用 "01 02 03" 比 "1. 2. 3." 更比邻。

**9. 核心概念反复出现**

样本 04 的 **"聊出来"** 出现了 12+ 次。样本 01 的 **"空教堂"** 贯穿全文。样本 03 的 **"AI"** 反复打点。**一篇好文章必须有一个反复出现的核心词或意象**——这个词承担所有论点的回响。

**一篇一个核心意象,收尾不另起炉灶。** 不要在文章最后三分之一引入一个全新的控制性比喻——它会跟前面立住的那个互相稀释。系列文章里,复用已经立住的意象(如 L 同学系列的「锚」),不要每篇换一个新比喻。

> 依据:05 九年级签约初稿在结尾才冒出「跑道」这个新比喻,V2 把它全部删掉、统一回贯穿全篇的「时间」+ 系列核心意象「锚」。

**10. 不元叙事**

**不**说"接下来我要讲什么"、"这一段最关键的是什么"、"我们今天的主题是什么"。让结构自己跑,让读者在读到时自然意识到"这一段在讲什么"。

样本里几乎找不到"接下来"、"下面我们看"、"先讲 X 再讲 Y"这种话。

**11. "真实"是核心立场词**

样本里"真实"反复出现:

- "在真实的商业世界里,真实地试过、也真实地碰过壁"
- "孩子在真实的现场里,自己撞出来、又真的做下去的那个"
- "AI 写出来的东西缺少真实的个人反思"

"真实"是比邻区别于"包装机构"的立场词。**不是凑字数的修饰,是定位标签。**

**12. 让事实说话,让读者自己得出结论**

样本 01 结尾不说"H 同学是个了不起的孩子",只说"凌晨三点,一个十七岁的男孩坐在电脑前"——读者自己读出"了不起"。

样本 02 不说"我们做对了 X",只说"主文书里最核心的三项,是书法、魔方、养老院里的老人"——读者自己读出"反直觉的策略"。

**少分析、多事实——让家长自己得出结论。**

## 二、4 种 case 类型 → 4 种开头模式

不同类型 case 的开头模式完全不同。**参照下面的对应表选,但不照搬。**

### 模式 A · 故事型深度案例

**典型样本**:01 空教堂

**结构**:前言段(2-3 句画弧线)+ 一段日常画面(意象浮现)

**示例骨架**:

```
**前 言**

从 [一个具体场景] 到 [一个结果],一位 [学生标签],用 [一段日常],
[做了一件什么事]。

这不仅是 [表层],更是 [深层]。

**[一个意象]**

[直接进入意象的画面]。

[意象的现状描述]。

[学生跟这个意象的关系——一个日常细节]。

这个意象后来成了 [文章核心议题]——但在最开始,
没有人意识到它的价值。
```

**关键**:前言段必须包含三件事——具体的画面、明确的结果、隐约的悬念。

### 模式 B · 故事型 + 方法论

**典型样本**:02 范德堡 G 同学、04 不会写文书

**结构**:分享会场景(把读者带到现场)+ 硬件清单或一个具体问题

**示例骨架**:

```
前几天我们办了一场围桌分享会——[具体描述,如 "10 位家长围坐三边"]——
听今年 ED 上 [学校] 的 [学生标签] 讲他自己的申请故事。

这篇文章是那场分享会之后我们自己的复盘——讲一个学生、
讲我们和他一起走过的 [时间]、讲 [某个具体的事]。

希望对各位家长有一点启发。

**一、那天他走进办公室的时候**

[学生标签] 是我们 [届数] 的学生里 [一个反常态的标签]。

他是个挺特别的孩子。但如果只看他签约那天的「申请档案」——

01　[硬件项 1]
02　[硬件项 2]
03　[硬件项 3]
...
```

**关键**:用"硬件清单"或"思维游戏"(让家长在心里先选,再揭晓答案)制造反差。

### 模式 C · 方法论问答型

**典型样本**:03 文书与 AI、04 不会写文书、07 不听老师

**结构**:多版本焦虑列举 + 分享会上某位家长的提问 + Eva 第一人称回答

**示例骨架**:

```
做了 [N] 年文书顾问,每年我都会被家长问到一个同样的问题。

它有不同的版本:

**「[版本 1]」**

**「[版本 2]」**

**「[版本 3]」**

归结起来都是同一句话:

**「[核心焦虑]」**

上周我们办了一场围桌分享会——讲到一半的时候,一位妈妈举手,
她从开场就一直安静地坐着、做笔记、没说过话。

举手之后她停顿了几秒,像是在斟酌怎么开口,
然后说出了那一句让我印象很深的话。

**「[核心问题原话]」**

〔现场一时安静。〕

这就是这一篇文章想讲的事。
```

**关键**:多版本焦虑让家长在心里自动对号入座。Eva 第一人称视角让回答有权威感。

**注意(标题场景优先)**:如果标题本身就是那句家长提问,开头第一拍应当直接落在那个提问/那个场景上;类比性的旁支轶事(同事的私人故事、另一个案例)放第二拍当佐证,不要顶替标题场景占开头。详见 `hook_patterns.md` 的"开头与 hook:先锚定标题场景"。

### 模式 D · 数据型 / 政策型

**典型样本**:03 文书与 AI 的后半部分

**结构**:一个明确的判断 + 一个反直觉的事实/政策/数据

**示例骨架**:

```
上周分享会上,一位妈妈问出了今年家长最想问的问题:

**「[核心问题]?」**

我想认真讲清楚—— **什么 X 、什么 Y、为什么** 。

[一段简短的背景铺垫]

**我那天是怎么答的**

我几乎是立刻回答的:

**[核心立场,粗体]**

[追问 + 立场强化]

在我展开讲为什么之前,我想先承认一件事:

**[一个让家长意外的承认/前提,缓和立场]**

[展开三个/四个理由,用编号 01 02 03 + 数据/政策/研究证据]
```

**关键**:开篇立场必须明确粗体打出来,然后用数据/政策/研究层层支撑。**承认"对立面的合理性"会让立场更有说服力。**

## 三、机构定位语言库

比邻在文中的定位是 **"现场提供者 + 关键判断者"**,不是"包装者"也不是"全能保姆"。

### 推荐用的句式

**关于角色定位**:

- "我们没有给他一套 [X],我们做的是一件事:把他放进 [Y]"
- "我们没有给他 [标准答案],只给了他 [起点]"
- "我们能做的——是在 4 年陪伴里,帮孩子判断哪些事值得做、哪些不值得"
- "比邻在 [地点],从来不是只给学生一个题目"

**关于过程**:

- "我们的中方顾问 / 外教 / 文书老师 / 文书委员会"
- "我们的判断标准是 X"
- "[一个具体动作] 是我们的 [角色] 做的;但 [灵魂动作] 是孩子自己的"

**关于对比立场**:

- "如果一家机构对 [X] 的态度是含糊的——你应该警觉"
- "我们和很多机构不一样的是——我们 [具体差异点]"

**关于真实**:

- "这是这个项目最真实的地方——它不是一个为了申请凹出来的「漂亮成果」"
- "孩子在真实的现场里,自己撞出来、又真的做下去的那个"

### 避免的句式

**不要写**:

- "比邻是一家专业的留学机构"(自我介绍式,土)
- "我们拥有 14 年经验"(资历堆砌,无说服力)
- "我们成功送出了多少学生"(数字堆砌)
- "选择比邻就是选择 [漂亮的承诺]"(直接卖签约)
- "我们承诺帮你拿到 [结果]"(承诺感太重,反而显得不专业)
- **泛卖点收束**:"四年的陪伴"、"学生为导向不是一句口号"这类通用中介话术——收束句要回到**这篇文章自己的论证**(例:把"签的是四年的陪伴"改成"签的是试错的机会,和回头的机会"),不要在落点处滑回 boilerplate。
- **市侩交易动词**:"买来 X"这类把服务说成"购买结果"的措辞——用"换来"等弱化交易感的词。(依据:05 把"9 年级签约买来的时间"全部改成"换来"。)

**不要让"我们"出现在每一段**——出现频率太高会变成机构自夸。**关键节点出现,其他地方让事实自己说话。**

### 机构方法论段的处理

**允许并鼓励**:在合适的节点(通常是文章中段、转折之后、或结尾收束)用"我们"以机构口吻直接表达方法论判断。

**示例(Hui 第六稿)**:

> 我们没有给他一套「咖啡项目」的模板,也没有让他去交一份「咖啡报告」。
> 我们做的是一件事:
> 把他放进一个真实的现场,然后在他自己撞出方向的那一刻,陪他做下去。

**这种段落是允许并鼓励的——不需要在编撰标注里列出**(它是机构主动表达的立场,不是对学生行为的虚构)。

## 四、AI 文风规避清单(必看)

比邻读者对 AI 文风极其敏感——读到 AI 词的瞬间就关页面。下面是写稿时**绝对不要出现**的词和句式。

### 不要用的词

- "在那一刻"、"那一瞬"、"恍若隔世"——过度文学化
- "勾子"、"钩子"——网感词,不出现在比邻文章
- "本质上"、"其实"、"真正的"——AI 的总结口头禅
- "不仅 X,更是 Y"——AI 模板句式,谨慎使用
- "让我们一起来 [动作]"——AI 互动废话
- "在这个 [场景] 中"——废话起句
- "众所周知"、"毋庸置疑"——空洞修辞
- "值得我们深思"、"引人深思"——AI 总结废话

### 不要用的句式

- "首先 X,其次 Y,最后 Z"——AI 三段论
- "X 不是 A,而是 B;X 不是 C,而是 D"——AI 排比滥用
- "在 X 的过程中,我们看到了 Y"——AI 总结句
- "这告诉我们 [一个抽象道理]"——抽象升华

### 不要做的事

- **不要总结自己刚说的话**——AI 喜欢每段末尾加一句"也就是说……"
- **不要预告下一段**——AI 喜欢"接下来我会讲……"
- **不要给段落起"一、二、三"这种编号标题**(Hui 第六稿删除了所有这种标题,改用空行 + 破折号自然分段)
- **不要在结尾说"总而言之"**——AI 总结惯性
- **不要为了文学性而堆砌形容词**——比邻文风克制
- **对第三方的负面推断要加对冲**——写其他机构、别人家孩子时用"大概率",不要写成确凿断言。(依据:06"这孩子是被规划出来的"→"这孩子,大概率是被人替他做出来的"。)
- **夸张体感词降级,花哨动词换平实**——如"喘不上气"→"皱眉"、"咂摸出来"→"想明白"。
- **POV 一致,删读心式插话**——叙述者别替读者下判断,如"我知道,这是一个更沉的问题"里的"我知道"可删;第三人称提问就别滑回"我"。
- **不强加人为紧迫**——如"今晚你可以问他"的"今晚",除非确有时效,否则改"你可以做的,是……"。

### 自检方法

写完一段读一遍,问:

- 这段有 AI 词吗?(查上面清单)
- 这段是事实还是评论?(评论越少越好)
- 这段是机构判断、学生事实、还是我自己脑补?(脑补的要么删要么进编撰标注)
- 这段去掉会怎样?(如果删掉文章还成立,就删)

## 五、编撰标注的具体格式

**仅当 Step 1 用户勾选"编撰标注清单"时输出。**

格式如下,直接附在正文末尾:

```markdown
---

## 编撰说明(供顾问审稿核实)

以下是我在素材基础上做的补充 / 润色 / 演绎,请逐条核实。
机构方法论段不在此列(那是允许的)。

### 画面描写

- 第 [N] 段:"[原句]" —— 原素材只说 [X],我补了 [Y]
- ...

### 动作 / 反应

- 第 [N] 段:"[原句]" —— 素材里没有这个动作,是我加的反应词
- ...

### 心理活动

- 第 [N] 段:"[原句]" —— 素材里没有这个心理,是我推演的
- ...

### 对话内容

- 第 [N] 段:"[原句]" —— 这句对话不在逐字稿原话里,我基于 [X] 推演
- ...

### 时间 / 地点 / 数字具体化

- "三户咖啡农" —— 素材说"另外几户",我具体化为三户
- "一个多小时" —— 素材说"很久",我具体化
- ...

### hook 设计来源

- 开头:[何种模式,呼应了什么]
- 结尾:[何种思路,跟开头如何呼应]
```

**目标**:让顾问审稿时一眼能看到要核实什么。**不是限制创作,是让创作过程对顾问透明。**

**但请记住核心原则 8**:编撰说明是兜底透明化,不是编造许可。身份性具体信息(年级、职业、年限、谁说的话、场景归属)优先在正文阶段就用模糊、忠于素材的写法,不要靠这份标注来合理化正文里的虚构精确设定。

---

## 写在最后

这份指南不是规则手册,是参考路径。比邻每一篇好文章都是顾问对 case 真实判断 + 这些文风 DNA 的结合产物。

**当 case 的真实判断 vs 这份指南的某条 DNA 发生冲突时,永远以顾问的判断为准。**

skill 是辅助,顾问的判断是灵魂。
