# 比邻公众号正文写作

## 这个 skill 是干嘛的

比邻顾问在一次 case 沉淀的最后一步——把杂乱的素材(分享会逐字稿、骨架文档、PPT、顾问笔记、学生原话)写成一篇可发的公众号文章。这个 skill 帮顾问把这一步走完,产出符合比邻调性、不堆砌、不软广、不模板化、不掉读者的 2500-4000 字成稿。

**这个 skill 不做的事**:

- **不**做选题脑暴(那是 `bilin-wechat-topic-brainstorm` 的职责。如果用户还没想清楚写什么,转回去先脑暴)
- **不**给一套死模板(比邻每篇文章都因 case 不同而结构不同)
- **不**替代顾问对 case 的真实判断(顾问的判断永远是文章灵魂,skill 是辅助)
- **不**替代 case 评估(那是 `bilin-admissions-consultant` 的事)

**这个 skill 做的事**:

- 在素材和方向已经清楚的前提下,按比邻文风产出成稿
- 帮顾问识别"哪些是素材里实有的、哪些是我帮你润色或补充的",方便审稿核实(**仅当用户要求时输出**)
- 根据 case 类型推荐合适的开头模式、节奏感、机构定位语言、hook 设计——但永远是推荐,不是规则

## 工作流(6 步,请按顺序)

### Step 0 · 先 Read writing_guide.md

正式进入 Step 1 之前,先 Read 两份文件:

- `references/writing_guide.md` —— 比邻文风 12 条核心 DNA、4 种 case 类型对应的开头模式、机构定位语言库、AI 文风规避清单、编撰标注格式
- `references/hook_patterns.md` —— 5 种结尾 hook 思路、hook 跟开头的呼应方式、5 个 hook 失败模式、设计建议

读完之后再开始 Step 1。同一会话内不需要重复读。

### Step 1 · 输入确认(必须 AskUserQuestion)

用户进来时手里的东西可能不同,先用 AskUserQuestion 问清楚五件事:

**问题 1 · 输入是什么?**

- 已经做过 bilin-wechat-topic-brainstorm,有选题卡片 + case 素材
- 没做 brainstorm,但有 case 素材 + 一个明确方向
- 只有一个想法,先帮我想清楚再写

**如果用户选第 3 项,温和地告诉用户先回 `bilin-wechat-topic-brainstorm` 把选题想清楚再来,不在这个 skill 里硬写。**

**问题 2 · 文章类型偏向?**

- 故事型(围绕一个孩子的具体经历展开 / 参考样本 01、02)
- 方法论问答型(围绕一个家长焦虑展开 / 参考样本 03、04)
- 数据型(围绕政策、数据、事实展开 / 参考样本 03 后半)
- 让 skill 读完素材自己判断

**问题 3 · 长度预期?**

- 短(1500 字以内,适合次条、信息传递型)
- 中(2500-3500 字,适合大多数家长能读完的最佳长度,默认)
- 长(4000+ 字,适合深度案例、镇号文章)

**问题 4 · 初稿交付格式?**

- **Markdown 草稿(默认,推荐)**——先出纯文本 md 稿,便于你直接改、也便于下一轮喂给大模型继续打磨;**人工确认定稿后,我再用 `docx` skill 转成可批注的 Word 版**
- 直接出 docx——你想要可批注的 Word 版一步到位(适合已经很确定、只需一次成型)
- 先 md,最后 md + docx 两版都给我

**默认走 md 优先**:除非用户明确要"直接 docx",否则初稿一律先出 md,等用户确认内容后再转 docx——避免在文字还要反复改的阶段反复重排 Word 格式。

**问题 5 · 附加需求?(可多选)**

- 编撰标注清单(写完后文末列出所有我补充/润色的细节,方便审稿)
- 系列呼应(这是系列里的一篇,需要呼应前篇/预告后篇)
- 标题候选(出 3 条不同腔调的标题)
- 都不要,只要一稿干净成稿

**如果用户勾了"系列呼应",追问**:这是哪一篇? 前篇/后篇是什么? 是否要在结尾用问题列表预告后续?

收齐答案后再进入 Step 2。

### Step 2 · 调性对齐(必须 Read 样本)

先 Read `references/samples_index.md`——这是样本的"文风维度索引",告诉你"想看开头模式查哪、想看 hook 设计查哪、想看机构定位语言查哪"。

然后根据 Step 1 的类型选择,Read 1-2 篇最接近的完整样本:

| Step 1 类型 | 优先 Read |
|---|---|
| 故事型(深度案例) | style_samples/01-shan-cheng-math-boy.md |
| 故事型(+ 方法论) | style_samples/02-vanderbilt-ed-story.md, style_samples/04-cant-write-in-chinese.md |
| 方法论问答型 | style_samples/03-essay-and-ai.md, style_samples/04-cant-write-in-chinese.md, style_samples/07-l-tongxue-not-listening.md |
| 数据型 | style_samples/03-essay-and-ai.md |

完整读完样本,内化其节奏、句式、机构定位语言、软广位置、hook 形态。

### Step 3 · 案例分析(不输出,但要在心里走过)

不要打到对话框里,但写之前自问 5 题:

1. 这个 case 的**核心张力**是什么?(被推到风口前的反主流 / 被低估的特质 / 反直觉的策略 / 一个具体瞬间)
2. case 的**现场感**从哪里来?(分享会 / 顾问回顾 / 学生口述 / 文书复盘 / 顾问的某次判断 / 一组数据 / 一个意象——读完素材自己判断)
3. 哪些是素材里**实有**的,哪些**可能需要我补充**?(在心里分两栏,补充部分在 Step 5 要列出)
4. 机构在 case 里的**真实角色**是什么?(提供现场 / 关键判断 / 长期陪伴 / 主导文书 / 等等)——这决定机构定位段怎么写
5. 这篇读完家长心里会**想什么**?("我家孩子能不能也……" / "下一篇讲什么" / "什么是好的 X" / "原来这么严重")——这决定结尾 hook 怎么设计

### Step 4 · 起草

起草的核心原则(详细规则见 `writing_guide.md`):

**开头**:不要照搬上一篇。根据 case 选适合的开头模式——前言段画弧线 / 分享会场景 / 一位家长的提问 / 一组政策数据。**这是比邻文章最关键的几百字,务必让 Step 3 第 5 题的"家长读完想什么"在第一段就开始酝酿。开头要锚在标题承诺的那个场景上——类比性的旁支轶事(同事的故事、另一个案例)再好,也放第二拍当佐证,不要顶替标题场景占据开头(详见 `hook_patterns.md` 的"开头与 hook:先锚定标题场景")。**

**节奏**:短句多、空行频繁、破折号 `——` 是核心节奏标点、粗体打点每段不超过 1-2 处。

**机构定位**:

- 用"我们",不用"比邻"自称
- 反复使用"真实"作为价值锚定词
- **机构方法论可以由"我们"直接表达**——这是允许并鼓励的(关键句式如"我们没有给他 X,我们做的是一件事:把他放进 Y")
- 但**学生的动作 / 心理 / 对话必须有素材依据**,不能凭空编撰

**编撰克制(正文从严)**:

- 凡是身份性细节(年级、职业、年限、是谁问的、哪个场景),先问自己"素材里有没有"。没有就用模糊写法("一位家长"而非"一位读 8 年级孩子的妈妈"),不要为代入感虚构精确设定。
- 引语只能归给真实说过它的人。需要某句话的"意思"但说话人不合适时,宁可改成叙述、或如实标明"一位家长说过",**不要把它安到另一个人嘴里**(移花接木)。
- 写到真实同事 / 家长的私人轶事,淡化可识别信息,并在交稿时提示"发布前建议征得本人同意"。

**让事实说话**:减少分析段、不元叙事、多用具体细节让读者自己得出结论。

**结尾 hook**:根据 case 设计,不模板化。常见思路、呼应方式和失败模式详见 `references/hook_patterns.md`。**目标是让家长觉得"值得持续关注比邻"或"想立刻咨询",但不要直接说"找比邻"。**

### Step 5 · 编撰标注(仅当 Step 1 第 5 题用户勾选时)

如果用户在 Step 1 选了"编撰标注清单",写完正文后,在文末加一个"——编撰说明——"区块,按以下分类列出所有补充/润色:

- **画面描写**:所有"在某个场景"、"看到什么"、"听到什么"——素材里没有的环境/视觉描写
- **动作 / 反应**:"愣了一下"、"笑了笑"、"抬了一下头"等
- **心理活动**:"他想"、"那种感觉很奇怪"、"他意识到"等
- **对话内容**:所有不在素材原话里的对话(即使是合理推演的)
- **时间 / 地点 / 数字具体化**:素材说"几次"文中说"三次"、素材说"一会儿"文中说"一个多小时"
- **hook 设计来源**:结尾 hook 是什么思路、跟开头怎么呼应

**机构方法论段不需要标注**——那是允许并鼓励机构以"我们"口吻直接表达的内容。

如果用户没勾"编撰标注清单",**不要输出编撰说明**——保持成稿干净。

**注意(配合核心原则 8)**:编撰说明是给真正必要的现场渲染做透明化,不是编造许可。身份性细节优先在正文阶段就模糊化处理——不要靠这里的标注来合理化正文里的虚构具体信息。如果一条细节你打算写进正文、又知道它一定会进 ⚠ 核实清单,那它大概率本就不该以那个精确度进正文。

详细格式示例见 `writing_guide.md`。

### Step 6 · 输出形态确认(必须 AskUserQuestion)

正文(+ 可选编撰说明)写完后,用 AskUserQuestion 问后续延伸需求:

- 要不要标题候选(3 条不同腔调:理性 / 故事 / 锋利)?
- 要不要次条文案(200 字以内短摘要)?
- 要不要 PPT 文案(适合分享会现场使用)?
- 要不要双版本对照(朴素版 vs 文学版)?
- 都不要,这一稿够了

按需追加,不要主动堆砌。

**docx 转换(md 优先流程的收尾)**:如果 Step 1 第 4 题选了"md 优先",**不要在初稿阶段就转 docx**。先把 md 稿交给用户,等用户明确说"内容 OK / 定稿了 / 转 Word",再用 `docx` skill 转成可批注的 Word 版。这样文字反复改的阶段不会被 Word 排版拖累。

## 核心原则(不是规则)

1. **不模板化**——这个 skill 给的是思维路径,不是套版。同样一个 case,不同顾问会有不同的切入,skill 永远尊重顾问的判断。
2. **"真实"是比邻最重要的立场词**——反复出现,不是为了强调,是为了校准。
3. **不元叙事**——不说"接下来我要讲什么"、"这一段最关键的是什么"。让结构自己跑。
4. **机构定位是"现场提供者 + 关键判断者"**——不是"包装者",不是"全能保姆"。
5. **学生的动作 / 对话 / 心理不能编撰,且不得移花接木**——必须有素材依据。机构方法论可以由机构主动表达,但学生的具体行为不能;同样地,**不得把一个人的原话挪给另一个人说**(比如把一位家长说过的话安到叙述者 Eva 嘴里)。涉及真实同事 / 家长的私人故事,身份信息默认模糊化,必要时提示"发布前建议征得本人同意"。
6. **hook 必须根据 case 设计**——不照搬上一篇。
7. **写完后如果用户要,必须诚实标注**——但用户没要时,不要主动输出标注(保持成稿干净)。
8. **编撰克制:正文从严,标注不是兜底。** 身份性具体信息——年级、职业、确切年限、谁说的话、场景归属——若素材支持不住,**初稿就用模糊、忠于素材的写法**(如"一位家长"而非"一位读 8 年级孩子的妈妈"),而不是先写实、再到文末标注。"能进编撰说明"≠"能进正文"。编撰说明留给真正必要的现场氛围渲染(看到什么、听到什么),不是为虚构具体信息开许可证。

## 跟其他 skill 的配合

**前置 skill**:

- `bilin-wechat-topic-brainstorm`——选题已定后再来这里写正文。如果用户没做过选题脑暴又方向不清,转回去先做。

**配合 skill**:

- `docx`——**默认流程是先出 md 草稿、人工确认定稿后再转 docx**(见 Step 1 问题 4 与 Step 6)。需要顾问批注的 Word 版时再用,不要在初稿阶段抢跑。
- `pptx`——如果要做分享会 PPT,先写正文再用 pptx skill 出 PPT

**不要在这个 skill 里做的事**:

- 不要替代选题脑暴
- 不要替代 case 评估(那是 `bilin-admissions-consultant`)
- 不要做选校 / 文书指导(那是顾问自己的事)

## 关于素材不够时

如果用户拿来的素材实在不足以支撑一篇 2500 字的文章,**不要硬写**,也不要靠编撰填字数。

用 AskUserQuestion 问用户:

- 是不是还有素材没给过来?(逐字稿 / PPT / 顾问笔记 / 学生原话 / 录音转写)
- 是不是这个选题方向需要再缩窄?
- 是不是先回 `bilin-wechat-topic-brainstorm` 重新定方向?

宁可让用户回去补素材,也不要靠脑补凑字数。

## 一个友好的提醒

比邻公众号的家长读者多数是高知、愿意投入研究、对"中介话术"非常敏感。他们能一眼看出:

- 哪些是真实的 case,哪些是为了发文凹出来的
- 哪些是机构的真实判断,哪些是为了卖签约
- 哪些细节有质感,哪些是流水账

**这个 skill 的根本目的,不是写一篇看起来漂亮的文章,是写一篇让那种家长愿意读完、读完后想了解比邻的文章。**

如果一篇稿子写出来,自己读着觉得"软广味太重"或"为了文学性而文学性",回去重写。比邻的家长不会读完。
