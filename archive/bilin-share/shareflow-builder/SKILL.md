# Shareflow Builder

用于把已选中的录取 case 生成完整线下分享会内容。

这个 Skill 必须按三层走：探索层 → 方向确认层 → 成稿层。三层的输出物形态不同，强制分离，避免一步到位带来的方向锁死和创造力收缩。

## 输入

需要一个已选中的学生 case。材料可以逐步补齐：

- 学生基础档案。
- 录取结果。
- 活动列表。
- 主文书、小文书、活动描述。
- 学生采访记录。
- 顾问复盘。
- 可用于现场的截图、文书片段、handout 或 PPT 材料。

## 工作流程

1. 整理已有材料和缺口。
2. 做可公开性分级：线下可用、公众号可用、仅内部参考、待公开确认项。
3. 走 framing-tools 的探索层启动前自检。
4. **探索层**：发散候选方向，输出角度卡片。
5. **方向确认层**：基于卡片提供组合方向 + 收敛性问题，等用户挑选 / 合并 / 否决。
6. 走 framing-tools 的方向确认层启动前自检。
7. **骨架层**：基于确认方向输出 12 字段方向骨架。
8. 走 framing-tools 的骨架层启动前自检。
9. 等用户确认或修改骨架。
10. **成稿层**：方向骨架确认后，生成完整分享会内容。
11. 走 framing-tools 的成稿层启动前自检。
12. **成稿 review**：启动 shareflow-review skill，对成稿做系统 review。
    - review agent 读取成稿 + 方向骨架，按 review-checklist 逐项检查。
    - 输出优先级分级的 review 报告（P0/P1/P2）。
    - 用户确认修改范围后，逐条修改成稿。
    - 修改完成后交付最终成稿。

## 探索层

目的是**显性化候选方向 + 让淘汰过程可见**。

产出物是**角度卡片**，不是骨架字段。每张卡片对应一个可能的故事主轴，含：

- 一句话主轴。
- 击中家长（按信念维度切，避免按焦虑维度切）。
- 故事发动机（这条线为什么独特）。
- 潜在反转（如果做大会变成什么样的现场推演）。
- 风险与归因纯度。

数量原则：

- 5-7 张主候选卡 + 1-2 张"对照卡"。对照卡明确标注"建议淘汰"和原因，让淘汰过程可见。
- 卡片之间可以互斥、可以叠加。叠加和互斥关系要在卡片后单独说明。
- 不要在探索层就替用户选好——把判断空间留给方向确认层。

探索层结束时不要直接进骨架，必须先走方向确认层。

## 方向确认层

基于探索层的卡片做收敛。产出物有两种：

- **组合方向**：把卡片组合成 1-3 个候选完整方向（每个方向通常由 2-3 张卡片叠加构成）。
- **收敛性问题**：3-5 个有判断含量的问题，让用户做选择。问题不是"你想要哪个方向"，而是"你这场分享会更想打动哪类家长 / 你愿不愿意暴露 X 这段材料 / 这个反转会不会得罪到场家长"这种能反向决定方向的问题。

收敛性问题的设计原则：

- 按信念维度切目标家长画像，不按焦虑维度切。
- 警觉"A vs B"的简化二元——如果你的主轴框架掉进二元，机构的卖点常常正好被埋在第三个位置。
- 反向画像必须给（这场分享会**不**为谁开），否则画像不收敛。

多骨架触发条件：

- case 同时存在多个互斥但都成立的故事发动机。
- 目标家长画像分裂明显，单一画像无法同时承载。
- 否则默认出 1 个骨架，避免重复劳动。

## 骨架层

确认方向后输出方向骨架。骨架必须包含：

- 核心主轴（含主标语 / **开场钩子类型选择** / 精神底色三件事）。
  - **开场钩子不是默认"去光环化"**——必须根据学生实际 profile 的张力类型选择钩子。常见钩子类型：
    - **去光环化钩子**：profile 看起来弱（标化低 / 排名差 / 活动少），钩子是"这些材料你敢交吗"。
    - **外部权威否决钩子**：profile 看起来强，但被外部权威（counselor / 竞赛评委 / 梦校拒信）否定，钩子是"为什么一个看起来什么都有的孩子会被判死刑"。
    - **认知错位钩子**：家长以为的优势其实是劣势（或反过来），钩子是"你以为的好材料，恰好是招生官跳过的材料"。
    - 钩子类型由 case 的实际张力决定，不要默认套用任何一种。
  - **开场钩子与散场疑虑必须形成闭环**：钩子提出的张力，散场疑虑要收回来，并暗示"想知道答案，我们后面可以聊"的转化信号。骨架设计阶段必须同时确定钩子和疑虑，不允许分开独立设计。
- 目标家长画像（含主画像 / 细分层 / 反向画像）。
- 故事发动机。
- **现场基线认知清单**：家长入场前已经知道的事实（录取学校 / 学生身份维度 / 邀请函 / 海报 / 上下文必然透露的信息）。反转只能建在他们不知道的部分。
- **认知反转**：单 case 默认 1 次结构性反转，三拍结构（家长眼 → 招生官眼 → 解析机构判断逻辑）。例外是反转对象 / 层次有明显差异时（不同 artifact / 不同维度），可多段。
  - **选校段 mini 推演**：如果选校决策中存在明显的"家长直觉 vs 数据判断"张力（如 test-optional 但仍 ED 名校、冷门专业但选了大校），可在选校段增加一次 mini 推演（2-3 分钟），让全场有两轮"直觉 vs 专业判断"的对比体验。mini 推演不占独立段落，嵌入选校解析中。
- **反转素材可行性核查**：每个反转用到的对照样本 / 揭晓素材 / 现场展示物，必须显式标注是否在比邻可控范围。外部学生 / 同校同学 / 第三方的材料默认拿不到，只能口述提及，不能做成可视化展示物。
- 互动机制设计。
- 机构价值落点（落到方法论 / 团队 / 流程，不落到单个顾问）。
  - **顾问判断过程显形化**：在反转的第三拍或关键解析段落中，顾问应分享自己面对这个 case 时的真实判断过程——"我第一反应是 X，但读完 / 想清楚之后改了判断为 Y，原因是 Z"。这不是讲故事，是让家长亲眼看到"专业判断"长什么样，比抽象说"我们有方法论"有效 10 倍。每个 case 至少要有 1 个这样的判断瞬间。
- **学生出场方式**：不默认开场出现。如有推演环节，学生应在推演揭晓时立即出场（楚昊场约第 17 分钟）；如无推演环节，学生应在开场 10 分钟内出场。
- **学生讲述形式**：默认 Q&A 引导式（顾问问 5–7 个结构化问题，学生每段回答 2–3 分钟）。禁止让学生做 ≥ 5 分钟连续独白。
- **主持人、顾问、学生角色分配**：必须显式列出三方时长占比。学生 Q&A 答题时长应不低于顾问的"独白式输出"（推演主持 + 第三拍解析 + 收尾兜回，不含 Q&A 引导和接住）。参照楚昊场比例：学生 30–35%、顾问总时长 50–55%、主持人 8–12%。顾问总数默认 1 位（必要时最多 2 位）。
- 补采材料（含 Q&A 问题清单 + 学生原话对齐）。
- 可公开性边界（含线下可用 / 降级处理 / 内部参考 / 公众号降级线四档）。
- 整体格调（包括禁用词列表 / 学生本人语调保留 / PPT 视觉风格）。
- 本 case 自身的新鲜角度。
  - **现场展示物设计**：每个 case 应识别 1-2 件可以直接投影给家长看的"证据物"——文书原文段落、写作样本、推荐信片段、成绩单截图等。如果学生有已发表或已提交的原创写作作品（如 Nemerov Writing Sample、文学杂志发表等），必须纳入展示物清单，不要设为"可选"。展示物的作用是让家长亲眼看到实力，比任何口头描述都更有力。展示时不做过度解读——投影原文，顾问说一两句点睛即可，让作品自己说话。

输出骨架后停止，等待用户确认或修改。不要在方向未确认时生成完整逐字稿。

## 成稿层

方向骨架确认后，生成完整分享会内容。完整稿必须包含：

- 分享会设计原理。
- 时间结构与现场设置。
- 主持人开场。
- 顾问引导词。
- 学生出场与回答设计。
- 家长互动问题。
- 推演、揭晓、解析环节（每段三拍，第三拍必须有具体话术）。
- 机构方法论归因。
- 散场疑虑处理。
- Q&A 控制建议。
- PPT 或 handout 内容清单。
- 补料采访问题。
- 风险提示与不可公开内容。
- 会后可转公众号的素材标注。

完整稿的质量必须接近可直接执行，而不是高层策划。成稿时必须做到：

- 每个环节都有明确目的、时长和讲者。
- 关键段落要有可直接说出口的话术。
- 互动问题要包含家长可能回答什么，以及讲者如何接住。
- 揭晓和解析之间要有停顿、转场或舞台提示。
- 学生回答不能临场发挥时，要列出需要提前采访确认的原话。
- PPT 或 handout 清单要说明每页展示什么材料、服务什么认知反转。
- 收尾必须处理一个具体的散场疑虑，而不是泛泛总结。
- 每个反转的第三拍（解析判断逻辑）必须有具体话术，不能空泛"我们的方法论是..."。

## 反模板规则

每个 case 启动时，下列要素必须从零重新挖掘，不可从过往 case 套用：

- 故事发动机。
- 目标家长画像。
- 认知反转的具体内容（推演 / 揭晓 / 解析作为机制可复用，但具体题目、内容、角度必须由 case 本身决定）。
- 互动机制的具体话术。
- 主轴 / 标语 / 钩子。

下列要素是稳定的，可以延续：

- 三层流程结构（探索 → 方向确认 → 成稿）。
- 三拍反转结构。
- 机构归因到方法论而非单个顾问的原则。
- 比邻品牌精神底色（专业判断 / 看见学生真实价值 / 不模板化也不放任）。

**现场流程形态默认对齐楚昊场**（参见 `_shared/source-materials/分享会流程.md`）。下列形态层面的要素是已验证 baseline，不要重新发明：

- 60 分钟全场结构。
- 推演（家长盲判 → 揭晓 → 顾问解析）作为主反转的现场实现机制。
- Q&A 引导式（顾问问 / 学生答 / 顾问接，每段答 2–3 分钟）作为学生主体讲述的形态。
- 替家长问 + 学生真实回答 + 顾问兜回 作为收尾彩蛋结构。
- 辉 + Eva 双人台上 / Lulu 等一线顾问不上台 作为人选配置默认。

case 之间真正应该差异化的：故事发动机、主轴、反转的具体内容、Q&A 的具体问题、替家长问的具体内容、现场展示物的具体材料。形态保留、内容差异化——这是"复用流程，不复用结果"的具体含义。

如果发现自己在套用某个过往 case 的具体内容（题目 / 揭晓 / 解析的具体角度），立即停止，回到 framing-tools 做自检。但如果发现自己在偏离 baseline 流程形态（自创学生独白 / 多段同结构反转 / 多顾问出场等），同样立即停止，回到 baseline。

**替家长问 tough question 跨 case 去重**：每个 case 的替家长问 tough question 必须与过往所有 case 的 tough question 对比，避免重复套路。如果过往 case 用过"就业"类问题，下一个 case 必须换一个维度（如家庭沟通 / 独立判断 / 价值观冲突等）。骨架确认时必须显式列出"与过往 case tough question 的差异"。

## 创作原则

- 复用流程，不复用结果。
- 7 步法（在 case-methodology.md 里）是判断骨架，不是探索层的输出格式——角度卡片不必 1:1 映射到 7 步法。
- 推演、揭晓、解析是互动机制，具体内容必须由 case 本身驱动。
- 每个 case 都必须找到自己的故事发动机。
- 不默认每场分享会都围绕文书展开。
- 不默认每场分享会都复制任一过往 case 的结构。
- 如果生成结果读起来像策划案、提纲或宣传文案，而不是现场可执行脚本，必须继续展开到逐字稿和执行材料。

## 安全边界

- 线下分享会可以使用已授权真实材料。
- 对授权状态不清晰的材料，标为"待公开确认项"。
- 不把内部资料写进对外产物。
- 不神化单个顾问。
- 不承诺录取结果。
- 高敏感素材（家庭创伤 / 道德选择 / 学校权威否决）使用前必须确认相关方授权。

## 复盘与累积

每次 case 的方向确认或骨架完成后，建议做两件事：

1. 检查是否有"我们差点搞错的方向 + 怎么矫正的"值得加进 `references/process-learnings/pitfalls-and-corrections.md`（上限 30 条，超过淘汰旧的或合并冗余）。
2. 检查 `references/process-learnings/framing-tools.md` 是否需要新增自检问题（上限 20 条，超过合并）。

每个 case 完成成稿后，写一份 case journal 放进 `references/process-learnings/case-journals/`。journal 不强制结构，记录这次讨论的关键转折、最终选择、为什么没选其他方向。journal 默认不预读，仅在新 case 与某个 journal 有特定相似情境时主动 pull。

累积的核心原则：**累积"切问题的方式"，不累积"切出的结果"。** 思维工具留下，具体答案扔掉。每个新 case 的故事发动机、画像、反转都必须从零挖掘。
