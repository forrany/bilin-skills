# 偏离-矫正记录

只记录"我们差点犯的错 + 怎么矫正的"。不记录"我们做对了什么"。

每条 entry 是一次具体的偏离 + 矫正，附可推广教训。新 case 启动时强制读，目的是避坑，不是找方向。

上限 ≤30 条。超过就合并、淘汰旧的或冗余的。

---

## 探索层：直接出骨架，跳过发散

- **偏离信号**：拿到 case 材料后立刻往 12 字段骨架走，没有先发散候选方向。结果方向被锁死，AI 的"挖掘"是补全模板而不是真正探索。
- **矫正动作**：在骨架前加"探索层"——发散输出多张角度卡片，每张含一句话主轴 / 击中家长 / 故事发动机 / 潜在反转 / 风险与归因，让用户先看候选再选方向。
- **可推广的教训**：骨架 12 字段一旦输出，方向已经收敛了。如果发散过程没有显性化，用户只能事后纠正而不能共同决策。任何强结构的输出都需要一个上游的"候选淘汰"阶段。
- **出处**：Therase case，2026-05-02。

## 探索层：把家长画像按"焦虑维度"切

- **偏离信号**：第一次给画像时切成"卷校中下游 + 厌恶作弊"和"孩子有 voice 但担心 AI 时代写作没用"，本质是按家长怕什么切。用户反馈"a / b 都不对"。
- **矫正动作**：改按"信念维度"切——家长信什么 / 不信什么。Therase 这场最终画像是"相信真实但不确定真实能赢的家长"，再分两层（已决定走真实路线 vs 还在犹豫）。
- **可推广的教训**：焦虑维度切出来的画像普遍太浅，因为绝大多数家长都被同样的焦虑绑架——分不出来谁是"我们的人"。信念维度切出来的画像更精准，因为它定义的是"和这场分享会精神底色对得上的家长"。当你切完发现画像太宽泛、覆盖人群过多，说明你切错维度了。
- **出处**：Therase case，2026-05-02。

## 反转设计：只有单层，让家长猜结果就揭晓

- **偏离信号**：第一版反转都是"家长猜哪个会被录 → 揭晓"。结构上接近综艺反转，给的是答案，不是判断逻辑。
- **矫正动作**：改成"三拍"——家长眼判断 → 招生官眼揭晓 → 解析比邻判断逻辑（第三拍是机构方法论显形的关键）。
- **可推广的教训**：分享会的反转如果只揭晓答案，等于把比邻的能力包装成"运气"或"灵感"。三拍结构强制把"判断逻辑"显形化，这是把功劳从单个顾问归因到机构方法论的核心机制。所有反转都要追问"这一段第三拍是什么"。
- **出处**：Therase case，2026-05-02。

## 主轴框架：陷入"真实 vs 包装"的简化二元

- **偏离信号**：第一版精神底色是"真实战胜包装"。读起来顺，但隐含着"机构 = 放手让孩子写真的"，把比邻的专业判断价值完全埋掉了。
- **矫正动作**：升级到"看见 + 翻译 + 保护"三件事——比邻不是放手，是识别家长看不见的好，再翻译成招生官认得的样子。机构的位置不在二元的任一极，在第三个位置。
- **可推广的教训**：所有"A vs B"型主轴框架都要警觉——机构的卖点常常正是被这个二元埋没的第三种动作。问自己：如果家长只在 A 和 B 之间选，比邻的服务是什么？如果答案是"鼓励选 A"或"鼓励选 B"，那机构看起来就只是助推器；机构真正的能力一定不止是这个。
- **出处**：Therase case，2026-05-02。

## 反转设计：依赖了比邻拿不到的对照素材

- **偏离信号**：A 段反转设计成"5 位同校申 WashU 学生 anonymized profile 对比表，让家长选谁会录"。其中 4 位不是比邻学生，他们的 profile / 文书 / 顾问内部判断比邻根本没有，这种现场对照表只能靠编或缩水成传闻，骨架强度直接崩。
- **矫正动作**：所有反转的对照样本 / 揭晓素材 / 现场展示物必须来自比邻自己能拿到、已授权、可现场出示的范围（比邻案例库 / 主文书 / 顾问内部讨论 / 学生采访稿）。外部学生 / 同校同学的传闻只能由学生 / 家长 / 顾问口述提及，不能做成可视化对照展示物。设计每个反转前必须先核查"对照素材是否在比邻可控范围"。
- **可推广的教训**：分享会的反转不是综艺悬念，是基于真实可用素材的认知错位。骨架字段填得漂亮但素材其实拿不到，是 AI 在"补全模板"时最容易出现的虚假完整。每个反转都要追问：这一拍的对照样本，比邻能不能拿到？拿不到要么降级成口述提及，要么砍掉。
- **出处**：Therase case，2026-05-03。

## 角色分配：学生戏份被顾问挤压 / 学生出场过晚

- **偏离信号**：第一版骨架做了"学生前 30 分钟不出场、中段才出场"的反结构，同时把多段反转的解析交给顾问主讲。结果分享会重心从学生本人滑向顾问，变成"机构推介会"，反而消耗信任。家长来分享会的核心需求是听学生本人讲，顾问独白会让 case 失去最强武器。
- **矫正动作**：学生是分享会主体讲述者，时长占比应明显高于顾问（建议学生 ≥ 50%、顾问 ≤ 30%、主持人 ≤ 20%）。学生出场时机最晚不晚于开场 10 分钟内。顾问只在第三拍做解析和判断显形（点睛 + 翻译 + 总结），不替学生叙述故事。"反结构"指的是叙事顺序的反转（先看材料再看人 / 先讲过程再揭录取），不是把主讲权交给顾问。
- **可推广的教训**：家长来听的是"这个孩子是谁、他怎么走过来的"。机构能力只能通过"解析学生讲述"来显形，不能通过抢戏显形。骨架层在分配三方角色时，必须显式列出三方时长占比，不能模糊处理。
- **出处**：Therase case，2026-05-03。

## 反转预设：用了违反现场常识的家长心理

- **偏离信号**：写"家长此时心里在猜'这个学生最后录上了吗'"。但凡来分享会的就是已录取案例，邀请函 / 海报 / 上下文必然写明，家长入场前已经知道结果，不可能产生这个猜测。这种预设暴露了 AI 没在"现场常识"里思考。
- **矫正动作**：设计反转 / 互动 / 家长心理预设前，必须先列出"现场基线认知清单"——家长入场前已经知道的事实（录取学校 / 学生身份维度 / 大致背景）。反转必须建立在他们不知道的部分。比如对录取案例分享会，家长不会猜"录没录"，但会猜"这种 profile 凭什么录 / 这段文书凭什么招生官买单"——后者才是真实的认知反转空间。
- **可推广的教训**：分享会海报 / 邀请函 / 上下文必然透露的信息不能被当成悬念。每个反转设计前必须经过"现场常识检验"——家长入场时已经知道了什么？我设计的悬念是不是其实早就揭晓了？
- **出处**：Therase case，2026-05-03。

## 学生讲述形式：让学生在台上做长时间连续陈述

- **偏离信号**：V2 骨架让 Theresa 在台上连续讲 15–20 分钟自述（高中状态 / SAT 下滑 / counselor 否决 / 同学买分 / 选校原因 / 跟外教合作）。对绝大多数高中生来说，台上连续陈述 ≥ 5 分钟压力极大，自然度差，容易紧张、跑题、卡顿；学生身上"有锋的语调"在压力下也容易丢。
- **矫正动作**：默认采用 Q&A 引导式——顾问问 5–7 个结构化问题，学生每段回答控制在 2–3 分钟，问题之间顾问做简短"接住"或转场。问题要提前在补采阶段对齐过，让学生用自己的原话回答，但有节奏地被引导出来。这是楚昊场已经验证过的形态（参见 source-materials/分享会流程.md）。
- **可推广的教训**：分享会要照顾学生在台上的负担。学生作为主体讲述者 ≠ 学生独白。Q&A 引导式让顾问承担"叙事节奏 + 关键提示 + 冷场救场"，学生只需对一个明确问题做 2–3 分钟回答，自然度和质量都明显更高。"主体讲述权"指的是话语主权和时长占比，不是连续独白的形式。
- **出处**：Therase case，2026-05-03（V3 修订）。

## 反转形式：同 case 内多段反转结构高度重复

- **偏离信号**：V2 骨架在同一 case 内设计了 B 段（AI 时代 voice）+ E 段（家庭创伤直写）两段反转，结构高度相似——都是"读文书段落 → 家长盲判 → 揭晓 + 顾问解析"。第二次出现时家长会感受到"套路"，前一次的真实感被消解。
- **矫正动作**：同一 case 内默认只做 1 次结构性反转（推演 → 揭晓 → 解析）。剩下的洞察通过 Q&A 自然带出，不再做形式化推演。例外：如果反转的对象 / 层次明显不同（比如楚昊场的主文书 / 小文书 / 活动描述是三个不同 artifact，反转的家长盲判维度也不同），可以做多段，但每段必须在 artifact 维度上有明显区分。
- **可推广的教训**：反转不是越多越好。家长在第一次反转时被"差距感"打中是真诚的；第二次结构相同的反转家长会立刻识别"模板"——真诚感被消耗。Vincent 的判准："家长尽量能感受到这次分享的真实、真诚，而不是套路"。多段反转的合理性必须经过"对象差异自检"——不只是问"反转拍数对不对"，要问"两次反转的对象 / 层次 / 家长盲判维度是不是真的不一样"。
- **出处**：Therase case，2026-05-03（V3 修订）。
