# Therase Case · 设计复盘

> 录取学校：Washington University in St. Louis · ED1 · Fall 2026
> 申请专业：英语文学（含 Creative Writing / Publishing）+ Drama 双专业
> 设计时间：2026-05-02
> 协作者：Vincent

## 起点

Vincent 提出对 shareflow-builder 直接出骨架的不满——AI 一拿到 case 就往 12 字段填，挖掘和创新力被收敛阶段压扁了。要在骨架前加一个真正的发散阶段，让候选方向显性化、可对比、可淘汰，再共同决策。

## 流程改造的判断

把 shareflow-builder 拆成三层：探索层（发散）→ 方向确认层（收敛）→ 成稿层（执行）。每层的产出物形态不同，强制分离，避免一步到位带来的方向锁死。

## 探索层第一次跑：7 张角度卡 + 1 张对照卡

针对 Therase 的稀缺信号挖出 9 个候选切入：

- counselor 当面唱衰反转录取
- 同校买分文化下唯一不作弊的录取者
- SAT 月月下滑、自己读 CDS 推 test-optional 数学
- 卷校排 40%、AI 时代 voice 胜利
- 主修 Playwriting 这种 4 所学校开的冷门专业
- 主文书直写离异家庭 + LA host family + 澳洲被 cuff
- Nemerov 诗稿（My Tongue Carries Six Ways to Be Wrong / Salted Years）
- 高效女孩遇到高效顾问的性格匹配
- 数据派学生的辅助式服务模式

聚合成 6 张主候选卡 + 1 张明显较弱的对照卡（"硬件不行靠活动取胜"——和楚昊撞车、埋没真正稀缺）。每张卡含一句话主轴 / 击中家长 / 故事发动机 / 潜在反转 / 风险与归因。

## Vincent 的方向选择

挑了 1 / 2 / 6 / 7 这四个稀缺信号，对应 A（不作弊 + counselor 否决）+ B（AI 时代 voice）+ E（家庭创伤直写）的组合。出一个主版本骨架，不要并行多版本。

明确指出我给的家长画像 a / b 都不对——不要按焦虑切。

## 画像的重切

第一次切错原因：我在切焦虑维度（卷校焦虑 / AI 焦虑），用户要的是信念维度。

重切后：**相信"真实"但不确定"真实能赢"的家长**。分两层（已决定走真实路线 vs 还在犹豫）。补充层是承认家长内心的尴尬——"我是不是不太懂我孩子的真正特别在哪"——但用专业能力差距的角度温和处理，不批评家长。

反向画像：要操作清单的、单纯硬件焦虑的、孩子背景非常 standard 的、不愿写真实家庭事的。

## Vincent 的关键补充：比邻能力的精准定位

这是这次讨论里最重要的一次重新对齐。

我之前的精神底色是"真实战胜包装"。Vincent 拉回来：比邻做的是**抓住和坚持学生真实、珍贵的东西，从招生官视角指导哪些是值得被看见的，有能力发掘、包装和展示这些真实**。家长的不理解（"我孩子怎么这么差"）正是他们没有这个专业能力。

由此精神底色升级到："**看见 + 翻译 + 保护**" 三件事。比邻不是放手让学生裸奔，也不是把学生模板化，是站在学生气质和招生官视角中间做专业判断。

主轴和反转设计随之全部重写：

- 主标语：替家长看见孩子，替招生官读懂孩子。
- 开场钩子：招生官眼里的好材料，常常不是家长眼里的好材料。
- 反转结构：家长眼 → 招生官眼 → 比邻判断逻辑（三拍）。
- 机构能力落点：鉴别 / 翻译 / 保护，三个独立可显形的能力维度。

## 主轴语言的迭代

第一版 "专业判断 = 看见你看不见的，翻译给招生官能看见的" 拗口，"看见"重复。

候选四个：双角色对仗 / 翻译动作主导 / 桥的隐喻 / 眼睛的隐喻。最终选了双角色对仗版（"替家长看见孩子，替招生官读懂孩子"）——和开场钩子（"招生官眼里的好材料常常不是家长眼里的好材料"）形成"差距存在 → 我们来弥合"的呼应。

## 骨架产出

12 字段全部按本次对齐的精神底色重写。重点设计：

- 学生出场方式做反结构——Therase 不在开场出现，前 30 分钟家长只看 anonymized 材料形成自己的判断，中段才出场。强制家长经历"我看不出来"的认知翻转。
- A / B / E 三段每段三拍。
- 顾问出场两位（中方 + 外教代表），交叉发言，避免单顾问独白。
- 整体格调反"逆袭奇迹"套话，保留 Therase 本人有锋的语调。
- 散场疑虑留"我家孩子有没有值得被看见的真实"，由现场顾问承接。

## 这次讨论沉淀的工具

- pitfalls-and-corrections.md 加 4 条：直接出骨架 / 焦虑维度切画像 / 单层反转 / 简化二元主轴。
- framing-tools.md 加初始 15 条自我审查问题。
- 这份 journal 本身。

## 不应被复用的部分

- Therase 的具体素材（不作弊 / 离异家庭 / Nemerov 诗稿 / counselor 唱衰）——这些是 Therase 的，不是方法论。
- "看见 + 翻译 + 保护" 这个三件事框架——这是这次刚好对得上 Therase 的精神底色，不是所有 case 的默认主轴。下一个 case 可能完全不需要这个框架。
- 三段反转 + 三拍互动结构——是这场分享会的具体设计，不是模板。
- 家长画像"相信真实但不确定真实能赢"——是 Therase 这场的，不是普适画像。

下一个 case 来的时候，故事发动机 / 画像 / 反转必须从零重新挖掘。这份 journal 默认不预读，除非明确判定相似情境（比如又一个家庭创伤直写 / 又一个 playwriting 申请 / 又一个 counselor 唱衰反转录取）才主动 pull。

## V2 修订（2026-05-03）：骨架细节问题暴露的三类系统性偏离

V1 骨架方向没问题，但落到细节时 Vincent 指出了三个具体问题，回看都不是这个 case 独有，而是 skill 层缺审查的系统性偏离。这一轮把三条新 pitfall 加进了 pitfalls-and-corrections.md（#5 / #6 / #7），三条新自检题加进了 framing-tools.md（#4 / #10 / #12），骨架层 output contracts 加了"现场基线认知清单"和"反转素材可行性核查"两个必填字段。

### 偏离 1：A 段反转依赖比邻拿不到的对照素材

V1 设计的 A 段是"5 位同校申 WashU 学生 anonymized profile 对比表，让家长选谁会录"。Vincent 指出这 4 位不是比邻学生，比邻没有他们的真实材料，做不出现场对照表——AI 当时填字段填得漂亮，但素材其实拿不到。

**矫正**：直接砍掉 A 段反转。"不作弊 / counselor 否决 / SAT 下滑"这三段素材改由 Theresa 自己在第二阶段自述里讲出来，不做成现场对照展示。skill 层加 pitfall #5 + framing-tools #4，要求每个反转设计前必须核查"对照素材是否在比邻可控范围"。

### 偏离 2：学生出场过晚、顾问抢戏

V1 设计的反结构是"前 30 分钟没 Theresa，家长只看 anonymized 材料形成判断"，配套把多段反转的解析交给顾问主讲。Vincent 指出家长来分享会的核心需求是听学生本人讲，顾问独白会让分享会变成"机构推介会"。

**矫正**：V2 把 Theresa 出场提前到开场 5–10 分钟内，连续讲 15–20 分钟不被打断。顾问段落只在两段反转的第三拍出现（每段封顶 5 分钟）+ 收尾归结（3 分钟）。骨架字段强制要求列出三方时长占比（学生 ≥ 50%，顾问 ≤ 30%）。skill 层加 pitfall #6 + framing-tools #12——把 framing-tools 第 12 条"学生主体讲述权"明确成"出场时机 + 主讲权归属"两件事，并指出"反结构 ≠ 把主讲权交给顾问"。

### 偏离 3："家长此时心里在猜'录上了吗'"——违反现场常识的预设

V1 学生出场方式段落里写过这种家长心理预设。Vincent 指出但凡来分享会的就是已录取案例，家长入场前一定知道结果。这种预设暴露了 AI 没在"现场常识"里思考。

**矫正**：骨架层加"现场基线认知清单"必填字段，强制列出家长入场前已经知道的事实（录取学校 / 学生身份 / 邀请函必然透露的信息）。反转只能建在剩下的不确定空间。skill 层加 pitfall #7 + framing-tools #10。

### Vincent 关于"妈妈想买分"素材的明确指令

V1 骨架里把"妈妈想让 Theresa 买分"作为家庭压力维度的素材，并标记为待妈妈授权后使用。V2 修订时 Vincent 明确指令：**这段素材不进入分享会任何形态（线下 / 公众号 / 内部参考），只讲同学买分**。家庭压力维度通过 Theresa 自述"看到同校同学走非常规途径拿 SAT 高分的反应"承载，避免引入妈妈这条线。

可推广教训：家庭内部压力素材即使可以授权，也未必合适放上台面。判断是否使用要看：能不能用学生自己的视角和外部观察素材替代家庭内部冲突？能替代就替代，不必为了戏剧张力消耗家长信任。

### 这一轮沉淀的工具

- pitfalls-and-corrections.md 加 3 条（#5 反转素材不可控 / #6 学生戏份被挤压 / #7 家长心理预设违反现场常识）。
- framing-tools.md 加 3 条（#4 反转素材可获得性 / #10 家长基线认知 / #12 学生主体讲述权——这条是把原 #10 升级），上限从 ≤15 调整到 ≤20。
- output-contracts.md 骨架层加 2 个必填字段（现场基线认知清单 / 反转素材可行性核查），并把"角色分配"字段升级为强制列出三方时长占比。
- SKILL.md 骨架层段落同步更新。

### 下一轮要警觉的元问题

V1 → V2 这一轮的根因是：探索层和方向确认层都在思考"故事发动机和反转角度"层面，没有下沉到"每个反转的现场可执行性"层面。骨架字段填得齐不等于骨架可上台。下一个 case 来的时候，要在方向确认层就把"现场可执行性"作为一道独立闸——反转素材在不在比邻可控范围、家长入场前已知什么、学生在这场会里讲多久——这三件事必须显式回答，不能等到骨架成型后用户来挑。

## V3 修订（2026-05-03）：流程形态对齐楚昊场

V2 修了反转素材 / 学生角色 / 现场常识三件事，但 Vincent 接着指出 V2 的"流程形态"本身还有问题——这次是更深的偏离：V2 自创了一种新的现场流程（学生独白 15–20 分钟 + 双段反转），完全没参照已经在用的楚昊场形态（推演 + Q&A 引导式 + 单段反转跨多 artifact）。skill 层之前没强制要求"对齐已验证的流程形态"，导致 V2 在不必要的地方重新发明轮子。

### 偏离 1：让学生在台上做长时间连续陈述

V2 设计了 Theresa 在第二阶段连续讲 15–20 分钟自述（高中状态 / SAT / counselor / 同学 / 选校 / 外教合作）。Vincent 指出对学生的考验和压力非常大，且不自然——分享会家长想听的是学生本人的声音，但不是听学生独白，是听学生在被引导下展开。

**矫正**：V3 改 Q&A 引导式——Eva 问 5–7 个结构化问题（Q1 自我介绍 + 高中 / Q2 找比邻的故事 / Q3 counselor 否决 + 同学走非常规途径 / Q4 主文书选材 / Q5 文书最打动你的一笔 / Q6 申请季最深印象 / Q7 level of interest 怎么做满），每段答 2–3 分钟，问题之间 Eva 做 30–45 秒接住。这是楚昊场 6 个月前就已验证的形态。

skill 层加 pitfall #8 + framing-tools #13。output-contracts 把"学生主体讲述权"细化为"学生 Q&A 答题时长 ≥ 顾问独白式输出时长"，并明确禁止 ≥ 5 分钟连续独白。

### 偏离 2：同 case 内多段反转结构高度重复

V2 设计了 B 段（AI 时代 voice）+ E 段（家庭创伤直写）两段反转，结构高度相似——都是"读文书段落 → 家长盲判 → 揭晓 + 顾问解析"。Vincent 指出第二次出现时家长会感受到套路。

**矫正**：V3 只保留 1 段结构性反转（主文书 voice）。E 段内容（离异 / LA / 澳洲）通过 Q4 由 Theresa 自己讲述写作动机，由 Eva 接住时点出"分寸把控是专业判断"——洞察保留，但不再做形式化推演。

skill 层加 pitfall #9 + framing-tools #14。output-contracts 把"反转字段"从"2–4 个反转"改为"单 case 默认 1 次结构性反转，例外是反转对象 / 层次有明显差异（不同 artifact）"。这条与楚昊场的"主文书 / 小文书 / 活动描述三层"模式一致——楚昊场的多反转之所以不套路，是因为对象差异显著。

### 偏离 3：双顾问出场 / 没有对齐已验证的人选配置

V2 推荐顾问 2 位（中方文书顾问 + 外教视角代表），但没有具体到人。Vincent 明确指令：本场只用 Eva 一位顾问（高级合伙人 / 文书委员会核心 / Lulu 的 leader），辉做开场主持 + 引荐后退场——这跟楚昊场是同一个人选配置。Lulu 不上台。

**矫正**：V3 把角色配置完全对齐楚昊场——辉 + Eva 双人台上。Lulu 作为一线顾问不出场，由 Eva 在台上代表"机构能力"层面（不只是某位顾问）。output-contracts 把"顾问总数"明确为"默认 1 位（必要时最多 2 位）"。

### Vincent 关于"单 case 内反转重复 = 套路感"的判准

这一轮 Vincent 给的核心判准是："家长尽量能感受到这次分享的真实、真诚和想要让家长看到的和认识到他们之前的认知错误。所以这样的比较复杂的交互设计，可能一次就可以了。"

可推广教训：分享会的反转机制是工具，不是目的。第一次反转是真诚的"差距感"教育；第二次同结构反转就变成"模板套路"——后者会消解前者已经建立的真诚感。设计反转的合理性必须经过"对象差异自检"——不只是问"反转拍数对不对"，要问"两次反转对象是不是真的不一样"。

### 这一轮沉淀的工具

- pitfalls-and-corrections.md 加 2 条（#8 学生连续陈述 / #9 反转结构重复）。
- framing-tools.md 加 2 条（#13 学生讲述形式 / #14 反转形式重复），#12 升级为含"出场 timing 弹性"。
- output-contracts.md 骨架层"反转字段 + 学生出场 + 学生讲述形式 + 角色分配时长占比"四处升级。学生时长占比从硬性 ≥ 50% 改为"学生 Q&A 答题时长 ≥ 顾问独白式输出时长"，并参照楚昊场已验证比例（学生 30–35% / 顾问 50–55% / 主持人 8–12%）。
- SKILL.md 同步更新。
- 骨架 V3 完整重写——单段主文书推演 + Q&A 串联 + 选校解析 + 替家长问彩蛋，时长结构精确到分钟，时长占比测算明确写入。

### 下一轮要警觉的元问题

V1 → V2 → V3 三轮的累积教训：**不要发明新的现场流程形态。已经有楚昊场作为已验证的 baseline 流程，新 case 默认对齐这个 baseline，只在 case 自身故事发动机要求的地方做差异化调整**。具体的对齐项：

- 推演（家长盲判 + 揭晓 + 顾问解析）这个机制是稳定的。
- Q&A 引导式（顾问问 / 学生答 / 顾问接）这个形态是稳定的。
- 替家长问 + 学生真实回答 + 顾问兜回 这个彩蛋结构是稳定的。
- 时长结构（60 分钟 / 学生 Q&A 答题 30–35% / 顾问独白式 30%）是稳定的。
- 辉 + Eva 双人台上、Lulu 不上台 这个人选配置是稳定的。

case 之间真正应该差异化的：故事发动机 / 主轴 / 反转的具体内容（题目 + 揭晓 + 解析） / Q&A 的具体问题 / 替家长问的具体内容 / 现场展示物的具体材料。

skill 层之前的"反模板规则"列了"故事发动机 / 画像 / 反转 / 主轴必须从零挖掘"，但没把"流程形态对齐 baseline"作为对应的"必须复用"列出。这一轮要把后者也写进 SKILL.md 的"反模板规则"对应位置。下一轮启动新 case 时，这条记得用上。
