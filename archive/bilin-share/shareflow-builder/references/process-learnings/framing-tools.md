# 自我审查清单

启动新 case 时强制走一遍。每条不是规则，是问自己的问题。

不告诉你答案是什么。只逼你看清自己当前的思考惯性。

上限 ≤20 条。超过就合并、淘汰旧的或冗余的。

---

## 探索层启动前

1. **画像维度自检**：我现在切家长画像是按什么维度切的？焦虑维度（家长怕什么）还是信念维度（家长信什么 / 不信什么）？焦虑维度通常太浅，画出来的画像覆盖人群太宽。

2. **角度卡数量自检**：我准备发散几张？是否有"对照卡"——明确建议淘汰但保留可见，让用户看到我淘汰了什么、为什么？没有对照卡，淘汰过程是隐藏的。

3. **二元框架自检**：我的主轴是不是落入了"A vs B"的简化二元（真实 vs 包装 / 亮眼 vs 朴素 / 早签 vs 晚签）？机构的卖点经常正好在二元埋没的第三个位置。

4. **反转素材可获得性自检**：我准备的每个反转，需要的对照样本 / 揭晓素材 / 现场展示物，是不是比邻自己能拿到的、已授权的？对照样本来自外部学生 / 同校同学 / 第三方机构的，比邻通常拿不到他们的真实材料，这种反转要么降级成口述提及，要么砍掉。骨架字段填得漂亮但素材拿不到，是最容易出现的虚假完整。

## 方向确认层启动前

5. **反转拍数自检**：我设计的反转是单层（家长猜结果就揭晓）还是三拍（家长眼 → 招生官眼 → 解析机构判断逻辑）？只有三拍才能让机构能力显形。

6. **归因纯度自检**：故事发动机能不能干净落到机构动作？哪些动作其实是学生 / 家庭自己的？被混淆的归因会让机构卖点变虚。

7. **去个人化自检**：我有没有不自觉地把功劳归因到单个顾问？需要升级到"机构方法论库"层面，避免把比邻的能力卖成"哪个老师好"。

8. **反向画像自检**：这场分享会明确不为谁开？没有反向画像的画像是不收敛的，宣发文案也写不出 self-select 的钩子。

9. **收敛问题自检**：我准备的收敛问题是不是"反向决定方向"的问题（"你愿不愿意暴露 X 这段材料"），还是"你想要哪个方向"这种空问？

10. **家长基线认知自检**：这场分享会上，家长入场前已经知道什么（录取学校 / 学生身份维度 / 邀请函 / 海报 / 上下文必然透露的信息）？我设计的反转有没有把家长已经知道的东西当成悬念？录取案例分享会上家长不会猜"录没录"，但会猜"这种 profile 凭什么录"——反转只能建在后者上。

## 骨架层启动前

11. **case 独特性自检**：我有没有不自觉地往过往参考案例的结构靠（楚昊三段 / Therase 双拍 / 任何已有 case 的形）？这个 case 自己的故事发动机是什么？

12. **钩子类型自检**：这个学生的 profile 张力是什么类型？我选的开场钩子（去光环化 / 外部权威否决 / 认知错位）是否匹配这个张力？还是我在默认套用"去光环化"——如果学生 profile 看起来不弱，"去光环化"就不成立。

13. **学生主体讲述权自检**：学生是不是分享会的主体讲述者（时长占比建议 ≥ 50%）？学生出场时机是不是合理——如果有"推演"环节，学生应在推演揭晓时立即出场（楚昊场约第 17 分钟）；如果没有推演环节，学生应在开场 10 分钟内出场。顾问段落是不是只做解析和点睛，不替学生叙述？"反结构"是指叙事顺序的反转（先看材料再看人 / 先讲过程再揭录取），不是把主讲权交给顾问——这两件事不能绑在一起。

13. **学生讲述形式自检**：学生作为主体讲述者，是不是在台上做长时间连续陈述？连续陈述 ≥ 5 分钟对绝大多数高中生压力极大，应使用 Q&A 引导式（顾问问 5–7 个结构化问题，学生每段回答 2–3 分钟）。"主体讲述权"指话语主权和时长占比，不是独白形式。问题要提前在补采阶段对齐过，让学生用原话回答。

14. **反转形式重复自检**：同一 case 内多段反转的结构是不是高度相似（比如都是"读文书段落 → 盲判 → 揭晓"）？同结构反转重复 → 家长会立刻识别套路 → 真诚感被消耗。同 case 内默认只做 1 次结构性反转，其他洞察通过 Q&A 自然带出。例外是反转对象 / 层次有明显差异（楚昊场的主文书 / 小文书 / 活动描述是不同 artifact）。

15. **格调自检**：我有没有用"逆袭""奇迹""坚持就是胜利"这一类煽情套话？不是所有 case 都要走励志路线。学生本人的真实语调是什么？

16. **互动机制自检**：推演 / 揭晓 / 解析这套机制本身是抽象的，但具体推演题目、揭晓内容、解析角度必须由这个 case 自手驱动。我现在设计的具体内容真的是 case 驱动的吗？还是套用过来的？

17. **钩子-疑虑闭环自检**：开场钩子提出的张力，散场疑虑是否收回来了？两者是否形成闭环（钩子 → 整场内容 → 疑虑 → 转化暗示）？还是钩子和疑虑各自独立，没有呼应？

18. **替家长问去重自检**：这个 case 的 tough question 跟过往 case 的 tough question 是否重复？如果都是"就业"类问题，必须换维度。骨架确认时是否显式列出了差异？

## 成稿层启动前

20. **执行度自检**：每个环节有没有明确的目的、时长和讲者？关键段落有没有可直接说出口的话术？我读起来像策划案 / 提纲，还是像可上场的脚本？

21. **第三拍话术自检**：每个反转的第三拍（解析判断逻辑）有没有具体话术？这是机构能力显形的关键点，不能空泛"我们的方法论是..."。

22. **散场疑虑自检**：收尾处理的是不是一个具体的散场疑虑？还是泛泛总结？泛泛总结的收尾是失败的收尾。散场疑虑是否回响了开场钩子？是否暗示了转化信号？
