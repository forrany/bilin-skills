# 输出格式契约

## Case 初筛判断卡

必须包含：

- 学生基础标签。
- 录取结果与传播价值。
- 归因纯度评级。
- 可打中的家长画像。
- 7 步法下的潜在反转点。
- 非框架发现。
- 建议内容形态。
- 需要补充的材料清单。
- 风险与公开性提醒。

## 探索层角度卡片

每张卡片必须包含：

- 一句话主轴。
- 击中家长（按信念维度切，不按焦虑维度切）。
- 故事发动机（这条线为什么独特）。
- 潜在反转（如果做大会变成什么样的现场推演）。
- 风险与归因纯度。

数量与组织：

- 5-7 张主候选卡 + 1-2 张"对照卡"（明显建议淘汰，留作显性化淘汰过程）。
- 卡片之间的叠加 / 互斥关系必须在卡片后单独说明。
- 不要在探索层就替用户选好答案。

质量自检：

- 是否按"信念维度"而非"焦虑维度"切家长画像？
- 是否有"对照卡"让淘汰过程可见？
- 是否落入了"A vs B"的简化二元？机构常常在二元的第三个位置。
- 是否在探索层就替用户选好了答案？

## 方向确认层产出

必须包含：

- 1-3 个候选完整方向（每个方向通常由 2-3 张卡片叠加构成）。
- 反向画像（这场分享会不为谁开）。
- 3-5 个收敛性问题（按信念维度切，不按焦虑维度切）。
- 多骨架的触发判断（默认 1 个骨架，仅当 case 有多个互斥发动机或画像分裂明显时才考虑出多骨架）。

质量自检：

- 收敛性问题是不是"反向决定方向"的问题，而不是"你想要哪个方向"这种空问？
- 反向画像是否明确？没有反向画像意味着画像不收敛。
- 是否避免了把功劳归因到单个顾问？

## 分享会方向骨架

必须包含：

- 核心主轴（含主标语 / **开场钩子类型**（去光环化 / 外部权威否决 / 认知错位，由 profile 张力决定）/ 精神底色）。
- **钩子-疑虑闭环**：开场钩子与散场疑虑必须形成闭环，散场疑虑要暗示转化信号。
- 目标家长画像（含主画像 / 细分层 / 反向画像）。
- 故事发动机。
- **现场基线认知清单**：家长入场前已经知道的事实（基于邀请函 / 海报 / 上下文必然透露的信息）。反转只能建在他们不知道的部分。
- **认知反转**：单 case 默认 **1 次结构性反转**，三拍结构（家长眼 → 招生官眼 → 解析机构判断逻辑）。例外是反转对象 / 层次有明显差异时（不同 artifact / 不同维度），可做多段，但每段必须显式说明对象差异。
- **反转素材可行性核查**：每个反转用到的对照样本 / 揭晓素材 / 现场展示物，必须显式标注是否在比邻可控范围（已授权 / 已存档 / 可现场出示）。外部学生 / 同校同学 / 第三方机构的材料默认拿不到，不能做成可视化展示物，只能由学生 / 家长 / 顾问口述提及。
- 互动机制设计。
- 机构价值落点（落到方法论 / 团队 / 流程，不落到单个顾问）。
  - **顾问判断瞬间**：至少 1 个具体场景，展示顾问面对 case 时的真实判断过程（"第一反应 X → 改判 Y → 原因 Z"）。
- **现场展示物清单**：1-2 件可直接投影的证据物（文书段落 / 写作样本 / 成绩单等）。学生有已提交的原创写作作品时，必须纳入（不设为"可选"）。
- **学生出场方式**：不默认开场出现。如有"推演"环节，学生应在推演揭晓时立即出场（参考楚昊场约第 17 分钟）；如无推演环节，学生应在开场 10 分钟内出场。
- **学生讲述形式**：默认 Q&A 引导式（顾问问 5–7 个结构化问题，学生每段回答 2–3 分钟）。**禁止**让学生在台上做 ≥ 5 分钟连续独白。问题需提前在补采阶段对齐，让学生用原话回答。
- **主持人、顾问、学生角色分配**：必须显式列出三方时长占比。学生作为分享会主体讲述者，**学生 Q&A 答题总时长应不低于顾问的"独白式输出"时长**（独白式输出 = 推演主持 + 第三拍解析 + 收尾兜回，不含 Q&A 引导和接住）。参照楚昊场已验证比例：学生 Q&A 答题约 30–35%、顾问总时长 50–55%（含推演主持 + Q&A 引导 + 接住 + 解析 + 兜回）、主持人 8–12%。顾问总数默认 1 位（必要时最多 2 位）。
- 补采材料（包括 Q&A 引导式所需的"问题清单 + 学生原话对齐"）。
- 可公开性边界（线下可用 / 降级处理 / 内部参考 / 公众号降级线四档）。
- 整体格调（含禁用词列表 / 学生本人语调保留 / PPT 视觉风格）。
- 本 case 自身的新鲜角度。

质量自检：

- 反转是否单 case 默认只做 1 次？如果做多段，反转对象是否在 artifact / 层次维度上明显区分？
- 每段反转是否都有三拍？特别是第三拍（解析机构判断逻辑）有没有具体话术雏形？
- 每段反转的对照素材是否在比邻可控范围内？拿不到的反转有没有及时降级或砍掉？
- 现场基线认知清单是否列全？反转有没有把家长已经知道的东西当成悬念？
- 学生是否是分享会主体讲述者（学生 Q&A 答题时长 ≥ 顾问独白式输出时长）？是否使用 Q&A 引导式而非连续独白？学生出场时机是否合理（推演揭晓时即出场 / 无推演时开场 10 分钟内）？
- 顾问段落是否只做推演主持 + Q&A 引导 + 第三拍解析 + 收尾兜回，不替学生叙述？顾问总数是否控制在 1 位（必要时最多 2 位）？
- 机构价值落点有没有不自觉归因到单个顾问？
- 反向画像是否明确？
- 主轴是否陷入"A vs B"二元，没有给机构留第三个位置？
- 是否不自觉地往过往参考案例的结构靠？
- 替家长问 tough question 是否与过往 case 重复？是否显式列出了差异？
- 开场钩子类型是否匹配学生 profile 的实际张力？有没有默认套用"去光环化"？
- 开场钩子与散场疑虑是否形成闭环？散场是否暗示了转化信号？

## 分享会完整稿

必须包含：

- 分享会设计原理。
- 时间结构与现场设置。
- 主持人开场。
- 顾问引导词。
- 学生出场与回答设计。
- 家长互动问题。
- 推演、揭晓、解析环节（每段三拍，第三拍必须有具体话术）。
- 机构方法论归因。
- 散场疑虑处理。
- Q&A 控制建议。
- PPT 或 handout 内容清单。
- 补料采访问题。
- 风险提示与不可公开内容。
- 会后可转公众号的素材标注。

质量自检：

- 是否接近可直接执行，而不是高层策划。
- 是否有主持人、顾问、学生分别可以直接使用的话术。
- 是否有现场节奏、停顿、转场和舞台提示。
- 是否说明每次互动希望家长经历什么判断落差。
- 是否列出家长可能回答和讲者接法。
- 是否把机构价值落到流程、团队和方法论，而不是单个顾问。
- 是否保留这个 case 自己的故事发动机，没有套用过往 case 结构。
- 三拍反转的第三拍是否都有具体话术，而不是空泛"我们的方法论是..."。

## 分享会成稿 Review

成稿生成后，必须通过 shareflow-review skill 做系统 review。review 按以下 5 个维度逐项检查：

1. **结构忠实度**：逐项对照骨架，确认每个字段在成稿中有对应实现。时长分配、角色分工、反转段数、Q&A 结构、展示物使用位置均与骨架一致。
2. **语言表达**：检查信息重复（同一活动列表/引语多次出现）、引语语言真实性（非英语母语者不应假装用中文说话）、抽象概念具体化、禁用词。
3. **流程设计**：检查段落间过渡、情感密度分布（避免末段连续高强度）、兜回/收尾是否与前文重复、是否有"呼吸点"。
4. **设计意图**：检查骨架关键设计是否充分体现——反转的戏剧感、学生语调保留、展示物"让作品自己说话"、顾问判断过程显形化、机构归因到方法论。
5. **完整性**：检查补采环节备用方案、可公开性边界一致性、PPT 清单与话术对齐、风险提示覆盖。

Review 输出按 P0（必须修）/ P1（建议修）/ P2（可选修）分级，用户确认修改范围后逐条修改成稿。

详见 `../shareflow-review/references/review-checklist.md`。

## 公众号文章草稿

必须包含：

- 标题候选。
- 开头钩子。
- 读者推演段落。
- 核心故事。
- 方法论升华。
- 克制的机构表达。
- 轻 CTA。
- 公开性降级说明。

质量自检：

- 是否完成公开性降级，没有直接照搬线下分享会。
- 是否把现场互动改写为读者能参与的推演。
- 是否保留 case 的独特故事，而不是只写录取战绩。
- 是否减少内部过程暴露。
- 是否使用克制、专业、不强销售的机构表达。
