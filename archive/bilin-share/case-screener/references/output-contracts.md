# 输出格式契约

## Case 初筛判断卡

必须包含：

- 学生基础标签。
- 录取结果与传播价值。
- 归因纯度评级。
- 可打中的家长画像。
- 7 步法下的潜在反转点。
- 非框架发现。
- 建议内容形态。
- 需要补充的材料清单。
- 风险与公开性提醒。

## 分享会方向骨架

必须包含：

- 核心主轴。
- 目标家长画像。
- 故事发动机。
- 2-4 个认知反转。
- 互动机制设计。
- 机构价值落点。
- 学生出场方式。
- 主持人、顾问、学生角色分配。
- 补采材料。
- 可公开性边界。
- 整体格调。
- 本 case 自身的新鲜角度。

## 分享会完整稿

必须包含：

- 分享会设计原理。
- 时间结构与现场设置。
- 主持人开场。
- 顾问引导词。
- 学生出场与回答设计。
- 家长互动问题。
- 推演、揭晓、解析环节。
- 机构方法论归因。
- 散场疑虑处理。
- Q&A 控制建议。
- PPT 或 handout 内容清单。
- 补料采访问题。
- 风险提示与不可公开内容。
- 会后可转公众号的素材标注。

质量自检：

- 是否接近可直接执行，而不是高层策划。
- 是否有主持人、顾问、学生分别可以直接使用的话术。
- 是否有现场节奏、停顿、转场和舞台提示。
- 是否说明每次互动希望家长经历什么判断落差。
- 是否列出家长可能回答和讲者接法。
- 是否把机构价值落到流程、团队和方法论，而不是单个顾问。
- 是否保留这个 case 自己的故事发动机，没有套用楚昊结构。

## 公众号文章草稿

必须包含：

- 标题候选。
- 开头钩子。
- 读者推演段落。
- 核心故事。
- 方法论升华。
- 克制的机构表达。
- 轻 CTA。
- 公开性降级说明。

质量自检：

- 是否完成公开性降级，没有直接照搬线下分享会。
- 是否把现场互动改写为读者能参与的推演。
- 是否保留 case 的独特故事，而不是只写录取战绩。
- 是否减少内部过程暴露。
- 是否使用克制、专业、不强销售的机构表达。
