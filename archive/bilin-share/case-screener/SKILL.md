# Case Screener

用于材料不完整时的早期判断。目标不是成稿，而是判断这个 case 是否值得继续投入，以及下一步应该补哪些材料。

## 必读参考

执行前读取：

- `../_shared/case-methodology.md`
- `references/output-contracts.md`
- `../_shared/public-reusable/brand-voice.md`

如需回看完整筛选方法论来源，可读取：

- `../_shared/source-materials/录取 Case 宣传操作手册.md`

如用户提供了具体学生材料，也读取用户给出的材料。不要主动读取 `internal-reference/`，除非用户明确说明这是内部判断资料；即便读取，也不能把内部资料写进对外产物。

## 输入

可接受少量材料：

- 学生学校、年级、申请方向。
- 录取结果。
- 活动列表或活动摘要。
- 文书方向线索。
- 顾问口头描述。
- 家长或学生反馈。

## 工作流程

1. 先整理已知材料和明显缺口。
2. 用 7 步法做初步判断。
3. 单独寻找非框架发现。
4. 判断最适合的内容形态。
5. 输出 Case 初筛判断卡。
6. 如果材料不足，列出按优先级排序的补料问题。

## 判断原则

- 复用流程，不复用结果。
- 楚昊 case 可以作为质量参考，不能作为套用模板。
- 必须寻找这个学生自己的独特故事。
- 不把录取学校排名当作唯一判断标准。
- 优先选择机构价值清楚、家长有参考意义、学生故事有传播力的 case。
- 初筛不是填表打分，必须给出判断理由和下一步材料策略。

## 必须输出：非框架发现

每次初筛都必须输出“非框架发现”。这一栏回答：

这个 case 里有什么不在 7 步法内、但可能特别有传播力？

可以从这些方向寻找：

- 画面感场景。
- 学生身上的矛盾。
- 家长容易忽略的问题。
- 能代表比邻新形象的能力点。
- 不同于传统留学叙事的新故事。

## 输出格式

使用 `references/output-contracts.md` 中的 Case 初筛判断卡格式。

如果 case 不适合做分享会，也要说明更适合公众号、短内容、私域沟通，或暂不深做。

## 安全边界

- 不把未授权学生隐私写成对外宣传语。
- 不把内部资料写进对外产物。
- 对可公开性不确定的信息，标为“待公开确认项”。
- 不承诺录取结果。
