# 成稿 Review 检查清单

对照方向骨架，逐项检查成稿。每个维度按编号检查，发现问题时记录优先级、位置、问题描述和修改建议。

---

## 维度一：结构忠实度

检查成稿是否完整实现骨架的每个设计要素。

### 1.1 全场结构

- [ ] 全场分段数量与骨架一致（不增不减）。
- [ ] 每段的时长分配与骨架一致（偏差 ≤ 1 分钟）。
- [ ] 每段的主导者（辉 / Eva / Theresa / 家长）与骨架一致。
- [ ] 全场总时长与骨架目标一致（偏差 ≤ 3 分钟）。

### 1.2 角色分配

- [ ] 辉、Eva、Theresa 三方时长占比与骨架一致。
- [ ] 学生 Q&A 答题时长 ≥ 顾问独白式输出时长。
- [ ] 顾问总数与骨架一致（默认 1 位）。
- [ ] 学生出场时机与骨架一致（推演揭晓时 / 开场 10 分钟内）。

### 1.3 反转结构

- [ ] 反转段数与骨架一致（单段 / 多段）。
- [ ] 每段反转的三拍结构完整（家长盲判 → 揭晓 → 解析机构判断逻辑）。
- [ ] 第三拍（解析）有具体话术，不是空泛描述。
- [ ] 选校段 mini 推演（如骨架要求）是否包含。

### 1.4 Q&A 结构

- [ ] Q&A 问题数量与骨架一致。
- [ ] 每个问题的内容范围与骨架描述一致。
- [ ] 每个问题有"提问 → 学生答 → Eva 接住"三段循环。
- [ ] 替家长问 tough question 与骨架一致。

### 1.5 现场展示物

- [ ] 骨架中列出的展示物在成稿中有对应使用位置。
- [ ] 展示物的展示方式与骨架描述一致（如"投影原文，不做过度解读"）。

---

## 维度二：语言表达

检查成稿中的话术质量。

### 2.1 信息重复

- [ ] **同一活动列表是否在多个段落中被完整念出**。如果辉开场已展示档案，Eva 不应再完整念一遍。正确做法：Eva 用一句话呼应（"辉刚才给大家看了档案"），不重复列名。
- [ ] **同一引语是否在 3 个以上位置出现**。关键引语（如 counselor 原话）全场出现 ≤ 2 次为宜：一次作为悬念指向，一次由学生亲口讲。超过 2 次边际效用递减。
- [ ] **同一概念/金句是否在兜回和前文重复**。如"写到哪里停"在推演段已讲过，兜回不应原句重复。
- [ ] **散场致谢是否与兜回末段内容重叠**。两段间隔 ≤ 1 分钟时，不应使用相同的关键词或句式。

### 2.2 引语语言真实性

- [ ] **非英语母语者的中文引语是否合理**。counselor（英语母语）的引语应保留英文原话 + 中文翻译，不应假装 counselor 说了中文。
- [ ] **英语母语者的英文引语是否有中文翻译**。面向中文家长的话术中，英文引语后应附即时中文翻译，确保家长理解。
- [ ] **学生/顾问的引语是否符合其真实语境**。学生跟外教用中文交流时的引语可以是中文；counselor 跟学生用英文交流时的引语应是英文。

### 2.3 抽象概念具体化

- [ ] **专业术语是否有家长能理解的具体解释**。如"世界观""处境意识""歧视认知"等抽象词，应转化为具体场景描述。
- [ ] **机构能力标签（看见/翻译/保护）是否有具体动作支撑**。每个标签首次出现时应有具体案例说明。

### 2.4 禁用词

- [ ] 全文不出现禁用词清单中的词（逆袭 / 奇迹 / 坚持就是胜利 / 感恩 / 温情 / 励志 / 传奇 / 命运转折）。

---

## 维度三：流程设计

检查成稿的现场节奏和过渡。

### 3.1 段落间过渡

- [ ] **相邻段落之间是否有桥接**。特别是话题跳跃时（如从 Q&A 到选校 mini 推演），应有 1-2 句过渡。
- [ ] **学生出场是否有仪式感**。出场话术是否自然（不是"请下一位嘉宾"这种主持人腔）。

### 3.2 情感密度分布

- [ ] **全场情感高点是否分散**。避免最后 10 分钟连续高强度情感内容（替家长问 + 兜回 + 散场）。
- [ ] **高强度情感段后是否有"呼吸点"**。如替家长问之后、散场之前，可以加一段认知收束（三个关键词总结等）让家长消化。

### 3.3 兜回与收尾

- [ ] **Eva 兜回是否重复推演段的分析框架**。兜回应回应学生刚讲的内容（新信息），而不是重复推演段已讲过的分析。
- [ ] **散场致谢是否重复兜回的关键词**。如果兜回末段已用"不漂亮的真实"，散场应换一个收束角度。

### 3.4 冷场/风险预案

- [ ] 现场 Q&A 冷场时是否有预备问题。
- [ ] 学生回答过短时是否有引导方案。
- [ ] 标注"需要补采"的环节是否有备用方案。

---

## 维度四：设计意图

检查骨架中的关键设计是否在成稿中充分体现。

### 4.1 反转的戏剧感

- [ ] **家长盲判环节是否有足够悬念**。盲判后的话术不应提前暗示答案。
- [ ] **揭晓环节是否有停顿和节奏**。应有舞台提示（如"停顿 3 秒，让家长读 PPT"）。
- [ ] **第三拍解析是否有"判断过程"的戏剧感**。顾问应分享自己的判断转折（"我第一反应是 X，但读完之后改了判断为 Y"），而不是直接给结论。

### 4.2 学生语调保留

- [ ] 学生回答要点是否保留了学生本人的语调特征（如黑色幽默、干脆、有锋）。
- [ ] 是否避免了把学生包装成"温情小白兔"。

### 4.3 展示物使用

- [ ] **展示物是否"让作品自己说话"**。展示原文时，顾问的解读应克制（1-2 句点睛），不做过度解读。
- [ ] **展示物是否有足够的展示时间**。应有舞台提示让家长有时间阅读。

### 4.4 机构归因

- [ ] 机构价值是否落到方法论/团队/流程，而非单个顾问。
- [ ] 是否避免了神化单个顾问。

---

## 维度五：完整性

检查成稿的执行完备性。

### 5.1 补采与备用方案

- [ ] 每个标注"需要补采"的环节是否有备用方案（如引导题替代开放题）。
- [ ] 备用方案是否具体可行（不是"如答不出则跳过"）。

### 5.2 可公开性边界

- [ ] 成稿中的话术是否与骨架的可公开性边界一致。
- [ ] 需要降级处理的内容（如"同学买分"→"非常规途径"）是否已降级。
- [ ] 不应出现的内部信息（如 counselor 全名、外教真名）是否已隐去。

### 5.3 PPT 清单

- [ ] PPT 页数与成稿中引用的 PPT 切换次数一致。
- [ ] 每页 PPT 的内容描述与对应段落的话术一致。
- [ ] PPT 清单中的描述是否与最新话术同步（如引语格式更新后 PPT 描述也要更新）。

### 5.4 风险提示

- [ ] 风险提示是否覆盖已知场景（学生紧张、家长不配合、冷场、收费问题、保证录取问题）。
- [ ] 每个风险是否有具体应对方案。

---

## 使用方式

review 执行时，按维度顺序逐项检查。每发现一个问题，记录：

```
### [P0/P1/P2] 维度名 · 检查项编号

**位置**：成稿中的具体段落
**问题**：具体描述
**建议**：修改方向或示例
```

检查完成后，按优先级排序输出完整报告。报告末尾附修改建议的汇总表。
