# 比邻公开复用资料：机构 Profile

本文件只存放外部可复用资料。内容允许被用于线下分享会、公众号文章、朋友圈、家长群或私域沟通。

## 机构定位

比邻教育是一家位于深圳的留学申请机构，主要帮助学生完成海外大学申请。比邻在录取 case 宣传中强调“通过具体 case 让家长理解专业申请服务的价值”，而不是单纯展示录取结果。

## 对外表达原则

- 可以表达比邻重视学生个体故事、申请材料质量、文书判断、活动梳理和申请策略。
- 可以表达比邻希望通过分享会帮助家长看见申请中的认知差距。
- 可以表达比邻不把分享会做成硬销售，而是用完整 case 进行深度内容交付。
- 不夸大录取承诺。
- 不把个别顾问包装成唯一功臣。
- 不把内部判断、内部复盘或未授权学生材料写进对外内容。
