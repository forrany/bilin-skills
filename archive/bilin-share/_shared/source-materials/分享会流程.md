# 本场分享会的设计原理
这场分享会和常规的"录取生分享"有一个根本区别—— 
常规做法：录取生上台讲自己的故事，家长被动听，听完鼓掌离场。 
本场做法：在录取生上台之前，先让家长面对这个学生的原始材料，让他们自己推演"主 文书应该写什么"。等家长绞尽脑汁给出一堆平庸答案之后，再揭晓真实方案。 
$^ { \star }$ 核心心理机制｜家长离场时的印象不是"这个孩子真优秀"——而是"同一份材料放 在我面前，我根本想不到这个角度"。这个"差距感"才是客户转化的真正动力。 
# 本场要达成的三个效果
• 让家长亲身体验"我想不到这个角度"——比听顾问讲一万句"文书很难"都管用 
• 让家长意识到"机构判断力"的稀缺——看材料能想到什么、必须推翻什么、最后留 下什么 
让家长带着一个"未解决的问题"离场——那我孩子的材料里，什么是可以写的？这 个问题会直接推动他们来咨询

# 顾问点破（不管家长答什么，最后由顾问做总结）
我来帮大家点破： 
**第一，招生官看活动列表，已经看到了哲学大会、复旦暑校、John Locke。** 这些都 在 Common App 的表格里有详细描述，招生官看完表格已经知道这个孩子是个"哲学学 术选手"。

**第二，主文书的功能，是写表格里看不到的东西——是写这个孩子是一个什么样的人。 ** 招生官要看的不是这个孩子多聪明、多勤奋，而是——这个孩子，是一个什么样的人？ 他怎么看世界？他和别的 500 个申哲学的孩子有什么不一样？

# 收尾环节（14 分钟）
这一环节的结构：先让家长自由问 10 分钟，然后顾问主动替家长问一个"没人敢问的问 题"，由学生回答、顾问兜回——用 8 分钟把整场分享会落到最关键的那个认知点上。最 后 2 分钟致谢散场。 
$^ { \star }$ 本环节设计原理｜Q&A 结束时，家长心里一定有一个问题不会当面问—— "学校 排名不错，但哲学这个专业，真的不会耽误他吗？"这个问题不回答，所有之前的铺 垫会被消解一半。设计方式：顾问替家长问出来，学生先真诚作答（增加可信度） 顾问再做专业兜回（把话题从'哲学好不好'拔高到'美本教育的本质'）。

# 【楚昊回答·用原话讲】
当然有考虑。 
其实我的心境跟现在也不完全一样。

孩子大学四年先去做他想做的事，等大学之后再考虑谋生，都不晚。甚至可以考虑很 长时间。

# 预案｜如果学生给的回答不在 A / B / C 之内
采访可以把主要几种回答方向都问到，但现场总有可能出现意外。顾问的兜回结构永远是 万能的—— 
• 如果学生突然很紧张、给了一个平淡的答案（"我还没想清楚"）——顾问接："18 岁没想清楚是正常的。正因为没想清楚，才要去一个能让他慢慢想清楚的地 方。"然后直接跳到第二段（硬事实）。 
如果学生说了一段很消极的话（"其实我有时候也担心"）——顾问接："楚昊这个 回答很真实。每个 18 岁的孩子对未来都有担心——这不是问题。问题是，你给他 的是什么样的大学环境，让他在担心的时候有路可走。"然后跳到硬事实。 
• 如果学生讲得太长（超过 4 分钟）——顾问要礼貌打断："楚昊讲的特别好。我来 接几句——"然后进入第二段。不要让学生的回答吃掉整个彩蛋环节。 
如果学生讲得太短（不到 1 分钟）——顾问多问一句追问，比如"那你父母当时具 体说了什么让你觉得他们支持？"或者"你说的'美国大学的好处'具体指什么？"—— 把回答延展到 2 分钟左右再进入兜回。 
$^ { \star }$ 顾问心态｜学生的回答是现场的素材，不是现场的答案。答案是由顾问的兜回框 架给出的。学生讲任何话，都只是在帮顾问提供一个切入点——切入之后，所有的 路径最后都通向'美本教育让孩子多打开几扇门'这个结论。
