# 录取 Case 宣传操作手册
如何找对 case、用对 case、宣传好 case 
双视角 SOP｜顾问 $\times$ 市场 
比邻内训材料 
# 前言｜我们为什么要写这份 SOP
我们做这套 SOP，是因为做完楚昊的分享会之后，意识到一件事—— 
楚昊这个 case 的营销价值，不在于他录了范德堡。录范德堡的学生每家机构都有。他的 价值在于—— 
他签约我们时几乎什么都做不了了——没时间做背景提升、没时间去夏校、没时间重 新规划活动，托福 SAT 都没出分。剩下的路只有一条：打磨文书和活动列表。 
而文书和活动列表的打磨，恰恰是我们最拿手的事情——也是真正给他加分的那件事。 这一件事做到位，把他送进了 ED T20。 
这种 case 是做营销的黄金素材。不是因为结果好看——而是因为机构的价值变得清清楚 楚、没有别的因素可以解释得掉。学生自己的硬件、家庭资源、早期规划这些"隐变量"都 被时间压掉了，只剩机构做的那件事——这件事成了。 
那分享会该怎么讲这个 case？按常规思路有两种做法—— 
• 做法一：把他能拿得出手的东西全堆出来——WCA 魔方亚洲百强、托福 
112、John Locke 哲学论文、复旦暑校唯一高中生——包装成"一个低调的学霸"。 
• 做法二：正面讲他"励志"——讲他如何克服困难、如何调整心态、如何靠努力逆袭， 情感催化。 
两种做法我们都不要。 
第一种做法会让家长觉得"这孩子本来就不简单"——归因不清，机构分到的功劳少。第二 种做法太套路，这类故事家长听过太多。 
我们选的是第三种做法——反其道而行之。我们不讲他身上"好看"的部分，专门讲他身 上"不好看"的部分——没夏校、没金奖、活动散、签约晚、专业冷。因为正是这些"不好 看"的地方，让机构能做的事被看得最清楚。 
但讲清楚这个 case 还不够。还有一个心理学问题—— 
家长对"文书很重要"这句话听过一百遍了，早就麻木了。你在分享会上讲第一百零一 遍，他们只会点头，不会签约。 
所以我们不能"告诉"家长文书重要。必须让家长亲身体验"文书思维"是多难、"文书判断 力"是多稀缺——这种体验只能通过一种方式创造：让家长自己上手试一次，然后发现自 己做不到。 
这就是整场分享会"推演—揭晓—解析"结构用了三次的原因。每次家长都推错，每次都经 历一次"原来可以这样"的震撼。三次之后，家长自己得出结论——"我需要一个专业的人 帮我。" 
这个结论是家长自己得出来的，不是我们灌输的。这才是这套方法论真正起作用的地方。 
整场分享会从头到尾，其实只做了一件事——把"这个 case 的反直觉性"转化成"家长的 认知缺口感"。家长带着这个认知缺口离场，后续的接触才有基础。 
这份 SOP，就是把这条从"原材料"到"宣传素材"的完整链路拆解开——下一次遇到类似的 黄金 case 时，我们不用再从零摸索。 
★ 一句话记住这份 SOP 的核心｜我们不讲这个孩子多优秀—— 我们讲"只有我们能 想到"的那几件事；我们不告诉家长机构多专业—— 我们让家长自己发现自己想不到； 我们不卖某位"顾问"——我们卖"机构的方法论"。 
这份 SOP 面向两种人共用—— 
顾问（前端）：在服务学生的过程中，有意识地识别和积累"有营销潜力"的素材。 这是市场工作的上游。 
• 市场（后端）：拿到一个录取 case 之后，把它设计成分享会、公众号长文、私域 推送。这是顾问工作的下游。 
两个岗位分工不同，但底层方法论是同一套。所以一份文档分两部分讲，共用同一个 8 步骨架。 
# 第一部分｜方法论骨架（7 步法）
这 7 步是底层方法论。无论你是顾问还是市场，无论你处理的是文书强的 case 还是竞赛 强的 case，这 7 步都适用。 
每一步回答一个具体问题——按顺序走完，你就会得到一个可以立刻用于营销的素材包。

# 第 1 步｜标签化：找出这个 case 最稀缺的 2-3 个标签
# 要解决什么问题
每一个录取case 身上都有一堆可讲的东西——学校背景、标化成绩、活动、文书、家庭、 性格……一次营销活动不可能全讲。讲太多 $=$ 什么都没讲。 
你必须选出 2-3 个最稀缺的标签——然后围绕这 2-3 个标签设计整个营销叙事。 
# 怎么做
把 case 所有维度摆出来，然后对每一个维度打问号： 
• 这个维度，市场上常见吗？ 常见的排除 
• 这个维度，我们其他 case 也有吗？ 重复的排除 
• 这个维度，能对家长产生'反直觉'或'焦虑共鸣'吗？——能的留下 剩下的 2-3 个就是你的营销标签。 
# 判断标准
一个好的营销标签应该满足三个条件： 
稀缺：家长在市面上不容易看到同类案例 
• 具体：不是'学生很努力'这种抽象评价，而是'申请季才签、没夏校'这种具体事实 
• 与家长自身相关：家长看到这个标签会想到自己孩子的某个焦虑点 
【以楚昊 case 为例】 楚昊案例摆了一堆维度：深中、哲学、书法、魔方、WCA 亚 洲百强、TOEFL 112、ED Vanderbilt、签约时间、文书质量、家庭背景……筛选后 选出的 3 个核心标签—— $\textcircled{1}$ 申请季才签约， $\textcircled{2}$ 没夏校、没竞赛金奖， $\textcircled{3}$ 深中非 top 学生 ED T20。这三个标签击中'已经来不及了、孩子不够拔尖、梦校难够'的目标家 长焦虑。标化 112、WCA 亚洲百强这些'好听'的东西被压下去——不用。 
⚠ 常见错误｜不要选'让机构看起来牛'的标签（比如高分、名校、金奖），要选'让 家长自己代入'的标签（比如普通、晚、散）。前者打击的是家长自尊心（'我孩子做 不到'），后者触发的是家长购买心（'我孩子也可以！'）。 
# 第 2 步｜归因检查：能不能干净地归因于机构？
# 要解决什么问题
同样是录取了 T20，不同 case 的营销价值天差地别——差别就在归因。 
如果学生本来就是家里花300 万从小培养的天才，录取T20 是'水到渠成'——这个 case 放出去，家长的反应是'我家孩子没这个条件'。机构能分到的功劳很少，营销价值就低。 
如果学生硬件平常、签约晚、资源少，录取 T20 明显有'机构介入才完成'的痕迹——这个 case 的功劳大头就能归给机构，营销价值就高。 
# 怎么做
问自己三个问题： 
• 学生签约时是什么状态？ 越接近'硬件平常、没资源、没方向'越好 
• 机构做了什么具体的事？ 这件事是否是学生自己或家长无论如何做不到的？ 
• 如果学生没签我们，结果可能是什么？ 差距越明显，归因越纯粹 
# 归因纯粹度评级

【以楚昊 case 为例】 楚昊是典型A 级——签约时已经是高二末、托福 SAT 都没出 分、在深中非top、没夏校没竞赛金奖。机构能动的只有文书。他最终录 ED Vanderbilt，'文书救了他'这个归因逻辑成立得很干净。这也是为什么整场分享会敢 于只聚焦文书—— 因为归因就在这里。 
⚠ 常见错误｜最危险的 case 是'学生本来就强、又签了我们'——这种 case 做营销 很尴尬，因为家长心里会问'到底是谁的功劳'。如果拿不出机构做了什么具体的'关 键动作'，宁可不做主推。 
# 第 3 步｜客户画像：能打中哪一群特定家长？
# 要解决什么问题
'所有家长'不是客户。任何一次营销活动，都只能打动一种特定焦虑的家长。你必须知道 你要打谁。 
清晰的客户画像决定了：在哪里宣传、什么话题、什么时间点、什么语气。 
# 怎么做
从 case 的稀缺标签反推——哪一种焦虑的家长，会被这些标签精确击中？ 
画像至少要包含这几个维度： 
• 孩子的年级（高一/高二/高三/已申请季） 
• 孩子的学校类型（国际高中 / 公立国际部 / 普高） 
• 孩子的硬件水平（拔尖 / 中上 / 中等 / 中下） 
• 家长的期待学校档次（T10 / T30 / T50 / 稳进即可） 
• 家长当前最大的焦虑点（来不及了 / 孩子不够拔尖 / 不知道怎么规划 / 和其他机构 合作不满意） 
【以楚昊 case 为例】 楚昊精准打击的画像： $\textcircled{1}$ 孩子在高二末到高三上、 $\textcircled{2}$ 公立国 际部或深中国体系、 $\textcircled{3}$ 硬件中上但不拔尖、 $\textcircled{4}$ 家长期待T30 但没把握、 $\textcircled{5}$ 最大焦虑 是'申请季到了，还能做什么？'——这群家长在市场上数量庞大，而且进入深度了解 的意愿更强（因为真的来不及了）。分享会一场下来，这种家长的反馈会远强于'高 孩子的家长'。 
$^ { \star }$ 画像决定渠道｜精准的客户画像还告诉你应该在哪里投放——针对'申请季家长'， 公众号长文效果好（他们会认真读）；针对'高一家长'，朋友圈九宫格更合适（他们 还在浅度了解阶段）。同一个 case 用不同渠道面对不同画像家长，话术完全不同。 
# 第 4 步｜认知误区：家长以为什么是对的，实际什么才是对的？
# 要解决什么问题
这是整个方法论的发动机—— 
一场真正有效的分享会，本质上不是'展示我们多好'，而是让家长意识到他目前对申请的 理解可能有问题。因为家长只要觉得自己都懂、都对，他就不需要机构。 
所以每一场营销活动都必须围绕纠正一个或几个家长的认知误区展开。误区越典型、越普 遍，击中面越大。 
# 怎么做
把你的目标画像家长放在脑子里，问自己： 
• 对于这类家长，关于申请/文书/活动/选校/专业，他们最常见的错误想法是什么？ 
• 这个错误想法，和你的 case 真实情况之间，有没有反差？ 
• 这个反差，能不能在现场被'戏剧化'地展示出来？ 
一个 case 里挖出 2-4 个认知误区是常见的——每一个误区对应一个营销'反转点'。 
【以楚昊 case 为例】 楚昊 case 至少挖到了 4 个典型家长认知误区： 
◦ 误区 1：文书要写'高大上'的活动（复旦暑校、John Locke） 真相：写被忽 视的日常爱好（书法、魔方） 
◦ 误区2：主文书是申请里最重要的一篇 真相：小文书和活动描述同等重要， 三层联动才是完整策略 
◦ 误区3：人文专业找不到工作 真相：顶尖美本的哲学生进投行是常规路径 
◦ 误区 4：签约晚就没救了 真相：签约时间决定磨的时长，不决定结果 
这 4 个误区就是分享会 4 个核心环节的'反转点'。 
⚠ 常见错误｜不要选'太过偏门'的误区（比如只有 $1 \%$ 家长会犯的错误），要选'大 多数家长都在犯'的误区—— 这样你的反转才有最大的击中面。 
# 第 5 步｜互动设计：怎么让家长自己撞上这些反转？
# 要解决什么问题
这一步把方法论从'知识'变成了'体验'。 
你可以用 10 分钟给家长讲'文书不应该写高大上的活动'——他们点头，但走出门就忘了。 
你也可以用 10 分钟让他们亲身推演一次，自己发现'我挑的方向都是错的'——他们会被 真正打动。 
两者的信息量相同，但说服力完全不同。前者是说教，后者是体验。 
# 怎么做：推演-揭晓-解析 三段式结构
每一个反转点都可以用这个标准结构： 
# Step 1｜展示原始素材（2 分钟）
把 case 的真实素材摆出来——活动列表、题目要求、申请条件。呈现方式要刻意'去光环 化'，越普通越好。 
# Step 2｜家长推演（3-4 分钟）
问一个直接的问题：'如果你是这个孩子的顾问，你会怎么做？'让家长举手回答。收集4- 5 个答案，写在白板或 PPT 上。 
# Step 3｜揭晓真实答案（2 分钟）
告诉家长实际的做法。如果能做到'和家长答案完全相反'，杀伤力最大。停顿5 秒让家长 消化。 
# Step 4｜顾问解析（3 分钟）
解释'为什么是这个答案而不是那个'。这里才能把方法论讲深、讲到家长心里。 
【以楚昊 case 为例】 楚昊分享会用了这个结构三次—— $\textcircled{1}$ 主文书推演（方向选 择）、 $\textcircled{2}$ 小文书推演（素材选择）、 $\textcircled{3}$ 活动描述展示（家长完全不知道的维度） 每一次家长都'推错一次'，每一次都经历一次'原来可以这样'的认知震撼。三次之后， 家长的心理已经从'我懂'变成'我需要专业的人帮我'。 
$^ { \star }$ 核心心理机制｜家长离场时的印象不是'这个 case 真精彩'——而是'同一份材料放 在我面前，我根本想不到这个角度'。这个'差距感'是整场分享会真正起作用的地方。 差距感不能被口头描述创造，只能被亲身推演创造。 
# 第 6 步｜机构归因：功劳归流程，不归个人
# 要解决什么问题
这是一个容易被忽略、但对规模化经营至关重要的步骤。 
如果分享会上你把某位顾问塑造成'有灵感的天才'，家长当场会被打动——但他们后续接 触时会指名要这位顾问。一个顾问一年能带的学生有限，'指名要'就意味着其他家庭的失 望。 
正确的做法是——把功劳全部归给机构的'流程'和'方法'，而不是某位个人的才能。 
# 怎么做
两条铁律： 
• 铁律 1：学生讲述时用统称。'我们的顾问''我们的外教'——不要具体名字。具体名 字会让家长形成对个人的依赖。 
• 铁律2：顾问解析时用方法论术语。不说'这位顾问很有洞察力'，而说'这是我们流 程里的某某动作'——把天才式直觉翻译成可复制的方法。 
【以楚昊 case 为例】 楚昊分享会里，我们把具体顾问的'灵感时刻'翻译成了一系列 方法论术语—— '对比追问'、'意象提炼'、'非标素材识别'、'中外顾问协作'、'深度访 谈'。家长听到的不再是'某位老师灵光一闪'，而是'这家机构有一套训练有素的流程'。 这样后续任何一位受过训练的顾问都能接住服务。 
⚠ 常见错误｜不要在分享会上称赞某个顾问的天才 这是对机构的长期伤害。表 面上光鲜，背后是资源错配和退款。如果某位顾问确实特别优秀，她的价值应该体 现在'带新人、做培训、沉淀方法论'上，而不是被用来做分享会招牌。 
# 第 7 步｜散场疑虑：家长带走的最后一个没问出口的问题是什么？
# 要解决什么问题
分享会结束时，家长心里总会有一个'没问出口的疑问'。这个疑问如果不处理，家长回家 一想就会动摇——之前铺垫的所有内容都会被消解一半。 
这个疑问通常是文化共识里的'默认担忧'——太普遍了以至于家长不好意思当面问，但每 个人心里都有。 
# 怎么做
先预判：对于你的目标画像家长，这场活动结束时他们心里最可能有的顾虑是什么？ 
然后设计一个'结尾彩蛋'—— 
• 第 1 步：顾问主动替家长问出这个问题（'替大家问出来'的姿态让家长感到被理 解） 
• 第 2 步：学生先回答（学生身份中立，说服力比顾问自己回答高） 
• 第 3 步：顾问兜回——补充学生没讲到的专业事实 $^ +$ 升华到格局层面 
【以楚昊 case 为例】 楚昊分享会结束时，家长心里的默认担忧是—— '学校排名不 错，但哲学这个专业，以后真的不会耽误他吗？'这个问题家长不会当面问（怕显得 功利），但回家路上一定会跟配偶讨论。所以我们设计了彩蛋——顾问主动替家长 问，楚昊真诚回答，然后顾问补三条硬事实（可以转专业、可以双专业、可以进投 行），最后升华到'这正是美国大学真正吸引人的地方'。 
$^ { \star }$ 兜回的万能结构｜不论学生具体怎么回答（认真型/ 理性型/ 慢慢想型/ 紧张 型），顾问的兜回框架都是同一个：接住学生 补硬事实 升华。学生讲任何话 都只是切入点，答案是由顾问的框架给出的。这样现场永远不失控。 
# 第二部分｜顾问视角：从服务学生过程中识别营销素材
这一部分面向顾问——你们是营销素材的真正源头。 
机构的市场团队再聪明，如果顾问在服务学生的过程中没有意识地收集'有营销潜力'的瞬 间，市场拿到手的素材就是干巴巴的结果清单（'XX 同学录取了 XX 学校'），做不出有温 度的内容。 
你们不需要懂营销——你们只需要做一件事：在服务学生的过程中，多问几个问题、多记 几个细节。这一部分教你该问什么、记什么。 
$^ { \star }$ 给顾问的一句话｜你每服务一个学生，都在无意中制造未来的营销素材。有意识 地收集这些素材，比未来让市场团队从头挖掘效率高 10 倍。 
# A. 哪些 case 有营销潜力：顾问的内部评估
不是每个录取 case 都适合做营销—— 顾问自己要先有判断。 
# 快速自测：这 4 个问题
在学生拿到录取后，问自己这 4 个问题： 
• Q1 学生签约时硬件如何？ 硬件越普通，后续机构介入的归因空间越大 
Q2 机构做了哪一件'具体的、可描述的'事情改变了学生的方向？ 如果能讲清楚这 件事（比如'我们把他的文书方向整个推翻重来'），营销价值就高 
Q3 这个 case 和常见同学有什么'反直觉'的点？ 比如申请季才签、比如申人文而 非CS、比如活动看起来散——这些都是营销钩子 
Q4 学生愿意配合分享他的经历吗？ 性格内向或不愿回顾的学生，不适合做主推 case 
4 个问题里有 2 个以上回答是'有/是'——这个 case 值得提交给市场团队考虑。4 个 全'是'——这是精品 case，建议做主推。 
【以楚昊 case 为例】 楚昊 4 个问题全'是'——签约时硬件普通、机构做了明确的文 书方向重构、case 有'深中非 top 学生 ED T20'这种反直觉点、楚昊本人愿意配合。 所以他成了一个主推 case 的候选。 
# B. 服务过程中要有意识记录的 6 类素材
服务学生的日常中，这 6 类瞬间最容易被忽略，但营销价值最高。看到就记下来——录 音、截图、或者写一句话在 CRM 里。 
# 1. 学生的'初始状态'
签约第一次会议时，学生是什么样的？自信？迷茫？焦虑？对自己的定位是什么？这些签 约时的原始状态是未来讲述'我们带来了什么改变'的对照基线。如果没记录，后面就永远 讲不清楚'改变'。 
# 具体要记：
学生第一次会议时的三句原话（尤其是自我评价类的） 
• 学生当时的标化、GPA、活动状态 
学生当时的目标校清单 
• 家长当时的焦虑点 
# 2. '废稿'和'弃选方案'
任何一个好成果都伴随着无数个废弃方案。但这些废弃方案是讲述'我们的专业判断在哪 里'最好的素材——因为它们展示了'我们最终选的方案vs 我们否决的方案'的对比。 
# 具体要记：
• 初稿文书内容（或截图保留） 
• 被否决的活动主题 
• 被否决的选校方案 
• 每次被否决时的关键讨论要点 
# 3. '关键转折点'的会议场景
哪一次会议是'方向转折'的那次？当时顾问问了什么问题？学生说了什么话？这些具体的 对话细节是营销素材的灵魂——家长听到具体细节会被打动，听到抽象总结会走神。 
# 具体要记：
• 那次会议的日期、时长、形式（线上/线下） 
顾问当时问的那个'关键问题' 
• 学生当时的反应和回答 
• 会议结束时的共识 
# 4. 学生的'不登大雅之堂'的兴趣
学生身上那些自己都觉得'太幼稚、太普通'不愿写进文书的东西——书法、魔方、收集昆 虫、追星、玩cosplay——往往是最好的文书素材。顾问要专门挖这些，然后把它们保留 下来作为未来营销的亮点。 
# 具体要记：
学生告诉你的任何'不登大雅之堂'的兴趣 
学生家里的日常仪式、亲子细节 
• 学生曾经'想做但又放弃的'念头（这是他内心真正在乎的东西） 
# 5. 外教/外部资源的具体贡献
外教改了哪一段？换了哪个词？提了哪个文化细节？这些具体的介入动作是中外顾问协作 流程的证明素材。 
# 具体要记：
• 外教提出的具体文化细节（比如帕特农神庙） 
• 外教改写过的具体段落前后对比 
• 外教和中方顾问沟通的方法论术语 
# 6. 家长和学生的'松绑时刻'
申请季家庭压力巨大，家长和学生的关系经常紧张。机构在这个过程中其实也承担了'家 庭关系调节器'的功能——哪一次谈话让家长松了口气？哪一次让学生不哭了？这些情感 价值是机构服务的隐性部分，家长会被打动。 
# 具体要记：
• 机构做了什么让家长松弛下来 
• 学生在申请季最焦虑的时刻，机构是怎么介入的 
家长事后表达感谢的原话

不同的 case、不同的目标画像、不同的推广预算，适合的活动形式不同。这一部分给你 一个活动形式决策树和分渠道执行要点。

同一个 case 可以做成多种形式——分享会、公众号、小红书、朋友圈、家长群文案。但 不是每个 case 都适合每种形式。

# 一个 case 的理想运作路径
好的 case 应该被'多形式复用'——每一种形式面向不同阶段的客户： 
新闻稿/战绩图 拉新，建立品牌认知（面向陌生流量） 
• 公众号长文 软性教育，让关注用户加深了解（面向关注用户） 
• 小红书/视频 社交传播，扩大影响力（面向泛流量） 
• 分享会 深度内容交付（面向已咨询/观望用户） 
• 1v1 内容分享 精准内容分发（面向已关注的家长） 
【以楚昊 case 为例】 楚昊 case 的理想运作： $\textcircled{1}$ 先发朋友圈战绩图 $\textcircled { 2 }$ 发公众号 长文《申请季才签约、没夏校、没竞赛金奖——他靠什么 ED 上范德堡？》 $\textcircled{3}$ 办 分享会做深度内容交付 $\textcircled{4}$ 给已关注的家长做 1v1 内容分享。一个 case 用四种形 式覆盖不同阶段的家长，宣传效率最大化。 
# B. 分享会执行要点
分享会是高投入高产出的形式——一场成功的分享会能显著提升品牌的专业度认知。但一 场失败的分享会会对品牌造成负面影响。 
执行分享会的关键要点： 
# 1. 标题和宣传—— 先筛选，再吸引
标题的作用不是'吸引所有家长'，而是'吸引目标画像的家长、劝退不合适的家长'。错误的 标题会吸引一堆不对的家长来，现场效果会打折扣。 
• 好的标题：'申请季才签约、没夏校——他靠什么 ED 上范德堡？'（精准打到'来不 及了'的焦虑） 
• 差的标题：'哲学男孩的名校之路'（太抽象、太不精准） 
# 2. 现场设计—— 遵循8 步方法论
整场分享会必须按前述7 步方法论走——每一步的产出都要落到具体的环节。详细结构 可参考《分享会骨架v11》范本。 
# 3. 现场节奏控制
• 60-75 分钟最佳（太短不够有料、太长家长疲劳） 
• 互动环节（家长推演）要占总时长 $30 \%$ 以上——被动听不如主动参与 
• 学生上场时间控制在 15-20 分钟—— 是主角但不是中心 
• Q&A 只留 5 分钟——台上不给具体建议类答案，留给后续深度交流 
# C. 公众号长文执行要点
公众号适合把一个 case 讲深讲透。目标读者是'愿意花 10 分钟读文章'的家长——他们不 是冲动购买，是在深度评估机构。 
# 结构模板
• 开头（钩子）：用一个反直觉或反常识的点开篇。不要'喜获 offer'这种陈词滥调。 
中段（故事）：讲 case 的关键转折—— 签约时的状态、推翻重来的过程、某个具 体场景。要有对话、画面、细节。 
• 方法论：把故事背后的方法论用 2-3 个标签抽出来。让读者感觉学到了东西。 
• 升华：把这个 case 上升到'关于美本申请的底层认知'。制造'原来这样'的顿悟感。 
CTA（引导）：结尾引导读者关注机构、进一步了解。不要销售感太强——'如果 你也有类似的困惑，欢迎扫码聊聊'就够了。 
# 长文 vs 短内容的取舍
长文（3000-5000 字）适合深度 case 展示。短文（800-1500 字）适合讲一个单点（一 个文书段落的拆解、一个方法论词汇的解释）。 
一个大 case 可以拆成一组 3-5 篇——长文讲故事 $^ +$ 若干短文各讲一个方法论点。这样传 播周期拉长到 1-2 个月，单个 case 的 ROI 更高。 
# D. 公域短内容（小红书/视频）执行要点
小红书/视频的逻辑和公众号完全不同——读者是被动刷到的，注意力只有 3 秒。所以要 的是强视觉钩子 $^ +$ 单一记忆点。 
# 选取原则
• 找 case 里最有画面感的一个元素（楚昊 case 里是'grid 意象'、'河边读书会'） 
• 找 case 里最反直觉的一个数字（'年级 141 人无 rank 录了 T20'、'22 个英文单词 赢得招生官'） 
• 找 case 里最有故事性的一个场景（'顾问让他把书法和魔方写在一起'） 
# 内容形式
• '反转型'：前两句让读者以为是某个结论，最后反转 
'数字型'：用一个惊人数字打开注意力 
• '对话型'：用一段学生和顾问的对话展开 
• '拆解型'：带读者拆解一个具体素材（文书段落、活动描述） 
# CTA 逻辑
小红书属于浅度触达——读者还在了解阶段。CTA 应该是'引导评论/主页了解'——让读者 和内容产生互动，而不是急于推进下一步。 
# 第四部分｜关键原则与避坑指南
# 贯穿始终的 4 条原则
# 原则1｜信息差就是价值
家长为什么付钱给机构？因为有些东西家长自己查不到、想不到、做不到。把信息差显性 化——让家长当场意识到'我的理解有盲区'，就是机构价值的证明。 
营销活动的最高境界不是'说服家长相信机构牛'，而是'让家长主动发现自己有盲区'。 
# 原则 2｜归因要干净
能归给机构的 case 价值最高。如果一个 case 的功劳主要是学生自己或家庭本来就优秀， 不要硬做主推——家长能看出来，反而伤害品牌。 
# 原则3｜方法论术语化
把机构做的事情用术语讲出来——'对比追问'、'非标素材识别'、'意象提炼'。术语让抽象 的专业能力变得可辨识、可复制、可传播。 
术语是机构知识产权的表达。没有术语，专业能力就是'某位老师的直觉'——无法复制、 无法规模化。 
# 原则4｜不要造神
不要把任何一位顾问塑造成天才。造神的短期收益是现场效果好，长期代价是家长指名要 人、资源错配、退款增加。 
真正有效的是'机构流程感'——让家长相信'任何一位比邻顾问都能提供这样的服务'。 
# 常见的 $\mathfrak { g }$ 个避坑提醒
这些错误都是真实会犯的——列出来避免重蹈覆辙。 
• 坑1｜拿到录取就发朋友圈，没有后续运作。 战绩图只是起点，如果没有配套的 长文、分享会、私域推送，这个 case 的营销价值大量浪费。 
• 坑 2｜把所有优点堆到一次营销里。 '录取 Vanderbilt $^ +$ 托福 $1 1 2 + { \mathsf { W C A } }$ 亚洲百强 $^ +$ 书法全国第二'——家长看完只记得'反正这孩子牛'，记不住任何一个点。一次营 销只讲一个核心标签。 
• 坑 3｜选了光鲜但归因弱的 case 做主推。 '签我们一年就录了哈佛'——家长心里 会想'他本来就是哈佛的料'。宁可做'签我们三个月的中等生录了 T20'——归因干净， 打击面大。 
• 坑4｜分享会把顾问塑造成天才。 这是所有机构最常犯的错误。短期效果最爽， 长期最致命。参见原则4。 
• 坑 5｜公众号长文写得像简历。 '该生 GPA 4.44，托福 112，参加了 X 活动，获得 了 X 奖项……'——这是简历不是故事。读者不会看完。 
• 坑 6｜标题党但内容空。 '深中非 top 学生 ED 范德堡'这种标题很好，但如果内容 只是炫耀、没有真干货，家长看完会觉得被骗。 
• 坑 7｜分享会没有互动环节。 顾问一个人讲 60 分钟——家长听完什么都记不住。 每 10 分钟必须有一次家长参与。 
• 坑 8｜Q&A 不设边界，什么问题都答。 回答'我孩子具体情况'类的问题必然答不好 （没看到材料），反而让家长觉得这个机构不够专业。公共场合答不好的问题，留 给私下深度交流。 
• 坑 10｜一个 case 只做一种形式就丢掉。 好的 case 应该被榨干—— 一次长文 $^ +$ 多 次短文 $^ +$ 多场分享会 $^ +$ 多条私域素材，一个 case 能覆盖2-3 个月的营销内容。

# 附录 B｜楚昊 case 完整推演（参考范例）
这是我们已经用这套方法论跑完的第一个 case——楚昊（Vanderbilt ED）。以下是完整 的 8 步推演结果，可作为范例参考。 
# 第 1 步｜标签化
稀缺标签 1：申请季才签约（高二末） 
• 稀缺标签 2：没夏校、没竞赛金奖、GPA 非拔尖 
• 稀缺标签 3：深中非 top 学生 ED T20 
# 第 2 步｜归因检查
• 签约时状态：托福 SAT 未出分、活动看起来散、意向 NYU 
• 机构关键动作：推翻学生初稿方向，重构为 grid/time 主题 
归因纯粹度：A 级 
# 第 3 步｜客户画像
• 目标：高二末-高三上、国际高中或公立国际部、硬件中上但不拔尖、期待T30 
• 最大焦虑：申请季到了还能做什么？ 
# 第 4 步｜认知误区
• 反转 1：家长以为文书要写高大上活动——实际写日常小事 
反转2：家长以为主文书是唯一—— 实际是三层协同 
• 反转 3：家长以为人文专业找不到工作——实际是美本灵活性最高 
• 反转4：家长以为签约晚就没救——实际签约晚只决定磨的时长 
# 第 5 步｜互动设计
• 3 次推演：主文书推演、小文书推演、活动描述展示 
总时长：55-60 分钟 
# 第 6 步｜机构归因
• 口径：学生全程用'我们的顾问/外教' 
• 方法论术语：对比追问、意象提炼、非标素材识别、中外顾问协作、深度访谈 
# 第 7 步｜散场疑虑
没问出口的问题：'哲学专业以后怎么办？'
