# Source Materials

本目录保存源材料和高保真样本。它们不是每次执行 Skill 时要照搬的模板，而是用于校准判断质量、现场节奏、逐字稿完成度、公众号公开性处理方式的原始参考。

## 文件用途

- `分享会流程.md`：楚昊线下分享会完整流程和逐字稿样本。用于学习节奏、转场、停顿、舞台提示、互动递进和完整度。
- `公众号.md`：楚昊 case 的公众号文章样本。用于学习公开渠道的匿名化、读者推演、克制表达和轻 CTA。
- `录取 Case 宣传操作手册.md`：案例筛选、7 步法、渠道决策和宣传原则的完整来源。

## 使用规则

- 默认优先读取本 suite 的 `references/` 中抽取后的方法论、输出契约和案例摘要。
- 当需要校准完整分享会的“可直接执行程度”时，再读取 `分享会流程.md`。
- 当需要校准公众号的公开表达和匿名处理时，再读取 `公众号.md`。
- 当需要回看完整方法论来源或判断是否抽取遗漏时，再读取 `录取 Case 宣传操作手册.md`。
- 源材料可以提供质量标准，但不能成为新 case 的固定结构模板。
