# 录取 Case 方法论

核心原则：复用流程，不复用结果；复用判断，不复用模板。

## 7 步法

1. 标签化：这个 case 最稀缺的 2-3 个标签是什么。
2. 归因检查：这个结果能否干净地归因到机构服务。
3. 客户画像：这个 case 最能打中哪类家长。
4. 认知误区：家长以为什么是对的，实际什么才是对的。
5. 互动设计：如何让家长亲自经历判断落差。
6. 机构归因：如何把价值归因到流程、团队和方法论，而不是某个人。
7. 散场疑虑：家长离场前最可能没问出口的问题是什么。

## 非框架发现

7 步法之外，Agent 必须寻找这个 case 自身额外的传播力。非框架发现可以来自画面感、矛盾感、学生声音、家庭互动、失败节点、专业选择、长期成长、选校判断、面试过程或其他不在 7 步法中的材料。

## 故事发动机

故事发动机是这个学生自己的叙事驱动力。它回答：为什么这个 case 只能这样讲，为什么这个学生不是另一个成功案例的替身。

## 互动机制

推演、揭晓、解析是可复用的互动机制。具体推演题目、揭晓内容、解析角度必须由 case 本身决定。

## 反模板规则

- 不从楚昊 case 出发寻找差异，而是从新 case 出发寻找独特性。
- 不默认每场分享会都围绕主文书、小文书、活动描述三段展开。
- 不默认每场分享会都必须强调文书能力。
- 如果 case 的机构价值主要体现为选校、面试、家庭沟通、长期规划或危机处理，分享会主轴应随之变化。
